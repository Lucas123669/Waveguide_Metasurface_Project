# 版图生成工作流总览

> 更新：2026-10-20。这里维护路线选择、运行入口和数据接入状态；具体参数以各路线的配置为准。
> 两条仓库内路线目前均为 `engineering_preview`，不是已经完成光学与加工验收的投片版图。

## 1. 先选路线，再选参数

- **三角空气孔光子晶体**：进入 [blueprints](../../blueprints/README.md)。有限六角边界，每元胞六个三角空气孔；含外围刻蚀开窗、参数标记、SEM 修正接口。输出 DXF。
- **圆柱超透镜**：进入 [metalens_blueprints](../../metalens_blueprints/README.md)。圆柱、正方晶格、圆形口径、单波长轴上聚焦；从外部相位库选直径。输出 DXF，可选层级 GDS。
- **矩形柱相位图排版**：用户提供的 Python ZIP 已阅读，尚未接入仓库运行入口。当前只是外部演示，不是第三条已部署路线。
- **同心圆环排布、椭圆、旋转矩形/PB、环形及其他特殊结构**：属于待扩展功能；形状分类文档不等于运行时支持。

不要把“圆形口径”“圆柱形状”“正方晶格/同心圆排布”混为一件事。
圆柱工作流独立于三角孔入口，只通过本地包依赖复用 `blueprint_core` 的中性基础工具；迁移圆柱路线时必须同时带上基础包。
两条路线均未自动绑定 L01/L02，也不会启动 MATLAB、CST、COMSOL 或 FDTD。

## 2. 已实现的数据流

### A. 三角空气孔路线

显式晶格/腔区/包层参数 → 六三角孔与外围开窗、标记 → 局部及空间包络修正 → dose 接口与网格取整 → DRC → DXF 写入回读 → PNG 与报告。

- 入口：`blueprints/main/run_blueprint.py`。
- 配置：`blueprints/main/parameter.json`。
- 核心：`blueprints/workflow/`，公开包名 `blueprint_core`。
- 输出：`blueprints/main/.out/<case>/`，严格为参数化 DXF、`preview.png`、`layout_report.json` 三文件。
- SEM 补偿是几何修正接口，不等于电子束散射的邻近效应校正（PEC）；不代表已经完成二次 SEM 工艺闭环。

### B. 圆柱超透镜路线

外部单元仿真 CSV + 物理元数据 → SHA256/物理条件/来源/透射率筛选 → 计算目标聚焦相位 → 环形最近邻选态 → 完整柱子口径筛选 → edge bias 与网格取整 → DRC → DXF/可选 GDS → 真实轮廓 PNG 与报告。

- 入口：`metalens_blueprints/main/run_metalens.py`。
- 配置：`metalens_blueprints/main/parameter.json`。
- 核心：`metalens_blueprints/metalens_workflow/`。
- `phase_library.py`：输入、来源、物理条件和相位覆盖检查。
- `geometry.py`：聚焦相位、选态、布点和完整轮廓口径限制。
- `config.py`：独立严格配置；未知字段拒绝，不包含三角孔专属参数。
- `gds.py`：实际修正后整数轮廓的 BOUNDARY/SREF 导出及回读核对。
- `cli.py`、`preview.py`：编排、追溯和实际多边形预览。
- 输出：`metalens_blueprints/main/.out/<case>/`，DXF、`preview.png`、`layout_report.json`，启用时另有 GDS。

当前默认值是 **1550 nm、周期 0.8 µm、口径/焦距各 100 µm** 的教学验证条件，不能自动替换为合作演示的 1064/852 nm 参数。
不直接读取任意二维相位矩阵、不支持 XLSX 导入、不支持圆环布点，也不执行整片光学验证。

## 3. 环境与运行

需要 Python ≥3.12。不要依赖某台机器上的旧 `.venv` 或绝对盘符；先确认解释器实际存在。

三角孔路线，从仓库根目录进入：

```powershell
cd blueprints
uv sync
uv run python main/run_blueprint.py --preflight-only
# 预检通过，并确认目标 case 不存在后，才生成
uv run python main/run_blueprint.py
```

圆柱路线，在另一个终端从仓库根目录进入：

```powershell
cd metalens_blueprints
uv sync
uv run python main/run_metalens.py --preflight-only
uv run python main/run_metalens.py
```

没有 uv 时，可在圆柱目录建立独立环境并显式安装相邻基础包：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -e ../blueprints -e . pytest
.venv/Scripts/python.exe main/run_metalens.py --preflight-only
```

两条 CLI 均支持 `--config`。正式参数入口仍为各自 `main/parameter.json`；试验配置另存于对应 `main/` 下，记录差异，不静默改正式默认值。
圆柱输出根受限于参数文件所在目录；不把外部配置放到任意目录后期待输出仍自动进入正式 `main/.out`。
不覆盖已有 case；参数变化导致重名时使用新的工艺 revision，而不是删除旧结果或开启 overwrite。

## 4. 圆柱相位库合同

当前支持三种 CSV：

- `matlab_work10`：`D,phase_deg,mag_dB`。`D` 按当前导入器解释为 µm；每行来源记为 `unverified`。
- `matlab_work11`：`state_idx,D_um,actual_phase_deg,mag_dB,source`。
- `canonical`：`state_idx,D_um,phase_deg,transmission,source`。

`phase_deg` / `actual_phase_deg` 是实际透射相位（度），不是反号的 `actual_design_phase_deg` 绘图坐标。
`transmission` 是 0–1 的归一化**功率透射率**；dB 列转换为 `10**(mag_dB/10)`，不是场振幅，也不是聚焦效率。
各状态直径必须小于库的周期；相位按周期距离比较，不跨 ±180°/0–2π 边界直接线性插值。

物理元数据 JSON 的字段见 [实际示例](../../metalens_blueprints/data/work11_demo.metadata.json)：
`schema_version`、`wavelength_nm`、`period_um`、`pillar_height_um`、`pillar_material`、`substrate_material`、`incidence`、`polarization`、`phase_convention`、`validation_status`、`provenance`。
当前只接受 normal / co_polarized 通道；需另行明确实验偏振、时间谐波与相位参考的对应关系，不能只凭一列相位猜测。
波长/周期必须匹配配置；CSV 和元数据各固定 SHA256。改变字节、换行或数据后同步更新哈希及 revision。

默认 12 态数据来自用户提供的 MATLAB/CST 教学资料；行标签虽为 `simulated`，但没有原始 CST 工程/频谱，因此元数据保持 `unverified_import`。
其环形最大相位空档约 61.44°，不是完整连续 2π 高透射库；默认门限不是加工推荐值。
不得通过填大阈值、伪造透射率、改变来源标签来掩盖不合格输入。

## 5. 最新外部输入：已阅读，不等于已集成

这些文件仍在用户本地，未随本次代码发布上传；其他 AI 必须向用户索取实际附件，不使用文档中的文件名假装已经读到内容。

### 矩形排版 ZIP

`phase_map_rectangular_pillars_example.zip` 内的 `phase_map_to_gds.py` 使用 numpy/gdstk：
二维 rad 相位矩阵（NaN 不布点）→ 矩形相位库 `id,phase_rad,size_x_nm,size_y_nm` → 环形最近邻 → 固定朝向矩形 → 层级 GDS、placements CSV 和报告。

- 示例矩阵 238×238，有效位置 44,512；周期 420 nm。
- 配套 16 态矩形库明确为 **synthetic demo**，不能作为真实 a-Si 库。
- 行 0 对应最小 y，绘图应使用 `origin=lower`；边长是完整长宽，不是半轴。
- `example_parameters.json` 是记录文件，主程序不会读取它来改变运行参数。
- GDS 只有二维保留柱轮廓；材料/高度不会变成 GDS 三维厚度。
- 示例按中心筛孔径，边缘矩形可能超界；现有回读只检查部分结构/数量/单位，不能替代逐轮廓 DRC。
- 尚无 DXF、工艺标定、透射筛选和完整光学验证；主程序直接写既定输出，应先增加无覆盖保护再接入。

### 新的直径—相位 XLSX

`单元相位库_直径与相位.xlsx`：工作表“直径与相位”，A1:B56，55 个状态，直径 200–470 nm（步长 5 nm），透射相位为 rad。

- 仅尺寸与相位，不含透射率、波长、周期、柱高、材料、衬底、入射/偏振及相位参考说明。
- 355/360/365 nm 附近相位分别约 5.359/6.130/5.212 rad，需核对原始仿真和透射率；不能直接判为错误或强行做单调插值。
- 全部状态未筛选时，环形最大相位空档约 0.4441 rad，对任意目标的最近邻误差上界约 12.72°；这不是实际器件误差或效率。
- 有 11 个直径 ≥420 nm，不能套用矩形示例的 420 nm 周期；改变周期也需要重新确认相位库适用性。
- 圆柱库不能通过“长宽都填直径”变成矩形库。缺少功率透射率时，当前 canonical 合同不能直接接收；不要填 1 冒充已知。

建议下一步先补物理条件和透射率，再设计独立 XLSX→标准库适配器及测试；二维相位图导入、矩形几何和圆环布局分别作为后续扩展任务，不在此次整理中暗中加入。

## 6. 验证与证据边界

修改代码后，在各路线目录分别运行（临时目录使用本次唯一后缀）：

```powershell
New-Item -ItemType Directory -Force main/.out | Out-Null
uv run python -B -m pytest tests -q -p no:cacheprovider --basetemp=main/.out/.test_tmp_YYYYMMDD_TASK
```

修改公共基础包时必须两条路线回归；再做两条 CLI preflight、源码语法检查、JSON/输入哈希和 `git diff --check`。
生成实际 PNG 后必须查看；GDS 还需独立查看器与平台转换软件验收。
只清理本任务的精确测试目录和缓存，不删除用户结果或环境。

历史证据：2026-10-16 圆柱 27 项测试、三角孔 99 项测试通过；新/旧预检分别 12,193 / 16,868 图元；详情见 [实施记录](../spec/plan-execute_20261016_blueprint_metalens_integration.md)。
2026-10-20 整理时旧环境引用的 Python 运行时已不可用，不能把历史结果表述为本日重新运行。当天实际检查与受限项写入 [整理记录](../spec/plan-execute_20261020_layout_workflow_handoff.md)。

DRC 无错误不等于生产合格：空的生产尺寸门限意味着未标定，不代表已经检查通过。
圆柱 v1 强制工程预览，即使填写剂量也不能提升为 released；原三角孔的发布门禁规则独立保留。
几何 edge bias、SEM 补偿、电子束 PEC、光学 OPC 是不同环节，不能互相冒充。

# 文献库指南

文献 PDF 与阅读笔记统一存放于 `literature/`。先区分稳定编号和分类标签：编号用于追踪，材料、波段、主题和用途允许多选。

- L 系列（L01–L05）：主论文与辅助文献笔记，`literature/阅读笔记_L*.md`
- Q1 历史编号系列（设计/物理）：Q1-01~Q1-11 在 `literature/Q1_L01相关/`；Q1-12 在 `literature/材料体系分类/通用交叉/`。`Q1` 仅是历史前缀，期刊级别另行标注
- F 系列：F-01–F-10 位于 `literature/Q1_工艺_L01相关/`；F-11–F-27 按材料体系存放
- Si、SiN、TiO₂ 波段专题：A/B/C/D/T 为专题内历史架位码，跨专题引用使用 `Si-1550:A2` 这类限定编号
- 总清单：`literature/文献清单.md`
- 多维分类：[literature/多维分类索引.md](../../literature/多维分类索引.md)
- BibTeX 与论文策略：`references/references.bib`、`references/README.md`

详细入口和命名规范见 `literature/README.md`。新增文献时只创建一份规范笔记和一个 PDF 位置，再把链接加入需要的多个分类视图；若影响集合统计或项目状态，再同步 `project_config.json`。

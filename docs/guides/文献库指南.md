# 文献库指南

文献 PDF 与阅读笔记统一存放于 `literature/`：

- L 系列（L01–L05）：主论文与辅助文献笔记，`literature/阅读笔记_L*.md`
- Q1 系列（设计/物理，11 篇）：`literature/Q1_L01相关/`
- F 系列：F-01–F-10 位于 `literature/Q1_工艺_L01相关/`；F-11–F-27 按材料体系存放
- Si 1550 nm 专题（A/B/C/D，29 篇）：`literature/材料体系分类/Si/1550波段/`
- 总清单：`literature/文献清单.md`
- BibTeX 与论文策略：`references/references.bib`、`references/README.md`

详细入口和命名规范见 `literature/README.md`。新增文献时必须同步 PDF、阅读笔记、总清单和对应专题/材料 README；若有机器可读集合统计，再同步 `project_config.json`。

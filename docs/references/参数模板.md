# 仿真参数模板

> 论文中的结构参数先按本模板整理，再填入每个仿真案例的 `params.json`。

## 1. 全局参数

| 参数 | 符号 | 值/单位 | 说明 |
| --- | --- | --- | --- |
| 工作波长 | λ₀ | nm | 真空波长 |
| 环境介质 | n_env | — | 通常为空气 (1.0) |
| 衬底 | — | — | 如 SiO₂、Si、蓝宝石 |
| 工作温度 | T | K | 如有需要 |

## 2. 波导参数

| 参数 | 符号 | 值/单位 | 说明 |
| --- | --- | --- | --- |
| 芯层材料 | — | — | 如 SiN、Si、TiO₂ |
| 包层材料 | — | — | 如 SiO₂、空气 |
| 厚度 | h_wg | nm | |
| 宽度 | w_wg | nm | |
| 模式 | — | — | TE₀ / TM₀ 等 |
| 有效折射率 | n_eff | — | 模式分析获得 |

## 3. 超表面单元参数

| 参数 | 符号 | 值/单位 | 说明 |
| --- | --- | --- | --- |
| 单元类型 | — | — | 纳米柱/圆盘/狭缝/椭圆柱… |
| 单元材料 | — | — | |
| 单元高度 | h | nm | |
| 横向尺寸 | d / w | nm | 直径或宽度（扫描变量） |
| 周期 | p | nm | 亚波长，p < λ |
| 旋转角 | φ | ° | 如用于几何相位 |

## 4. 仿真设置

| 项目 | 选择/值 | 说明 |
| --- | --- | --- |
| 软件/方法 | — | FDTD / RCWA / FEM… |
| 光源 | — | 平面波 / 模式源 / 偶极子 |
| 边界条件 | — | Bloch / PML / 周期边界 |
| 网格精度 | — | 每波长点数或最小网格 |
| 收敛判据 | — | 场衰减、监视器稳定 |
| 扫描变量 | — | 如单元直径 d：范围与步长 |

## 5. 监控量与目标

- 透射/反射谱
- 单元相位与振幅（复透过率）
- 效率（衍射级次 / 指定角度）
- 远场角分布（θ、φ）
- 偏振转换率（如适用）
- 设计目标：如“0–2π 相位覆盖、效率 > 60%”

## 6. 约束条件（制备相关，可后填）

- 最小线宽 / 最小间距
- 工艺可实现的深宽比
- 材料兼容性

# simulations 使用约定

> 本文件夹存放所有仿真相关内容。每个独立仿真案例一个子文件夹，命名与内容遵循以下约定，保证可复现、可交接。

## 目录与命名

```
simulations\
├── README.md          ← 本文件（使用约定）
├── 参数模板.md          ← 仿真参数模板（论文参数 → 仿真参数 的映射依据）
└── case_XXX_主题名\
    ├── README.md      ← 案例目标、方法、结论（必填）
    ├── params.json    ← 输入参数（与 README 同步）
    ├── scripts\       ← 仿真与后处理脚本
    ├── results\       ← 结果数据与图表
    └── notes.md       ← 过程中发现的问题与决策（可选项）
```

案例编号从 `case_001` 开始顺序递增，主题名用英文或拼音（如 `case_001_unit_cell_phase_sweep`）。

## 复现要求

- 每个案例必须写明：仿真软件与方法、波长与材料参数、边界条件与光源、网格/收敛设置。
- 参数统一记录在 `params.json`，脚本只从参数文件读取，不写死数值。
- 重要结果要截图/存图并给出结论，不只留原始数据。

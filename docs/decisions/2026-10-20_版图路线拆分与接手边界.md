# 版图路线拆分与接手边界

日期：2026-10-20。依据用户先前要求“圆柱路线可以新起一个工作流”，以及本次整理与 GitHub 提交要求。

## 决定

- 保留 `blueprints/` 三角空气孔入口、参数和三文件输出合同，不修改其几何算法。
- 发布独立 `metalens_blueprints/` 圆柱入口、参数、相位数据、测试和 DXF/可选 GDS 导出；显式依赖原 `blueprint_core` 中性工具，不复制基础实现。
- 把 [工作流总览](../guides/版图生成工作流.md) 与 [AI 接手提示词](../guides/AI_版图工作流接手提示词.md) 作为跨路线入口，各路线 README 保留具体实现说明。
- 外部矩形 Python ZIP 与直径—相位 XLSX 仅记录已阅读和缺失条件，不在此次整理中集成或分发附件。缺少功率透射率及物理条件时不伪造数据通过门禁。

## 不变边界

两条默认路线均为工程预览，未新增已接受的器件仿真或加工结果；不改变 L01/L02 实验状态、合作波长计划或实际工艺参数。
圆柱 v1 仅正方晶格、圆形口径、单波长轴上聚焦；同心圆排布、矩形/椭圆/PB 和任意二维相位图导入仍未实现。
历史测试记录与本次实际复核分开陈述；运行产物继续留在各路线忽略的 `main/.out`，不把生成的大版图作为源码附件上传。

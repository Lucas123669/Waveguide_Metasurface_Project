# 文献多维分类与笔记归一

## 背景

原文献库同时用 L/Q1/F、A/B/C/D/T、材料目录、波段目录和 SCI 分区表示文献。A/B/C/D 在 Si 与 SiN 专题中重复，`Q1` 又同时像编号和期刊等级，导致编号、分类和物理位置被混为一谈。同一 DOI 还存在多份内容相近的笔记。

## 决策

1. 文献编号只承担追踪作用，不再表达唯一分类。
2. L/Q1/F 保留为历史稳定编号；`Q1` 前缀不保证当前期刊等级。
3. A/B/C/D/T 保留为专题内历史架位码；跨专题使用 `材料-波段:架位码`，例如 `Si-1550:A2`。
4. 材料、波段、主题、用途均为可多选标签。期刊级别单独记录，不参与文件路径和编号。
5. PDF 保持一个物理位置；跨分类通过索引链接，不复制文件。
6. 同一 DOI 只维护一份规范笔记；旧路径改为兼容页，保留链接稳定性。
7. `literature/多维分类索引.md` 负责分类导航，`literature/文献清单.md` 负责稳定编号与状态。
8. `CHANGELOG.md` 只记录结构、口径和可复现结果等项目级变化，维护流水账留给 Git 历史。

## 迁移策略

- 不批量移动 PDF，避免仓库体积和链接风险。
- 不重命名既有 L/Q1/F 文件和目录。
- 将旧 `分区全景索引.md` 降为兼容入口；历史细节可从 Git 历史查看。
- 先处理已确认的重复笔记，后续新增文献直接按本规则入库。

## 验收标准

- 读者能区分“编号、专题架位码、分类标签、期刊级别、物理位置”。
- 一篇文献能从多个任务视图访问，但只有一个规范笔记。
- 根 README、文献入口和文献清单不再重复维护长更新记录。
- 旧链接继续可用。

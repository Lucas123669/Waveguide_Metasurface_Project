# 决策记录：材料体系分类目录收纳 PDF 的约定修订 + F08 案例文献批次（F-11~F-27）

> 日期：2026-09-02
> 类型：文献组织约定修订 + 文献批量入库记录

## 背景

- `literature/材料体系分类/` 初建于 2026-09-01，原约定"只放分类索引、不复制 PDF"（PDF 保留在 `literature/` 下 L/Q1/F 原结构）。
- 用户要求下载 F08 制造综述（本库 F-08）中按类别介绍的重要参考文献，并选择"PDF 直接放体系目录"。

## 决策

1. **约定修订（2026-09-02 起）**：`literature/材料体系分类/<体系>/` 目录除 README 外，开始收纳：
   - `pdfs/`——原文 PDF；
   - `阅读笔记_F_编号_作者_年份.md`——精读笔记。
   原"只索引不复制"原则仅对 L 系列、Q1 系列与 F-01~F-10 继续适用。顶层 README 已同步改写。
2. **编号方案**：新增文献延续 F 系列编号 **F-11~F-27**（与 F-01~F-10 同性质：Q1 级制造/工艺文献；来源 F08 案例论文），编号全局唯一并登记于 `literature/文献清单.md` 与 `project_config.json`。
3. **合法性**：PDF 仅从合法开放获取渠道下载——出版社 OA 正式版、PMC/Europe PMC、arXiv 作者版、DOE OSTI 官方绿色稿、中国激光杂志社官方平台。出版社版为订阅制的用 arXiv/绿色稿替代并在清单注明；无任何盗版渠道。
4. **待办遗留**：F-19（Optica）与 F-20（De Gruyter）出版社反爬（Radware/403），脚本无法下载 → 标记"待浏览器手动下载"，落地页 URL 记录在 `scripts/f08_download_manifest.json` 与文献清单；对应阅读笔记待 PDF 到位后补写。

# L01 微纳加工细节与注意事项

> 来源：Huang et al., *Leaky-wave metasurfaces for integrated photonics*, Nature Nanotechnology 18, 580–588 (2023) 的 Methods「Device fabrication」部分，以及补充材料 S.5、S.6、S.13、Fig. S16。
> 笔记日期：2026-08-24

## 1. 一句话概括工艺路线

**单层 PMMA 工艺**：PMMA 同时充当电子束胶和波导图案层，EBL 曝光 + 显影即完成全部结构（波导边界 + LWM 孔阵），**没有刻蚀、没有剥离**，是这套器件工艺友好性的核心。

## 2. 论文给出的工艺步骤（原文参数）

| 步骤 | 参数 / 操作 |
|---|---|
| 衬底 | 180 μm 熔融石英（SiO₂，n≈1.44） |
| 波导层沉积 | PECVD 生长 300 nm Si₃N₄（n≈2.00） |
| 图案/胶层 | 旋涂 300 nm PMMA（n≈1.48），180 °C 烘烤，兼作 EBL 胶 |
| 电子束光刻 | Elionix ELS-G100；100 keV；束流 1 nA；剂量 750 μC/cm²；BEAMER 做邻近效应校正；定义波导边界与 LWM 图案 |
| 显影 | 3:1 异丙醇（IPA）:去离子水 |
| 解理 | 解理芯片露出窄脊形波导端面，供透镜光纤耦合 |
| 洁净室 | Columbia Nano Initiative；CUNY ASRC NanoFabrication Facility |

表征：1.55 μm 二极管激光 → 透镜光纤（调偏振）→ 器件；表面辐射经 ×10/×20 近红外物镜（Mitutoyo）→ 偏振片（Thorlabs）→ 近红外相机（Princeton Instruments）。

## 4. 精度要求分析（为什么加工容差要紧）

1. **δ 直接决定辐射振幅**：一阶线性区 A ∝ δ（图 3b）。δ 有 ±ε 的相对误差 → 振幅误差 ≈ ε。
2. **δ 二次方决定 Q 与光谱**：Q = C/δ²。δ 相对误差 ε → Q 误差 ≈ 2ε，且共振线宽/波长随之漂移。δ 越小越敏感（弱散射单元、或高效 apodization 设计的弱辐射区）。
3. **α 决定偏振**：α 误差 → 偏振取向 ψ 误差与偏振串扰。要求圆孔足够"圆"、椭圆取向精确——任何非故意的各向异性（束斑像散、显影不均匀、胶的各向异性收缩）都会等效引入 δ/α 误差。
4. **结论**：对最小特征（几十 nm 的 δ、~200 nm 量级的孔）需要**几纳米量级的尺寸重复性**，工艺窗口取决于剂量、显影、烘烤的一致性。

## 5. 注意事项（按工序）

### 5.1 材料与薄膜
- PMMA 身兼两职意味着**胶厚 = 波导层厚 = 孔深（300 nm）**：厚度偏差同时改变 n_ms 与辐射行为，旋涂均匀性与 180 °C 烘烤一致性必须严格控制；残留溶剂会改折射率和显影速率。
- PECVD Si₃N₄：关注厚度均匀性、n≈2.0 的稳定性与吸收；PECVD 相对 LPCVD 质量低一些但温度低，适合 180 μm 薄熔融石英衬底。
- 180 μm 薄衬底：易解理（工艺需要），但易碎、易翘曲；SiN 膜应力会导致弯曲，影响 EBL 聚焦与对准。

### 5.2 电子束光刻
- 100 keV 高能 + 1 nA 低束流：分辨率高、邻近效应小，但**写入慢**——数十万–百万孔级图案（估算）耗时长，需考虑漂移。
- **邻近效应校正不可省**：图案同时包含大开放区（波导边界）和 0.4 μm 周期密孔阵，局部剂量差异大；BEAMER PEC 保证大/小特征同时达到目标尺寸。
- **写场拼接**：400 μm LWM + 4.8 mm 锥形区超出单写场，拼接误差会破坏晶格周期性，产生可见缺陷（条纹）。100 keV 下写场约 0.5–1 mm，需要写场校准与拼接策略。
- 绝缘衬底（玻璃/PMMA）存在充电问题，需考虑电荷泄放手段（论文未写明，属通用工艺考虑）。

### 5.3 显影
- 3:1 IPA:去离子水属于温和显影液，工艺窗口较好，但对**时间/温度/搅拌一致性**敏感；显影不足会残留、过显影会吃掉小孔或放大 δ 误差。
- 建议显影后 SEM 抽检：孔圆度、尺寸、跨孔径均匀性、缺陷密度。

### 5.4 缺陷控制
- 补充材料 S.13 / Fig. S16 明确指出：**加工缺陷（破损元胞、随机散射）引起面内散射，在表面辐射图中产生下游条纹**，且"可通过改进加工去除"——即器件良率直接与缺陷密度挂钩。
- 微粒污染会毁掉局部元胞，全孔径（400 μm）内任何缺陷都可见，洁净室操作与样品保护很重要。

### 5.5 端面与测试
- 解理质量决定耦合效率：端面需垂直、无碎屑；180 μm 熔融石英为无定形材料，采用划片-断裂。
- 耦合时必须调偏振以激励**基模 TM**：错激励成 TE 会得到不同的 Jones 响应（含零阶散射项，S.6 式 S2），器件性能劣化。
- 辐射近正入射（NA 0.1–0.37），收集光路用近红外物镜 + 偏振片 + 近红外相机。

## 6. 对项目复现的启示

1. **工艺门槛集中在 EBL 一步**：PECVD SiN + 旋涂 PMMA + EBL + 显影 + 解理，无刻蚀，是我们可以完整复制的流程。
2. **低折射率对比体系是"容错设计"**：S.4/S.13 说明该体系下扰动保持微扰性、平带不造成串扰，对加工误差的敏感性低；若迁移到 SOI 高对比体系，同样的加工误差影响更大。
3. **效率与加工精度成反比**：理论 99% 表面发射需 apodization（σ_max ≈ 0.04/μm、Q_min ≈ 25），弱辐射区 δ 极小，对加工精度要求更高；论文演示器件保持低效率（大部分功率留在导模），工艺压力较小。
4. **量产路线**：单层 PMMA 图案天然适合纳米压印/DUV 转移（无刻蚀）；可参考我们之前搜到的 DUV 制造 qBIC Si₃N₄ 晶圆的 Nano Letters 2026 工作。
5. 对我们而言：先仿真复现元胞库，再决定是否/如何进入加工；加工前需确认可用 EBL 设备与洁净室条件。

# 片上光波导与超表面工艺研讨纪要

- 日期：2026-09-28
- 议题：片上光波导与超表面的目标器件、材料路线、微纳加工、仿真与测试推进
- 参会发言：毛逸飞、吴家昊（发言人 1 / 2）、刘畅、孟乐天等 7 人
- 文档状态：会议纪要；其中工艺参数与设备能力仍需平台确认和试片验证

## 一句话结论

合作项目先以 **MOT 演示**为应用牵引，按“波导出光口 → 超表面集成 → 调制功能”逐级推进；近期材料集中在 **Si 与 Si₃N₄**，合作演示先做 **1064 nm**、再拓展至 **852 nm**，TiO₂ 暂缓。加工侧优先解决 EBL 防充电、硬掩膜、刻蚀窗口和大面积图形密度效应，仿真侧采用局部抽样而不是直接做毫米级全器件全波仿真。

> 口径说明：1064/852 nm 是本次合作演示的近期波长顺序，不回溯修改 L01/L02 在 1550 nm 下的论文复现参数。

## 1. 已形成的项目方向

### 1.1 应用与器件推进顺序

1. 初期以磁光阱（MOT）作为核心演示场景。
2. 在出光与聚焦能力稳定后，拓展至光镊等高功率聚焦应用。
3. 器件按模块化方式推进：先实现波导出光口，再集成超表面，最后增加调制器件等复杂功能。

### 1.2 分工

- 毛逸飞团队：光栅耦合器（Grating Coupler）设计及部分微纳加工。
- 吴家昊团队：原子相关表征与测试。
- 其他成员按下文待办项推进衬底、工艺、仿真资源和测试设备调研。

### 1.3 材料与波长

- 近期材料：优先 Si 与 Si₃N₄，减少多材料并行带来的工艺复杂度。
- TiO₂：保留为后续路线，本阶段暂缓加工。
- 第一测试波长：1064 nm，优先利用较易获得、成本较低的固定波长激光器。
- 后续波长：852 nm，面向铯原子相关应用。
- 光源策略：当前优先采购或借用特定波长激光器，暂不把超连续谱光源列为近期必需设备。

## 2. 微纳加工讨论

### 2.1 EBL 防电荷积累

会议建议针对交大 EBPG 平台的绝缘样品充电问题，在电子束胶表面蒸镀约 **10–15 nm Cr** 作为临时导电层；曝光后先湿法去 Cr，再显影。

在转为正式工艺卡前，需要向平台确认：

- Cr 的沉积方式、厚度窗口和膜连续性；
- 导电层如何与样品台可靠接地，而不只是“表面有金属”；
- 去 Cr 药液及其对 PMMA、ZEP、HSQ 和下层材料的兼容性；
- 去 Cr 后是否引入胶损伤、残留、线宽偏差或图形坍塌；
- 加 Cr 前后是否需要重新做剂量矩阵和聚焦/漂移验收。

因此，**10–15 nm Cr 是会议建议的起始条件，不是已经验证的固定 Recipe**。

### 2.2 掩膜与图形转移

- 深刻蚀优先评估 Cr 硬掩膜，避免正胶直接承担长时间刻蚀造成的选择比不足和侧壁劣化。
- 同时调研 HSQ。候选流程为“HSQ 图形 → 转移至 Cr → Cr 掩膜刻 Si”。
- HSQ 曝光后会形成类 SiOₓ 的无机网络，既可作负胶也可作硬掩膜；但“HSQ 刻 Cr、Cr 再刻 Si”的两级选择比、去膜方式和残留必须分别验证。

建议先做小尺寸 DOE，测量：曝光剂量、显影偏差、Cr 刻蚀选择比、Si/Si₃N₄ 刻蚀速率、侧壁角、线宽偏差、粗糙度和残留。

### 2.3 Si / Si₃N₄ 刻蚀与过刻蚀

会议认为目标深度不一定需要专用深硅刻蚀机，普通介质 ICP-RIE 可能可以完成，但必须以平台材料兼容性和试片结果为准。需要确认：

- 目标膜厚、最小线宽和最大深宽比；
- 气体体系、偏压、ICP 功率、腔压、温度和刻蚀速率；
- 掩膜选择比、侧壁角、微加载（microloading）和 ARDE；
- 对下层 SiO₂ / 熔融石英的选择比以及允许的过刻量；
- 终点监测方法与停机判据。

会上提到“监测氧气浓度来判断终点”，该说法需由工艺工程师结合实际气体体系核实。实际设备可能使用 OES 等方式监测特定等离子体发射线，不能在未确认前把“氧气浓度”写成通用终点判据。

### 2.4 波导旁大面积区域

- 候选版图方案：在波导周围设置数百微米量级的隔离间隙，避免大面积高折射率薄膜紧邻波导。
- 候选曝光方案：大开放区使用较大束流，精细结构使用较小束流；在 BEAMER 中完成邻近效应修正（PEC）和跨写场处理。
- 需要先检查隔离间隙对光学传播、热效应和版图面积的影响，再确定最终宽度。
- 刻蚀 DOE 应同时包含孤立线、密集阵列、大开放区和波导邻边，比较不同图形密度下的刻蚀深度与侧壁。

## 3. 仿真与测试策略

### 3.1 大尺寸超表面

- 毫米级器件不直接作为第一步进行全器件全波仿真。
- 先以小尺寸器件验证设计误差，再抽取大器件中心、过渡区和边缘的局部结构进行仿真。
- 局部模型至少检查相位、振幅、偏振、反射/透射、工艺偏差敏感度以及波导模到自由空间的功率预算。

### 3.2 计算资源

- 当前 CPU 运行 FDTD 效率较低，先调研校内可用 GPU 服务器。
- RTX PRO 6000 可作为候选配置，但采购前必须用代表性模型做基准测试，并确认所用 FDTD 软件、版本与许可证支持 GPU 加速及所需显存。
- COMSOL、FDTD 和自研代码对 GPU 的利用方式不同，不能只凭显卡型号判断加速收益。

### 3.3 耦合与光路

- 端面耦合拟使用六轴位移台，使单模光纤对准波导端面。
- 会上提到“端面耦合效率最高约 50%”应视为讨论目标，而非本项目已实现数据；后续需用输入功率、输出功率、器件传播损耗和接口损耗建立统一测量口径。
- 调研全自动光纤耦合测试设备，同时整理 3D 打印接口/夹具方案。

## 4. 分阶段决策门

1. **G1：EBL 防充电可用**——完成 Cr 顶层导电方案的接地、去除、剂量和图形漂移试片。
2. **G2：刻蚀链路可用**——完成胶/硬掩膜/Si 或 Si₃N₄ 的选择比、侧壁和过刻蚀 DOE，并明确终点判据。
3. **G3：1064 nm 设计可用**——完成材料光学常数确认、单元库、中心/边缘局部仿真和工艺容差分析。
4. **G4：测试链路可用**——完成波导端面、六轴调节、固定波长光源、探测器和功率标定。
5. 通过上述关口后，再扩大器件面积并推进 852 nm、超表面集成和调制功能。

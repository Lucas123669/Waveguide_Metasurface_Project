# EBL 加工与仿真设备咨询问题清单

> 日期：2026-09-14  
> 用途：向 EBL 平台、洁净室工艺老师和仿真平台负责人集中咨询。本文只整理问题和项目基线，不把文献参数当作本地平台承诺。  
> 术语：本文统一使用“**邻近效应**（proximity effect）”；口头所说的“导电胶”需先确认是可水洗导电聚合物顶涂、金属导电层，还是其他防充电方案。

## 1. 咨询目标与优先级

### P0｜开始版图和投片前必须确认

1. 绝缘衬底上的防充电方案能否与 300 nm PMMA 最终结构层兼容。
2. 本机加速电压、束流、写场、邻近效应校正软件和剂量测试方法。
3. 300 nm PMMA 的具体型号、旋涂/烘烤/显影窗口及尺寸偏置。
4. 400 μm 超表面区与约 4.8 mm 锥形区的写场拼接、漂移和总写入时间。
5. COMSOL 6.3 的 Wave Optics 许可、批处理能力，以及元胞扫参可用的 CPU、内存和临时存储。

### P1｜小试前确认

1. 测试片尺寸、剂量矩阵、邻近效应参数标定和 SEM 量测方案。
2. 薄熔融石英样品的夹持、接地、翘曲、解理和破片风险。
3. 并行任务数、排队时限、远程运行、断点恢复与数据归档方式。

### P2｜整器件加工或扩算前确认

1. 跨写场的大面积一致性、长期漂移和缺陷密度。
2. 器件级三维模型的自由度、峰值内存和求解时长实测，再决定是否申请工作站或集群。

## 2. 提交给平台的项目基线

| 项目 | 当前基线 | 必须说明的边界 |
| --- | --- | --- |
| 衬底/薄膜 | 180 μm 熔融石英 / 300 nm PECVD Si₃N₄ | 薄片易碎、绝缘且可能翘曲；本地膜参数仍需实测 |
| 图形层 | 300 nm PMMA，同时作为 EBL 胶和最终光学结构层 | 显影后不剥胶；导电层去除不能损伤或改变 PMMA |
| 图形 | 0.4 μm 晶格中的圆孔/椭圆孔；超表面区约 400 μm；锥形区约 4.8 mm | 同时存在密集小图形与大开放区，且需要跨写场 |
| 文献曝光基线 | L01：100 keV、1 nA、750 μC/cm²、BEAMER PEC | 仅用于对照；必须按本机、本胶和本衬底做 dose test |
| 另一可比工艺 | PMMA 950K、300 nm、20 kV、200–250 μC/cm²、Espacer 300Z | 电压、烘烤和显影条件不同，不能直接替代 L01 参数 |
| 仿真主线 | COMSOL 6.3 FEM；先做 L01 元胞 `D₀/δ/α` 扫描与容差展宽 | L01 原文使用 FDTD；是否需要 Lumerical/MEEP 交叉验证待定 |
| 已有规模证据 | L02 的一个已求解三维 COMSOL 文件约 923 MB | 文件大小不等于运行峰值内存，设备需求须用实际作业记录确定 |

## 3. EBL 与 PMMA 加工问题

### 3.1 防充电层：所谓“导电胶”到底怎么做

向 EBL 平台逐项询问并记录：

- 对“熔融石英 / Si₃N₄ / 300 nm PMMA”绝缘堆叠，平台首选哪一种防充电方案：Espacer 类可水洗导电聚合物、Electra 类材料、蒸镀薄金属，还是样品边缘导电连接？
- 若使用导电聚合物，请给出**产品全名、批次/有效期、目标厚度、旋涂转速与时间、是否烘烤、曝光前等待时间**。
- 导电层放在 PMMA 上方还是下方？若放在上方，对束流散射、对焦和实际到达 PMMA 的剂量有多大影响，剂量测试是否必须连同导电层一起完成？
- 导电层怎样去除：去离子水冲洗时长、是否搅拌、去除发生在曝光后显影前还是其他时点？该步骤是否会使 PMMA 吸水、开裂、起皮或改变小孔尺寸？
- 若使用金属层，金属种类/厚度、沉积温升、去除液及其对 PMMA 和最终光学性能的影响是什么？既然 PMMA 是最终结构层，能否无残留去除？
- 样品如何与样品台形成可靠接地：边缘露底、导电胶带、银浆或专用夹具？接地点离写入区多远，是否会污染真空腔体？
- 平台如何判断充电已受控：对焦漂移、图形偏移、束斑畸变是否有可观察的验收标准？
- 同一防充电方案能否用于后续 SEM；若 SEM 需要另加导电层，量测后能否恢复为可进行光学测试的洁净表面？

**需要拿到的结论：** 一条带材料、厚度、顺序、去除方法和接地方法的完整流程，而不是只得到“可以涂导电胶”。

### 3.2 邻近效应校正（PEC）与剂量标定

- 平台使用哪套 PEC 软件和版本（如 BEAMER 或设备自带软件）？支持按图形密度进行剂量调制、形状偏置和写场级校正吗？
- 本机加速电压、束流、光阑、束斑、步进尺寸和写场分别有哪些可选值？平台建议本项目优先保证分辨率还是写入时间？
- PEC 所需的前向散射、背散射范围和能量沉积分布参数来自厂商库、历史标定还是本衬底实测？玻璃/Si₃N₄/PMMA 堆叠是否已有可复用参数？
- 图形同时包含 0.4 μm 周期密孔阵和大开放区，版图应如何分层、fracture 和分区赋剂量？波导边界与孔阵是否需要不同剂量或不同偏置？
- 应设计怎样的二维 dose matrix：剂量、孔径偏置、椭圆长短轴差 `δ`、局部图形密度各取多少档？每档需要多大面积才可可靠量测？
- 正胶开孔后，目标孔径和椭圆长短轴通常会出现何种系统偏差？平台是否能提供类似厚度 PMMA 的历史 CD 偏差和重复性数据？
- PEC 验收看哪些量：中心/边缘孔径、圆度、椭圆角度、密集区/稀疏区差异、跨写场差异？建议每项采用什么统计量和抽样数？
- 小 `δ` 区域对尺寸误差更敏感。平台能承诺的不是“最小线宽”，而是多大范围内的 **CD 均值误差与 3σ 重复性**？

**需要拿到的结论：** 本机的剂量测试版方案、PEC 参数来源、版图预处理规则和 CD 验收口径。

### 3.3 PMMA 配方、旋涂、烘烤与显影

- 平台可提供或允许自带的 PMMA 是哪一款：分子量、固含量、溶剂、厂家、产品号和有效期分别是什么？PMMA 950K、AR-P 679.04 与 950K A4 在平台流程中是否可等效使用？
- 在实际熔融石英/Si₃N₄ 表面上，达到 300 nm 的旋涂曲线是什么？是否需要脱水烘烤、表面清洗、底涂或过滤？这些处理会不会影响附着力和最终折射率？
- 对 180 μm 薄片使用何种托片、边缘去胶和背面清洁方法，才能避免真空吸附失败、厚度不均和破片？
- 烘烤采用热板还是烘箱？温度、时长、升降温和冷却方式如何固定？180 °C 文献条件是否适合本平台，还是先以较低温条件做对照？
- 曝光剂量是否按“PMMA + 防充电层 + 实际衬底”整体标定？不同电压下怎样选择起始范围，禁止仅按文献剂量比例换算后直接投正式样品。
- 3:1 IPA:去离子水是否是平台常用显影体系？显影温度、时间、搅拌方式、终止/漂洗和干燥方式分别是什么？是否建议与 7:3 IPA:水或其他体系做对照？
- 如何检查显影残留和孔底清洁度？若出现残胶，平台允许的后处理是否会改变 PMMA 光学层厚度或孔形？
- 显影后 PMMA 作为永久光学材料时，是否需要后烘、静置或防护层？其收缩、老化、吸水和清洁方式是否有历史数据？
- 是否能测量加工前后膜厚、粗糙度以及 1550 nm 的折射率/吸收；对应设备是台阶仪、AFM 还是椭偏仪？

**需要拿到的结论：** 可复现的 PMMA 工艺卡，以及膜厚、孔径和光学常数的测量方法。

### 3.4 写场拼接、漂移与样品处理

- 选定电压和精度下的最大可靠写场是多少？400 μm 超表面区能否置于单写场内？约 4.8 mm 锥形区如何拆分？
- 平台的写场拼接误差和长时间漂移如何标定？晶格跨边界时，版图是否应调整边界位置、留缓冲区或改变扫描方向？
- 是否需要全局/局部对准标记；标记材料、尺寸、制作顺序和识别精度是什么？
- 单次写入预计多久？设备是否允许自动对焦、分区调焦和中途校准？超过多长时间后需要考虑热漂移与充电变化？
- 薄熔融石英如何装载、卸载、运输和解理？平台是否支持先用厚片/小片做工艺验证，再转入 180 μm 正式衬底？

### 3.5 小试与验收

建议先让平台确认以下最小测试结构，而不是直接写完整器件：

1. 不同剂量 × 不同孔径偏置的密集圆孔阵。
2. 多档 `δ` 和 `α` 的椭圆孔阵，同时放置稀疏区与大开放区。
3. 一条跨写场晶格，用于测量拼接错位与周期突变。
4. 带/不带防充电层的对照区（若平台安全规则允许）。
5. 膜厚、孔径、长短轴、取向角、残胶、缺陷密度和跨区域均匀性的量测标记。

正式投片前至少应形成：测试版 GDS、曝光参数表、SEM/AFM/膜厚结果、推荐剂量与偏置、PEC 配置版本、拼接误差记录。

## 4. 仿真对软件与设备的咨询问题

### 4.1 先按任务询问，不先报一个“电脑配置”

| 仿真任务 | 当前状态/规模 | 向平台询问并记录 |
| --- | --- | --- |
| 平板波导模式 | L01 `case_001` 已可用纯 Python 完成 | 是否需要 COMSOL；单次运行时间、内存很小，可作为环境连通性测试 |
| qBIC 周期元胞 | L01 `case_002`，待扫描 `D₀/δ/α`，并做 `σ=1/2/3 nm` 容差展宽 | 单模型自由度、网格收敛后峰值内存/时长；扫参并行度；本征频率与频域求解各需何种模块 |
| 单 meta-atom 相位库 | L02 三维端口激励、金属局部细网格 | 金属边缘网格、PML 和参数扫描的峰值资源；能否批处理和断点续算 |
| 有限超胞/整器件 | 已有 15 超胞 45° 结果；一个 solved `.mph` 约 923 MB | 实际自由度、峰值 RAM、墙钟时间、临时文件和输出大小；扩展孔径后的增长趋势 |
| 超透镜/大孔径 LWM | 尚未扩算 | 先做对称性、降维和子模型评估；何时必须使用高内存节点或集群 |

### 4.2 软件、许可与自动化

- 现有 COMSOL 6.3 许可是否包含 **Wave Optics Module**，能否使用 Electromagnetic Waves, Frequency Domain、本征频率、端口、周期/Floquet 边界、PML 和远场计算？
- 许可是单机、浮动还是集群许可？允许同时运行多少个 GUI、batch 和参数扫描作业？并行时如何消耗许可令牌？
- `comsolbatch`、`comsolmphserver`、Java API，以及 Python `mph`/JPype 连接是否允许使用？无人值守长作业有无平台限制？
- 若要严格对照 L01 的 FDTD，平台是否有 Lumerical FDTD 许可；若没有，是否接受以 COMSOL FEM 为主、后续再做交叉验证？
- 材料库是否含 1550 nm 的 PMMA、Si₃N₄、Si、SiO₂ 和 Au 光学常数；自定义色散数据能否留存并注明来源？
- 平台固定使用哪个 COMSOL 小版本、操作系统和求解器设置？项目文件跨版本打开后是否能回退？

### 4.3 CPU、内存、存储与队列

- 可用节点的 CPU 型号、物理核心数、单核频率、总内存和每作业内存上限是多少？
- COMSOL 当前求解器在这些模型上能有效利用多少核心？增加核心后是否有平台实测加速数据？
- GPU 是否被拟采用的 COMSOL 求解器实际使用；若没有明确验证，不把高端 GPU 作为本项目采购的首要依据。
- 本地 SSD/高速临时盘容量、单作业临时文件上限和 I/O 性能如何？作业结束后临时目录保留多久？
- 单任务最长运行时间、队列等待时间、最大并行任务数和夜间作业政策是什么？作业被中止后能否恢复？
- `.mph`、导出场数据和扫参结果存在哪里；个人配额、项目共享空间、备份周期和长期归档容量是多少？
- 能否通过远程桌面或作业调度器查看日志、停止异常作业并下载轻量结果，而不搬运全部大型 `.mph`？

请仿真平台先协助完成三个基准作业，并回填下表。只有这些数据齐全后，才讨论“最低配置/推荐配置/集群配置”。

| L01 单个 qBIC 元胞，收敛网格 | 待填 | 待填 | 待填 | 待填 | 待填 | 待填 | 待填 |

设备负责人需要据此回答：

1. **最低可运行设备**：可完成单元模型与串行扫参，但不保证时效。
2. **推荐工作站**：能在预期周期内完成收敛测试和常规扫参。
3. **集群触发条件**：达到何种自由度、内存或扫参数量时应转集群。
4. **预计扩展策略**：优先并行多个独立参数点，还是给单个大型模型增加共享内存与核心。

## 6. 咨询后的决策门

- **门 1｜可做剂量测试片**：EBL-01 至 EBL-05 有明确流程，且平台接受实际样品堆叠。
- **门 2｜可投正式样品**：测试片给出推荐剂量/偏置、CD 重复性和拼接误差，PMMA 无不可接受残留或损伤。
- **门 3｜可启动批量扫参**：SIM-01 至 SIM-03 完成，单元模型网格收敛且资源日志已保存。
- **门 4｜可扩展整器件**：已有模型的功率平衡与边界收敛通过，SIM-04 明确工作站或集群路线。

未跨过相应决策门时，不把文献配方写成正式工艺卡，也不按猜测配置采购仿真设备。

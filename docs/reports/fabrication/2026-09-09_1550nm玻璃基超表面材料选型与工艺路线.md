## 0. 先给结论

1. **Si + HPFS 7980 作为第一主线。**依据不是笼统的“硅最好”，而是已有 1550 nm、a-Si:H 纳米柱、熔融石英衬底三项同时满足的直接实验；高折射率也有利于在有限厚度内实现完整相位控制。[E2]
2. **不能无条件写“Si 损耗很低”。**高质量 c-Si 在通信波段的线性吸收低；项目拟直接沉积的 a-Si:H，其消光系数 `k`、缺陷态、含氢量和应力由 PECVD 配方决定，必须用本机同炉见证片实测。
3. **Si₃N₄是长距离低损耗波导备选。**文献中的极低传播损耗依赖膜厚、模式约束、退火和专用制造工艺，不能直接作为本项目 300 nm 薄膜的预期值。[E4]
4. **TiO₂是低吸收透射型器件备选。**项目文献已经证明 C 波段共振和玻璃上的制造模块，但尚无一篇文献同时证明“TiO₂纳米结构 + 熔融石英 + 1550 nm高效率实验”。[E6][E7][E8][E10][E11]
5. **PMMA用于快速工艺闭环或作为Si₃N₄上的扰动层。**PMMA与熔融石英折射率过于接近，不宜作为裸玻璃上的主光学层。[E5][E9]
6. **自由空间Si/玻璃与波导馈电Si/玻璃要分开表述。**C2直接证明自由空间a-Si:H/熔融石英器件；A1证明波导馈电设计与PECVD a-Si工艺模块，但衬底是SOI。把两者组合到HPFS 7980属于本项目的工程迁移。[E2][E3]

## 1. 原材料表的准确改写

| 材料体系 | 1550 nm特点 | 玻璃上主要工艺 | 项目定位 |
| --- | --- | --- | --- |
| Si | a-Si文献模型中 `n=3.43`；高折射率使结构紧凑。高质量c-Si线性吸收低，但PECVD a-Si:H的 `k` 必须实测 | 项目拟采用PECVD a-Si:H + EBL + Al₂O₃硬掩模 + ICP-RIE；高质量单晶Si-on-glass通常需要键合或层转移等集成步骤 | **主路线（D）** |
| Si₃N₄ | 化学计量膜 `n≈2.0`；通信波段波导可实现低传播损耗，但损耗数字与结构和工艺绑定 | PECVD或LPCVD；可刻蚀Si₃N₄，也可像L01一样仅图形化上层PMMA | **低损耗波导备选（D）** |
| TiO₂ | 不同1550 nm模型分别采用 `n=2.05`、`n=2.40`；部分文献的 `2.55` 是有效折射率，不是同一薄膜的材料范围 | 反图形EBL+ALD填充，或厚膜蒸发+硬掩模+RIE；面积扩展可评估TiO₂复合树脂UV-NIL | **自由空间透射器件备选（D）** |
| PMMA | L01在1550 nm采用 `n≈1.48`；与熔融石英 `n≈1.44` 的折射率差约0.04，裸玻璃上约束很弱 | 旋涂+抗充电层+EBL+显影，可直接保留为最终结构 | **工艺标定或Si₃N₄上层扰动（D）** |

### 为什么不能直接写“低损耗、高效率”

- 复折射率写为 `ñ=n+ik`；`n` 控制相位和约束，`k` 表征材料吸收，吸收系数为 `α_abs=4πk/λ`。
- **传播损耗**以 dB/cm 表示，除了材料吸收，还包含侧壁散射、弯曲损耗、衬底泄漏和工艺缺陷。
- **透射率**是穿过器件的总功率比例；**聚焦效率**是进入规定焦区的功率比例；**衍射效率**是进入目标衍射级的比例。三者不能混用。
- 高 `n` 能提高相位积累和模式约束，但不自动保证高效率；高深宽比、粗糙度或阻抗失配可能抵消材料优势。

## 3. 逐页内容与汇报文稿

### 第1页｜材料选择不是“谁折射率最大”

#### 屏幕内容

标题建议：

> 1550 nm玻璃基超表面的材料选择：光学能力、损耗、工艺与证据

四个判断问题：

1. 能否提供完整 `0–2π` 相位控制？
2. 损耗指材料吸收、波导传播损耗，还是器件效率？
3. 能否迁移到 `L≤250 mm、t≥300 μm` 的玻璃基片？
4. 结论来自 `E1550`、`S1550`、`P` 还是 `D`？

#### 口头文稿

> 这一部分不把四种材料简单排成优劣顺序，因为高折射率、低损耗和高器件效率不是同一个概念。材料选择需要同时回答四个问题：第一，能不能在有限厚度内完成零到二π的相位控制；第二，损耗具体来自材料吸收、波导散射还是辐射过程；第三，工艺能不能迁移到我们的长条形薄玻璃上；第四，现有结论到底是1550纳米实验、仿真，还是其他波段的工艺参考。后续每个结论都会标明证据等级。

### 第2页｜HPFS 7980 0-AA：体材料等级不等于薄片完整规格

#### 屏幕内容

| 项目 | 7980 Standard 0-AA信息 | 对器件的意义 |
| --- | --- | --- |
| 项目尺寸 | `L≤250 mm`，`t≥300 μm` | 属于项目/供应商约束，不是0-AA等级定义 |
| “0”夹杂等级 | 夹杂物总截面积 `≤0.03 mm²/100 cm³`；规格统计忽略直径 `≤0.10 mm` 的夹杂 | 降低体散射热点和缺陷风险，但不等于完全没有微小夹杂 |
| “AA”均匀性 | 632.8 nm测试条件下，使用轴方向的相对折射率不均匀性 `Δn≤0.5 ppm` | 降低基底引入的波前误差；是整块光程平均量，不是300 μm薄片的局部分辨率图 |
| 应力双折射 | `≤5 nm/cm` | 减少偏振串扰，但不等于器件没有应力双折射 |
| 条纹 | ISO 10110-4 Class 5 | 约束体材料条纹，不替代表面面形 |
| OH含量 | 800–1000 ppm | 不能据此直接宣称1550 nm吸收；需透过率或损耗实测 |

采购/验收必须另外写明：

- 总厚度变化 TTV、翘曲 bow/warp、表面面形与粗糙度；
- 平行度或楔角，以及双面镀膜要求；
- 1550 nm折射率、透过率及批次证书；
- 0-AA母材批次追溯；手册中的直接均匀性测试厚度边界不能自动外推到300 μm薄片。

#### 两个与测量直接相关的估算

采用1550 nm处熔融石英相位折射率工程初值 `n≈1.444`、群折射率工程初值 `n_g≈1.463`：

```text
空气/玻璃单面菲涅耳反射：
R = ((n-1)/(n+1))² ≈ 3.3%

300 μm平行玻璃在近正入射下的自由光谱范围：
Δλ ≈ λ²/(2n_g t) ≈ 2.74 nm
```

以上为工程估算，不是Corning对1550 nm的保证值。约2.74 nm的条纹间隔还假定基片两面近似平行、近正入射，并且光源相干性和光谱仪分辨率足以观察条纹。产品手册中的7980折射率公式只声明至1128.95 nm；设计冻结前应取得供应商数据或实测。手册的材料属性表也没有把7980 Standard标为专用“IR transmittance”等级，因此不能只根据材料名称宣称C波段损耗已经获得供应商保证。[E1]

#### 口头文稿

> 我们选定的是Corning HPFS 7980标准级0-AA。这里的零和AA不能理解成尺寸或表面精度。零描述夹杂物等级，AA描述体材料折射率均匀性。它们能够降低散射热点和材料不均匀引起的波前误差，但不能代替薄片的总厚度变化、翘曲、表面粗糙度和面形要求。
>
> 项目的厚度条件是最薄可以做到300微米，也就是厚度下限，不是厚度上限。对于300微米薄片，应要求供应商提供母材批次和0-AA等级追溯，并单独验收薄片面形、TTV和翘曲。
>
> 在1550纳米处，我们可以先用1.444作为熔融石英相位折射率的工程初值，但Corning手册中的7980折射率公式只声明到1128.95纳米，所以不能把外推值写成采购保证。按相位折射率估算，空气到玻璃单面反射约3.3%；采用群折射率约1.463，300微米平行板在近正入射下的干涉条纹间隔约2.74纳米。测量窄带共振时必须使用空白参考片、轻微倾斜、楔角或减反射方案处理基片干涉。

### 第3页｜折射率影响结构尺寸，但不单独决定效率

#### 屏幕内容

| 材料 | 1550 nm参数依据 | 与玻璃的折射率差（工程估算） | 证据边界 |
| --- | ---: | ---: | --- |
| a-Si | `n=3.43` | 约1.99 | C2单元模型和器件实验；a-Si:H的`k`未给出 [E2] |
| Si₃N₄ | `n≈2.0` | 约0.56 | L01和Si₃N₄综述 [E4][E5] |
| TiO₂ | 不同模型为2.05或2.40 | 约0.61–0.96 | 不同论文输入，不能当成同炉薄膜范围 [E6] |
| PMMA | `n≈1.48` | 约0.04 | L01复合结构，不是裸玻璃强约束结构 [E5] |

Bayati在同一1550 nm仿真任务中的几何初值：[E6]

| 材料 | 周期 | 柱高 |
| --- | ---: | ---: |
| Si | 775 nm | 1240 nm |
| TiO₂ | 790.5 nm | 1317 nm |
| Si₃N₄ | 930 nm | 1550 nm |

这些尺寸只说明趋势，不是项目加工图纸；更换薄膜 `n、k`、基底、目标NA和相位实现方式后必须重新优化。

#### 口头文稿

> 折射率的实部n决定相位传播和模式约束，消光系数k决定材料吸收。因此只给出n不能证明材料低损耗。Bayati在1550纳米对多种材料做了统一条件下的数值比较，Si、TiO₂和Si₃N₄采用的柱高依次约为1.24、1.317和1.55微米。趋势说明折射率越低，通常需要更高或更大的结构才能获得足够的相位变化。
>
> 但同一论文也指出，在数值孔径低于约0.6并完成重新优化后，不同折射率材料可以得到接近的聚焦表现。所以Si的核心优势是结构紧凑和实现高NA的潜力，而不是不经优化就一定效率最高。

### 第4页｜Si + HPFS 7980主路线：直接证据、工程迁移与验证门

#### 屏幕内容A：最直接的器件证据

Arbabi 2015（C2）：[E2]

- 波长1550 nm，a-Si:H纳米柱，500 μm熔融石英衬底；
- 柱高940 nm、六角周期800 nm；
- 直径200–550 nm覆盖完整 `0–2π` 相位；
- 周期单元仿真透射率大于92%；
- 焦距500 μm的器件聚焦效率大于82%；
- 焦距50 μm的另一器件实现 `0.57λ` FWHM。

**82%和0.57λ来自不同器件，不能合并成一个性能指标。**文中聚焦效率的分子是进入焦平面半径 `3×FWHM` 圆孔内的功率，也不等同于总透过率。

#### 屏幕内容B：建议的第一轮工艺链

```text
HPFS来料检查
  ↓
同批小尺寸见证片/coupon
  ↓
PECVD沉积a-Si:H〔项目拟采用；C2未披露沉积方式〕
  ↓
椭偏测1450–1650 nm的n、k、膜厚；用独立透射/反射或波导损耗复核低损耗；测应力、翘曲、粗糙度
  ↓
ZEP520A + EBL
  ↓
约70 nm Al₂O₃蒸发 + lift-off形成硬掩模
  ↓
C₄F₈/SF₆ ICP-RIE刻蚀a-Si:H
  ↓
SEM/AFM：CD、侧壁角、深度、底部残留和粗糙度
  ↓
1550 nm：透射/反射/相位/效率/偏振测试
```

C2直接支持从ZEP、Al₂O₃硬掩模到C₄F₈/SF₆刻蚀的图形转移，但没有披露a-Si:H沉积设备；“采用PECVD直接沉积到HPFS”是项目拟验证的步骤。[E2]

扩展解释见[a-Si:H材料与1550 nm工艺说明](2026-09-09_a-SiH材料与1550nm工艺说明.md)和[EBL后硬掩模的作用与工艺顺序](2026-09-09_EBL后硬掩模的作用与工艺顺序.md)。

#### 波导馈电边界

Hsieh 2023（A1）证明：[E3]

- 220 nm SOI波导、50 nm SiO₂间隔层、500 nm PECVD a-Si柱；
- 柱位置控制采样相位，柱直径控制向上散射强度；
- 直径100–300 nm时，向上耦合强度从0.01变化到2.20 mm⁻¹；
- 柱直径同时会引入附加相位，作者通过微调柱位置进行二次相位补偿；
- 示例器件的设计目标向上耦合份额 `η_up` 为1%或2.5%，论文没有把它作为实测总效率。

A1证明波导馈电的设计方法和PECVD/硬掩模/ICP-RIE模块，但其衬底是SOI，不是熔融石英。它不能单独证明HPFS上的波导馈电器件已经成熟。

#### 口头文稿

> Si作为第一主线，最强依据不是一句硅工艺成熟，而是已经存在1550纳米、非晶硅纳米柱和熔融石英衬底三项同时满足的实验。Arbabi使用940纳米高的a-Si:H柱，在800纳米周期下通过改变200到550纳米的直径实现完整相位覆盖。
>
> 最高82%的聚焦效率和最小0.57倍波长焦斑来自两片不同焦距的器件，不能合并。作者把实测效率相对仿真的约10%差异归因为玻璃背面约3%的反射，以及粗糙纳米柱造成约7%的散射。这说明工艺控制重点应放在背面反射、刻蚀侧壁和粗糙度，而不仅是能否把图形刻出来。
>
> 材料上还要区分c-Si和a-Si:H。高质量c-Si在通信波段线性吸收低，但高光强下仍可能存在双光子吸收。项目拟直接沉积的是a-Si:H，其消光系数和应力取决于PECVD配方，必须实测，不能直接套用c-Si参数。
>
> 对波导馈电，A1提供了很好的相位—振幅联合设计和PECVD工艺模块，但它使用SOI，而且示例的设计目标向上耦合份额只有1%或2.5%，不是实测总效率。柱直径在改变散射强度的同时还会改变相位，因此作者需要再微调柱位置补偿。我们的第一轮实验应先复现Si/玻璃材料和刻蚀闭环，再单独建立同时记录相位与散射强度的波导馈电元胞库，而不是把两篇论文的性能直接拼成一个已经验证的器件。

### 第5页｜Si₃N₄：低损耗的优势必须带着几何条件讲

#### 屏幕内容

- 化学计量Si₃N₄：`n≈2.0`，透明窗口约400–4000 nm。[E4]
- 通信波段传播损耗示例：[E4]

| 波导条件 | 文献总结的传播损耗 | 代价/边界 |
| --- | ---: | --- |
| 小于400 nm、中等约束 | 约0.1–0.3 dB/cm | 侧壁粗糙度重叠较强 |
| 先进减法工艺 | 0.004 dB/cm @1550 nm | 专用沉积、刻蚀和退火 |
| TriPleX低约束 | 0.00034 dB/cm @1570 nm | 弯曲半径可达1 cm |

沉积权衡：[E4]

- LPCVD约800 °C，膜质量较高；化学计量膜超过约400 nm时要处理张应力、开裂和翘曲；
- PECVD热预算较低，但硅烷体系含氢和较低致密度可能增加通信波段吸收；
- 1000–1200 °C高温退火可减少Si–H、N–H、O–H相关吸收，因此“PECVD沉积温度低”不等于整个超低损耗流程都是低温。

L01的直接玻璃证据：[E5]

- 300 nm PMMA / 300 nm PECVD Si₃N₄ / 180 μm熔融石英；
- 工作在1550 nm附近；
- 只图形化PMMA，Si₃N₄保持连续膜，因此没有Si₃N₄刻蚀侧壁；
- 论文样片180 μm厚度不满足本项目 `t≥300 μm`，只能证明物理和工艺概念。

效率边界：[E5]

- 补充材料S.11中的99%是1 mm长理想化数值设计，需要 `Q_min≈625`；
- 补充材料数值分析指出，正文低折射率对比系统的最低可实现Q在 `10⁴–10⁵`量级，同尺寸示例效率约1%；
- 高Q表示谱线窄、储能时间长，不自动意味着高出光效率。

#### 口头文稿

> Si₃N₄的优势主要体现在波导传播损耗，而不是高折射率。必须防止把文献中的记录值直接写成本项目的预期值。例如0.00034 dB每厘米来自低约束TriPleX结构，其弯曲半径可能达到厘米量级，并不适合所有紧凑超表面。
>
> L01给出了更贴近项目的1550纳米玻璃结构：300纳米PMMA、300纳米PECVD Si₃N₄和180微米熔融石英。这里Si₃N₄保持为连续膜，真正曝光的是PMMA，因此避开了Si₃N₄刻蚀和侧壁散射。它是一条工艺很短的波导漏波路线，但180微米只是论文样片参数，不应覆盖项目300微米厚度下限。
>
> L01补充材料中的99%和约1%都是数值设计或作者估计，不是样品的绝对效率实测。正文所用低折射率对比系统耦合较弱，大部分功率会继续留在导模中。因此如果项目优先长距离传播，Si₃N₄很合适；如果优先在短口径内强出光，就需要更强扰动或更长辐射口径。

### 第6页｜TiO₂：材料潜力成立，但C波段玻璃实验证据尚未闭环

#### 屏幕内容

证据分层：

- `S1550`：Bayati采用 `n=2.4`、柱高1317 nm；没有制造TiO₂器件。[E6]
- 其他1550 nm模型采用 `n=2.05`；部分文献的 `n_eff≈2.55` 是结构有效折射率，不能作为同一薄膜的材料范围。[E10]
- `E1550`：Fathi 2026在1567 nm测得GMR，`Q≈1125`；衬底为MQW/蓝宝石混合体系，不是熔融石英。[E7]
- `P`：Devlin在熔融石英上完成反图形EBL+ALD填充，非晶TiO₂ RMS粗糙度约0.738 nm；78%–82%效率来自可见光，不能标为1550 nm性能。[E8]

#### 三条路线不是一条串联流程

| 路线 | 基本流程 | 适用性与风险 |
| --- | --- | --- |
| 反图形EBL+ALD填充 | 正胶ZEP-520A曝光反图形并形成牺牲模 → 低温ALD填充 → Cl₂/BCl₃回刻 → 去胶 | 保形性和表面质量好；面对约1.3 μm高柱时沉积时间、厚胶稳定性和去胶需验证 |
| 厚膜蒸发+直接刻蚀 | 蒸发TiO₂ → EBL → Cr硬掩模 → 氟基RIE | 可形成微米级厚膜；应力、化学计量、侧壁和HPFS附着需重测 [E11] |
| TiO₂复合树脂UV-NIL | 模具压印 → UV固化 → 脱模 | 适合面积扩展；折射率低于致密TiO₂，并有收缩、残余层和批次波动 [E11] |

#### 口头文稿

> TiO₂的2.05到2.55不能作为一个固定材料范围使用。2.05和2.40来自不同仿真输入，2.55还可能是纳米柱模式的有效折射率。设计前必须对同炉见证片测量1500到1600纳米的n和k。
>
> 当前项目文献中，TiO₂的1550纳米高透射和高聚焦效率主要是数值结果。Fathi在1567纳米测得Q约1125的导模共振，证明TiO₂可以在C波段形成窄带共振，但衬底是量子阱和蓝宝石，不能代替TiO₂/HPFS验证。
>
> 玻璃上已经有反图形EBL加ALD填充等成熟模块，但对应效率实验主要在可见光。因此TiO₂应定位为低吸收透射型自由空间器件的备选；传播相位或消色差器件可以宽带，而GMR或qBIC仍然是窄带，不能把材料透明窗口宽等同于器件带宽宽。

### 第7页｜PMMA：价值在于缩短工艺闭环

#### 屏幕内容

L01的1550 nm直接证据：[E5]

- `n(PMMA)≈1.48`、`n(Si₃N₄)≈2.00`、`n(SiO₂)≈1.44`；
- 300 nm PMMA / 300 nm Si₃N₄ / 熔融石英；
- 100 keV、1 nA、750 μC/cm² EBL；
- BEAMER邻近效应修正；IPA:去离子水=3:1显影；
- PMMA保留为最终波导边界和扰动结构，不刻蚀Si₃N₄。

项目用途：

- EBL剂量和邻近效应校准；
- 玻璃充电与导电层验证；
- 线宽、孔径、拼接和均匀性验证；
- 作为Si₃N₄上层低折射率扰动；
- 不作为裸HPFS上的1550 nm主超表面。

Hirler 2026的全聚合物器件使用悬空300 nm PMMA膜，实测Q最高523；通过横向缩放，实测qBIC共振由551 nm调到838 nm，但没有1550 nm演示。悬空设计也不能作为PMMA直接贴玻璃的证据。[E9]

#### 口头文稿

> PMMA的优势是工艺短，而不是光学约束强。PMMA在L01中的折射率约1.48，熔融石英约1.44，折射率差只有约0.04，很难在裸玻璃上支撑强约束、高散射效率的独立纳米柱模式。
>
> L01能够工作，是因为PMMA下方还有折射率约2.0的连续Si₃N₄膜。PMMA负责定义边界和周期扰动，主要导模能量仍由Si₃N₄承载。因此应把它称为PMMA图案/Si₃N₄连续膜/玻璃复合平台。
>
> PMMA在项目中的最佳用途，是快速建立曝光、显影、抗充电和尺寸控制能力，或者作为Si₃N₄上的最终扰动层，而不是独立承担1550纳米主光学功能。

### 第8页｜项目决策与第一轮实验闭环

#### 屏幕内容

```text
第一主线：HPFS 7980 + PECVD a-Si:H + EBL + Al₂O₃硬掩模 + ICP-RIE
          │
          ├─ a-Si:H的k、应力或均匀性不达标
          │      → 优化PECVD，或转Si₃N₄
          │
          ├─ 深刻蚀侧壁/粗糙度不达标
          │      → 降低结构高度并重优化，或评估TiO₂反填充
          │
          ├─ 器件核心转为长距离低损耗传播
          │      → Si₃N₄优先
          │
          └─ 仅需快速验证曝光和图案
                 → PMMA或PMMA/Si₃N₄
```

#### 实验关口

| 阶段 | 必测量 | 本阶段回答的问题 |
| --- | --- | --- |
| 玻璃来料 | 尺寸、TTV、翘曲、面形、粗糙度、双折射、1550 nm透过率 | 0-AA母材质量能否转化为合格薄片？ |
| 连续薄膜 | 椭偏拟合1450–1650 nm的`n、k`、膜厚分布、应力、AFM粗糙度、附着力；另做透射/反射或波导损耗验证 | 本机a-Si:H是否具备进入图形化的条件？椭偏拟合`k≈0`是否只是触及检测下限？ |
| 刻蚀DOE | 刻蚀速率、掩模选择比、CD偏差、侧壁角、残留、粗糙度 | 可制造元胞范围在哪里？ |
| 周期元胞 | 透射/反射、共振位置、相位或散射强度 | 实际材料和几何是否与仿真一致？ |
| 完整器件 | 效率、带宽、焦斑/远场、偏振和角度敏感性 | 是否达到进入尺寸放大的性能门？ |
| 250 mm适配 | 设备载台、载片方式、膜厚均匀性、应力翘曲、曝光拼接 | coupon工艺能否迁移到最终长度？ |

具体膜厚、CD和侧壁角公差不在没有灵敏度分析时凭经验填写。应先将实测 `n、k` 带回RCWA/FDTD模型，扫描几何误差，再由允许的效率下降、相位误差和共振漂移反推出制造公差。

#### 收尾文稿

> 综合现有证据，Si的优势是折射率高、结构紧凑，而且已有1550纳米a-Si:H加熔融石英的直接实验，因此适合作为第一主线。这个选择并不意味着我们已经证明本机PECVD a-Si:H低损耗；真正的项目结论要由同炉见证片的n、k、膜厚、应力和粗糙度建立。
>
> Si₃N₄适合传播距离较长、波导损耗优先的方案；TiO₂适合低吸收透射型自由空间器件，但仍缺少HPFS上的C波段直接实验；PMMA主要承担工艺标定和低折射率扰动层功能。
>
> 第一阶段不直接加工250毫米长的最终样品，而是先使用同批HPFS小尺寸见证片，依次完成薄膜、刻蚀、元胞和器件验证。通过这些关口后，再进入长基片的设备夹持、膜厚均匀性、应力和曝光拼接验证。

## 4. 专业术语表

| 术语 | 汇报中的简明解释 |
| --- | --- |
| `n` | 折射率实部，决定相位积累、波长压缩和模式约束。必须注明波长和薄膜制备条件。 |
| `k` | 消光系数，描述材料吸收；`α_abs=4πk/λ`。仿真设`k=0`只表示忽略吸收。 |
| `n_eff` | 波导或纳米结构模式感受到的有效折射率，不一定等于块体材料折射率。 |
| 线性吸收 | 单光子、功率近似成正比的吸收过程。通信波段高质量c-Si的线性吸收低。 |
| 双光子吸收（TPA） | 高光强下两个光子同时被吸收的非线性过程；1550 nm的Si仍可能发生。 |
| 高折射率反差 | 纳米结构与周围介质之间较大的折射率差，有利于模式约束和短距离相位积累。 |
| Meta-atom | 构成超表面的单个亚波长结构，例如Si纳米柱。 |
| `0–2π`相位覆盖 | 元胞库能够提供完整一个光学相位周期，是任意波前整形的基础。 |
| 传播损耗 | 单位通常为dB/cm，包括材料吸收、散射、弯曲和衬底泄漏。 |
| 聚焦/衍射效率 | 进入规定焦区或目标衍射级的功率比例；必须说明分母和积分区域。 |
| PECVD | 等离子体增强化学气相沉积；温度较低，但含氢量、膜密度、应力和损耗需验证。 |
| LPCVD | 低压化学气相沉积；膜质量通常较高，但温度高，厚膜应力较大。 |
| ALD | 原子层沉积；逐层、自限反应，保形性好但厚膜沉积慢。 |
| EBL | 电子束曝光；分辨率高但串行写入，绝缘玻璃通常需要抗充电处理。 |
| PEC | 邻近效应修正；补偿电子在胶和衬底中的散射造成的局部剂量偏差。 |
| NIL | 纳米压印；通过母模并行复制结构，适合面积扩展，但需控制残余层和缺陷。 |
| 硬掩模 | 位于光刻胶和目标薄膜之间的耐刻蚀层，例如Al₂O₃或Cr。 |
| Lift-off | 先沉积掩模材料，再溶解底部光刻胶，使非目标区域材料一同剥离。 |
| ICP-RIE | 高密度反应离子刻蚀；通过离子方向性和化学反应获得深而较垂直的侧壁。 |
| 深宽比 | 结构高度与最小横向尺寸之比；越高越难刻蚀、填充、去胶和干燥。 |
| GMR | 导模共振；周期结构把自由空间光耦合进可泄漏导模，通常产生窄带响应。 |
| BIC/qBIC | BIC是不向自由空间辐射的束缚态；小幅破坏对称性后成为可激发的qBIC。 |
| Q因子 | 近似为`Q=λ₀/Δλ`；Q越高谱线越窄，但耦合过弱时不一定有高出光效率。 |
| NA | 数值孔径，`NA=n sinθ`；NA越高通常焦斑越小，制造和采样要求越高。 |
| FWHM | 光强降到峰值一半处的光斑全宽，用于描述焦斑或谱线宽度。 |
| TTV | Total Thickness Variation，整片最大厚度和最小厚度之差。 |
| Fabry–Pérot条纹 | 两个近似平行表面之间的多次反射形成的周期性光谱起伏。 |

## 5. 答辩时最可能被追问的问题

### Q1：既然Si₃N₄和TiO₂损耗更低，为什么仍选Si？

> “低损耗”要对应具体指标。Si₃N₄的优势是长距离波导传播；TiO₂具有低吸收潜力，但项目库尚缺TiO₂/熔融石英/1550 nm高效率直接实验。Si已有直接C波段玻璃器件证据，并能以更紧凑结构实现完整相位。因此先选Si建立器件和工艺闭环，同时把实际a-Si:H的`k`作为第一道淘汰门。

### Q2：为什么不直接采用c-Si？

> c-Si在通信波段材料性能好，但它不能像a-Si:H一样简单地低温直接沉积到熔融石英。直接Si-on-glass通常涉及键合、层转移或特殊结晶过程。第一轮优先PECVD a-Si:H是为了降低集成复杂度，不代表a-Si:H的损耗已经默认合格。

### Q3：L01已经用了180 μm玻璃，为什么本项目300 μm还要重新验证？

> 180 μm证明的是该论文结构的物理和实验可行性；本项目的300 μm是几何下限。厚度改变会改变基片Fabry–Pérot条纹、机械刚度、端面处理和夹持方式，且HPFS 7980 0-AA也不是L01明确声明的玻璃等级，所以不能直接继承。

### Q4：TiO₂不是公认的低损耗材料吗？

> 材料方向上可以说“具有低吸收潜力”，但器件结论必须落到同炉薄膜的`n、k`以及目标衬底和波段。当前证据分别证明了1550 nm仿真、1567 nm非玻璃衬底实验和玻璃上的可见光制造，三部分尚未在同一个器件中闭环。

### Q5：为什么不直接在250 mm长玻璃上做第一片？

> 文献没有直接证明该长度上的PECVD均匀性、薄膜应力、载台兼容性和EBL拼接。先用同批coupon建立材料和刻蚀窗口，能够把材料失效、图形失效和尺寸放大失效分开，避免一次大样失败后无法定位原因。

## 7. 汇报前检查清单

- [ ] 所有“低损耗”后面注明是材料吸收、传播损耗还是器件效率。
- [ ] 所有效率注明仿真/实测、波长、衬底和效率定义。
- [ ] 不把C2的82%效率和0.57λ焦斑说成同一器件结果。
- [ ] 不把L01理想化99%设计说成样品实测效率。
- [ ] 不把TiO₂的2.05–2.55说成同一薄膜在1550 nm的实测范围。
- [ ] 不用Hirler 2026支持PMMA在1550 nm的性能。
- [ ] 明确L01的180 μm是论文参数，本项目要求为`t≥300 μm`。
- [ ] 明确0-AA不包括TTV、面形、粗糙度和1550 nm透过率的完整薄片保证。
- [ ] 明确Si为阶段性主路线，PECVD a-Si:H的`n、k`和应力仍是第一轮验证项。

# a-Si:H 材料与 1550 nm 工艺说明

> 用途：解释项目主路线中的 `a-Si:H` 是什么、氢的作用、为什么适合玻璃衬底，以及应如何建立损耗和工艺验收依据。本文是[1550 nm玻璃基材料汇报稿](2026-09-09_1550nm玻璃基超表面材料选型与工艺路线.md)的技术附录。

## 1. 一句话结论

`a-Si:H` 是**氢化非晶硅**：用非晶结构换取低温、异质衬底直接沉积能力，再利用氢降低无序硅网络中的部分缺陷和亚带隙吸收。它兼具较高折射率与玻璃工艺兼容性，但其1550 nm损耗、应力和热稳定性取决于沉积配方，不能直接继承SOI中c-Si的数据。

## 2. 名称和符号

| 符号 | 含义 | 不能误解为 |
| --- | --- | --- |
| `a-` | amorphous，原子没有形成长程周期晶格 | 多晶硅或低质量单晶硅 |
| `Si` | 薄膜主体为Si原子网络 | SiO₂、Si₃N₄等硅化合物 |
| `:H` | hydrogenated，生长时有氢进入薄膜并参与缺陷钝化 | 固定化学计量比的“SiH”或常规电学掺杂 |

冒号表示薄膜含氢量可随工艺变化。若没有另外加入B、P等掺杂源，氢主要承担结构/缺陷钝化作用，而不是用来提供自由电子或空穴。

## 3. c-Si、a-Si和a-Si:H的区别

| 材料 | 微观结构 | 优点 | 项目中的主要限制 |
| --- | --- | --- | --- |
| c-Si | 长程有序晶体，每个Si原子理想情况下四配位 | 通信波段线性吸收低、材料参数稳定 | 高质量单晶Si-on-glass通常需要键合、层转移或其他结晶/异质集成步骤 |
| a-Si | 无长程有序晶格 | 可在玻璃等异质衬底上低温沉积 | 悬挂键、受应变Si—Si键和无序结构会产生亚带隙吸收 |
| a-Si:H | 含氢的无序Si网络 | 保留低温沉积能力，同时降低部分缺陷吸收 | `n、k`、密度、含氢量、应力和稳定性由沉积配方与热历史决定 |

## 4. 氢起什么作用

非晶网络容易出现未完全成键的Si原子，即**悬挂键（dangling bond）**：

```text
未钝化：Si—Si—Si•
                ↑ 悬挂键

氢钝化：Si—Si—Si—H
```

传统解释是：H与未配位Si形成Si—H键，减少禁带内缺陷态，从而降低亚带隙吸收。更严格地说，氢还可能在薄膜生长过程中促进局部原子重排、减少受应变Si—Si键。因此，低吸收并不只由“悬挂键数量”决定。

氢并非越多越好。过量氢或不合适的等离子体条件可能伴随：

- Si—H₂等键合状态增多；
- 微空洞和薄膜密度下降；
- 折射率下降；
- 热处理时氢逸出；
- 薄膜应力、界面和长期稳定性变化。

所以项目需要控制的是“可重复的低缺陷网络”，不是单独追求最高含氢量。

## 5. 为什么适合玻璃衬底

> **术语口径**：本文说的"玻璃/熔融石英"特指 **Corning HPFS 7980 一类合成熔融石英**（非晶 SiO₂），**不是**泛指的 "SiO₂"——不要与 SOI 的**热氧化 BOX**、**石英单晶**、**普通/显示玻璃**混谈。完整对照见 [熔融石英 ≠ 泛指的 SiO₂](2026-09-11_熔融石英与SiO2术语差别.md)。

熔融石英没有单晶晶格，不能为Si外延提供晶格模板。a-Si:H不要求晶格匹配，可通过PECVD等方法直接沉积到玻璃、SiO₂或已加工介质层上。

已有实验以SiH₄为前驱体，在250 ℃通过PECVD把a-Si:H直接沉积到玻璃上，说明“低温沉积到异质玻璃”是可行工艺模块；但该实验工作在可见光，不能作为本项目1550 nm损耗值。[Park等，Scientific Reports 2017](https://doi.org/10.1038/s41598-017-02911-w)

项目必须进一步验证：

- PECVD载台是否接受**直径不超过 250 mm、厚度不小于 300 μm 的玻璃晶圆**（早期文档写作"矩形玻璃/长度"，实指**晶圆直径**；常规规格 D100/D150/D200/D300）；
- 是否需要临时载片或边缘夹持；
- 长方向膜厚与折射率是否均匀；
- 薄膜应力是否造成bow/warp；
- a-Si:H与HPFS 7980的附着力和热循环稳定性。

“能沉积到玻璃”不能直接推导为“能在最终尺寸HPFS上均匀低损耗沉积”。

## 6. PECVD如何形成a-Si:H

典型PECVD使用SiH₄，并可能加入H₂、He或Ar：

```text
SiH₄进入腔体
   ↓
RF等离子体生成SiHₓ自由基和活性氢
   ↓
自由基在玻璃表面吸附、扩散和反应
   ↓
形成无序Si—Si网络
   ↓
部分氢以Si—H等形式保留在薄膜中
```

关键变量及其影响：

| 工艺变量 | 可能影响的材料量 |
| --- | --- |
| 基片温度 | 表面迁移、含氢量、密度、应力和氢逸出风险 |
| SiH₄/H₂或载气比例 | 沉积速率、氢参与程度、非晶/纳米晶边界 |
| 腔体压力 | 自由基输运、均匀性和膜密度 |
| RF功率/偏压 | 前驱体分解、离子轰击、缺陷和应力 |
| 电极间距与载台结构 | 直径方向（≤250 mm）的厚度与材料均匀性 |
| 后续热历史 | Si—H稳定性、折射率、应力和吸收变化 |

SiH₄是自燃性危险气体，只能在具有气柜、泄漏检测、尾气处理和联锁系统的专用设备中使用。

## 7. 1550 nm下为什么“可能低损耗”，但不能默认低损耗

1550 nm光子的能量约为：

```text
E = hc/λ ≈ 1.24/1.55 ≈ 0.80 eV
```

该能量低于硅的基本带隙，因此理想材料中的普通带间吸收受到抑制；氢化又可以减少部分亚带隙缺陷态。但实际薄膜仍可能存在：

- 悬挂键和深能级缺陷吸收；
- 无序结构和受应变Si—Si键引起的亚带隙吸收；
- 微空洞、密度不足和界面态；
- 纳米柱侧壁与顶部粗糙散射；
- 高光强下的非线性吸收；
- 热处理或包层变化引起的表面钝化退化。

一项1550 nm a-Si:H线波导实验测得TE模传播损耗 `2.7±0.1 dB/cm`，并发现其特定结构在高于约350 ℃退火后透明度快速下降；这说明损耗与热历史、界面和钝化状态有关，而不是一个材料常数。[Zhu等，Optics Express 2012](https://doi.org/10.1364/OE.20.023676)

另一项HWCVD研究获得约 `0.8 dB/cm` 的1550 nm波导传播损耗。它采用的不是PECVD，也不是本项目纳米柱，因此只能用来说明“不同沉积路线可以得到显著不同的传播损耗”。[HWCVD低损耗a-Si:H波导](https://eprints.soton.ac.uk/427414/2/PR_331501_AUTHOR_1.pdf)

Molina-Ruiz等在磁控溅射a-Si:H中测得1550 nm四分之一波厚度薄膜最低吸收 `5.8 ppm`，对应吸收系数 `0.42 cm⁻¹`（室温生长、工作气10% H₂、后氢化状态）。这项结果支持“优化a-Si:H可以获得很低的1550 nm材料吸收”，同时也显示氢比例和热处理存在最优窗口，并非氢越多越好。由于沉积方法是磁控溅射、样品是镜膜而非PECVD纳米柱，该数值只作材料机制与量级依据，不作为本项目验收值。[E1阅读笔记](../../../literature/材料体系分类/Si/1550波段/阅读笔记_E1_Molina_Ruiz_2025.md)；[DOI](https://doi.org/10.1103/5n1c-tjhq)

## 8. `n`和`k`分别控制什么

复折射率为：

```text
ñ = n + ik
```

- `n`：决定相位积累、波长压缩和模式约束；
- `k`：消光系数，表征材料吸收；
- 吸收系数：`α_abs=4πk/λ`；
- 只知道`n≈3.43`不能证明薄膜低损耗。

以波长1550 nm、厚度940 nm的均匀a-Si:H为例，只计算单程材料吸收，不含反射、散射和共振增强：

| `k` | `α_abs` | 通过940 nm后的吸收 |
| ---: | ---: | ---: |
| `1×10⁻⁴` | 约8.1 cm⁻¹ | 约0.076% |
| `1×10⁻³` | 约81 cm⁻¹ | 约0.76% |
| `1×10⁻²` | 约811 cm⁻¹ | 约7.3% |

若将940 nm均匀薄膜的单程材料吸收预算设为1%，粗略要求：

```text
k ≤ -ln(0.99)λ/(4πh) ≈ 1.3×10⁻³
```

若吸收预算为0.1%，则约需 `k≤1.3×10⁻⁴`。真实超表面中的共振和场增强可能使等效光程增加，所以最终`k`上限应由器件仿真反推。

## 9. 高折射率对1550 nm超表面的直接价值

Arbabi 2015在1550 nm采用a-Si模型折射率 `n=3.43`。940 nm高、800 nm周期的纳米柱通过200–550 nm直径扫描覆盖完整 `0–2π`透射相位，周期元胞仿真透射率大于92%。最高82%聚焦效率与最小 `0.57λ`焦斑来自不同透镜，不能合并成一个器件指标。[项目C2 PDF](../../../literature/材料体系分类/Si/1550波段/pdfs/C2_Arbabi_2015_High_Contrast_Transmitarray_Lens.pdf)；[DOI](https://doi.org/10.1038/ncomms8069)

相位积累可粗略理解为：

```text
φ ≈ (2π/λ)n_eff h
δφ ≈ (2π/λ)(n_eff δh + h δn_eff)
```

高`n_eff`有利于在有限高度内得到大相位变化；膜厚和折射率沿**直径方向（≤250 mm）**的波动则会转化为相位误差。实际纳米柱还包含界面、多模和共振效应，最终尺寸必须用RCWA/FDTD重建元胞库，不能仅按上述近似式计算。

## 10. 自由空间证据与波导馈电证据要分开

- C2直接证明：a-Si:H/熔融石英/1550 nm自由空间透射器件可行。[C2阅读笔记](../../../literature/材料体系分类/Si/1550波段/阅读笔记_C2_Arbabi_2015.md)
- Hsieh 2023证明：PECVD a-Si纳米柱可以在SOI波导上实施相位—振幅联合控制，但其衬底是SOI，示例设计目标向上耦合份额为1%或2.5%，不是HPFS器件的实测总效率。[项目A1 PDF](../../../literature/材料体系分类/Si/1550波段/pdfs/A1_Hsieh_2023_Waveguide_Phase_Amplitude_Control.pdf)；[DOI](https://doi.org/10.1364/OE.487589)

因此，“PECVD a-Si:H波导超表面直接集成到HPFS 7980”是由相邻证据支持的项目工程路线，仍需本项目实验闭环。

## 11. 项目工艺链与每一步的目的

```text
HPFS 7980来料验收
   ↓  排除TTV、面形、翘曲和透过率问题
同批见证片/coupon
   ↓  避免第一轮直接消耗最终尺寸（直径 ≤250 mm）的晶圆
PECVD沉积a-Si:H
   ↓
椭偏n、k、膜厚 + 独立透射/反射或波导损耗
   ↓  防止把椭偏检测下限误当成k=0
应力、翘曲、AFM粗糙度、附着力和热历史复测
   ↓
ZEP520A + EBL
   ↓
Al₂O₃ lift-off硬掩模
   ↓
ICP-RIE刻蚀a-Si:H
   ↓
按工艺要求去除残余硬掩模，或把残余层纳入光学模型
   ↓
SEM/AFM + 1550 nm光学测试
```

EBL不需要曝光掩膜版，但深刻蚀仍可能需要样品表面的硬掩模，详见[EBL后硬掩模的作用与工艺顺序](2026-09-09_EBL后硬掩模的作用与工艺顺序.md)。

## 12. 第一轮测量清单

| 测量 | 目的 | 解释边界 |
| --- | --- | --- |
| 1450–1650 nm椭偏 | 拟合`n、k`与膜厚 | 极小`k`可能触及检测下限 |
| 独立透射/反射 | 复核薄膜吸收与界面反射 | 需要空白HPFS参考片 |
| 波导cut-back或谐振器 | 测包含吸收和散射的传播损耗 | 与纳米柱器件效率不是同一指标 |
| FTIR | 分析Si—H等键合状态 | 含氢量不能单独代表低损耗 |
| Raman | 检查非晶网络及是否出现纳米晶化 | 需与工艺基线样品对照 |
| AFM | 测连续膜表面粗糙度 | 不替代刻蚀后侧壁检查 |
| 截面SEM | 测柱高、CD、侧壁角和底部残留 | 需做片内多位置统计 |
| 应力/翘曲 | 判断长薄玻璃的承载和图形稳定性 | 薄膜应力与基片厚度共同作用 |
| 热历史前后复测 | 检查烘烤、掩模沉积和刻蚀后的漂移 | 不只检查as-deposited薄膜 |

## 13. 可直接用于汇报的文稿

> 这里的a-Si:H读作氢化非晶硅。a表示硅原子没有形成长程有序晶格，冒号H表示薄膜中引入了氢，但它不是固定比例的硅氢化合物，也不是传统意义上的电学掺杂。
>
> 与晶体硅相比，非晶硅可以通过PECVD在较低温度下直接沉积到熔融石英上，因此不需要晶格匹配或先完成单晶层转移。但是无序硅网络中存在悬挂键和受应变的Si—Si键，它们会形成亚带隙缺陷态。氢的主要作用是钝化部分缺陷并改善局部网络结构，从而降低近红外吸收。
>
> 选择a-Si:H的第二个原因是折射率高。Arbabi在1550纳米设计中采用3.43的折射率，使用940纳米高的纳米柱，通过改变200到550纳米的直径覆盖完整零到二π相位。这为Si加熔融石英提供了直接器件依据。
>
> 但a-Si:H不能简单写成低损耗硅。它的消光系数、含氢状态、密度和应力都取决于PECVD温度、气体比例、压力、功率和后续热历史。不同文献中的传播损耗有明显差异，椭偏拟合的k接近零也可能只是达到检测下限。
>
> 因此，本项目选择a-Si:H的准确表述是：它兼具高折射率和低温玻璃兼容性，是当前最有直接证据的主路线；但其1550纳米低损耗不是预设结论，而是第一轮见证片必须通过n、k、透射、应力、粗糙度和刻蚀后光学测试建立的工艺结果。

## 14. 术语速查

| 术语 | 含义 |
| --- | --- |
| 悬挂键 | 未完成正常四配位的Si键，会形成缺陷电子态 |
| 钝化 | 通过化学成键降低缺陷态活性，例如形成Si—H键 |
| 亚带隙吸收 | 光子能量低于理想带隙时，由缺陷或无序态引起的吸收 |
| 消光系数`k` | 复折射率虚部，决定材料吸收 |
| PECVD | 等离子体增强化学气相沉积，适合较低温度异质衬底沉积 |
| 热历史 | 薄膜经历的沉积、烘烤、退火和等离子体温度过程 |
| cut-back | 制作不同长度波导，用插入损耗对长度的斜率提取传播损耗 |
| 见证片 | 与正式样品同炉加工、专门用于材料和工艺测量的小样 |

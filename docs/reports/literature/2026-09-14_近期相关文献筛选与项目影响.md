# 近期相关文献筛选与项目影响（截至 2026-09-14）

> 更新（2026-09-14，近期文献补充）：按 DOI 去重后补入 Q1-13 至 Q1-16；只把全文可核验、能改变当前设计/工艺决策的工作纳入规范文献库。

## 1. 检索范围与筛选规则

- 时间重点：2024–2026；早期论文仅用于查重，不在本轮扩容。
- 主题：waveguide metasurface、guided-wave radiation、qBIC/nonlocal metasurface、Jones matrix、PMMA/EBL anti-charging、Si/SiN/TiO₂、1550 nm 与 fabrication tolerance。
- 来源优先级：出版社开放全文或作者公开版；只看摘要而无法核对方法的论文不入选。
- 入选要求：至少补齐一个项目缺口，并能落到设计变量、仿真验收量或加工咨询问题。
- 去重依据：DOI 为主，标题和作者为辅；同一论文不因跨材料/跨主题而复制 PDF 或笔记。

## 2. 本轮入选

### Q1-13｜全参量 Jones 矩阵片上超表面

- Ji et al., *Nature Communications* 15, 8271 (2024), DOI: [10.1038/s41467-024-52476-2](https://doi.org/10.1038/s41467-024-52476-2)。
- 补足缺口：1550 nm、实验、四个复数 Jones 分量、方向复用。
- 项目动作：`case_002` 的单元库由“相位/效率”扩展为 `Jxx/Jxy/Jyx/Jyy + efficiency + crosstalk`。
- 边界：LNOI + a-Si，不是 HPFS + a-Si:H；几何不可直接移植。

### Q1-14｜片上非局域 qBIC 光谱路由

- Shi et al., *Light: Science & Applications* 15, 66 (2026), DOI: [10.1038/s41377-025-02146-9](https://doi.org/10.1038/s41377-025-02146-9)。
- 补足缺口：用缩放因子调波长、用倾斜角调辐射强度，并以级联像素管理多波长功率。
- 项目动作：为器件级模型增加逐段剩余导模功率与“绝对提取效率/能量利用效率”分离记账。
- 边界：可见光实验；论文报告的三色能量利用效率约 0.62，不等于绝对提取效率，单器件绝对提取仍低于约 7%。

### Q1-15｜介电常数不对称 qBIC 与 E-Spacer 300Z

- Yang et al., *Nanophotonics* 14(27), 5311–5321 (2025), DOI: [10.1515/nanoph-2025-0415](https://doi.org/10.1515/nanoph-2025-0415)。
- 补足缺口：给出 fused silica 上 `PMMA 950k A4 + E-Spacer 300Z + EBL + Cr hard mask + ICP-RIE` 的明确流程，并用选择性 PMMA 覆盖调 qBIC。
- 项目动作：加工咨询必须区分“曝光辅助 conductive polymer”和“最终结构 PMMA”；增加去除、污染、剂量漂移及多层 overlay 问题。
- 边界：本地 PDF 为 arXiv 作者版；`Q > 10^7` 是 restored-BIC 理想模拟，不是实验结果。

### Q1-16｜1550 nm 全介质 meta-waveguide

- Wang et al., *npj Nanophotonics* 2, 20 (2025), DOI: [10.1038/s44310-025-00069-2](https://doi.org/10.1038/s44310-025-00069-2)。
- 补足缺口：1550 nm Si-on-Si₃N₄ 片上模式控制与明确的 ±10 nm 容差扫描。
- 项目动作：COMSOL/FDTD 设备需求要支持多模端口、模式分解、参数扫描和网格收敛；首轮容差范围可从 ±10 nm 起步。
- 边界：全文为 numerical demonstration，没有加工样品；97% 反射率和 Q 值不能当作本项目实测预期。

## 3. 已检索但未重复收录

- Watanabe et al., 2025，低折射率对比超高 Q BIC，DOI `10.1021/acs.nanolett.4c05880`：已是 `Si-1550:B2`，并与 `SiN-1550:B5` 交叉索引。

两篇均保留原规范笔记，不另建 Q1 编号。这样避免“近期论文”与既有材料专题形成重复条目。

## 4. 对近期工作的优先级影响

1. **先补仿真输出定义**：Jones matrix、多模功率、绝对提取效率、剩余导模功率、串扰、Q 与容差必须分栏记录。
2. **再做单元与短阵列**：Q1-13 的四柱超胞和 Q1-14 的双参数 qBIC 都先做小规模收敛测试，不直接上完整器件。
3. **把 EBL 防充电问具体**：以 Q1-15 的 E-Spacer 300Z 流程为案例，要求加工方给出可用商品、涂覆/去除步骤、接地策略和剂量校准。
4. **设备需求用算例表达**：以 Q1-16 为基准，要求多模 port、mode overlap、±10 nm 参数扫描和至少两档网格收敛，而不是只问“能否做 COMSOL”。

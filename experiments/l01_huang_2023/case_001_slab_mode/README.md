# case_001：波导堆叠的导模分析（TM₀ / TE₀ 有效折射率）

## 目标

计算主论文（L01）波导堆叠——空气 / PMMA 300 nm / Si₃N₄ 300 nm / SiO₂——在 λ₀ = 1.55 μm 下的导模有效折射率，作为后续超表面元胞设计的模式基线。

## 方法

1D 多层平板波导传输矩阵法（自写 Python，见 `scripts\slab_mode_solver.py`）。对 TE 与 TM 分别求解色散方程（边界为上下包层衰减场），用二分法求根。

## 结果（λ₀ = 1.55 μm，材料取固定折射率）

| 模式 | n_eff | λ_guided (μm) |
| --- | --- | --- |
| TM₀ | 1.5507 | 1.000 |
| TE₀ | 1.6759 | 0.925 |

TM₀ 色散（λ₀ = 1.50–1.60 μm）：n_eff 从 1.5609 单调降至 1.5412，dn_eff/dλ ≈ −1.97 /μm。

## 与论文的对比

- 论文相位校正公式使用 n_ms ≈ 1.52（超表面区）与 n_wg ≈ 1.55（锥形区）。我们的 TM₀ n_eff ≈ 1.5507 与 n_wg ≈ 1.55 高度一致；n_ms 略低符合预期（超表面区被孔洞“稀释”平均折射率）。
- 说明论文的波导工作在弱约束 TM₀ 模式，模式对超表面扰动敏感度适中，有利于漏波辐射。

## 结论与下一步

- 基模 TM 有效折射率已确定 ≈ 1.55；后续元胞设计（2a_y 周期）须与该模式匹配。
- 下一步（case_002）：FDTD 元胞仿真——复现论文的半元胞 Jones 响应 (Ex, Ey) = δ(a_x sin2α, a_y cos2α)，并验证 Q ∝ 1/δ²。

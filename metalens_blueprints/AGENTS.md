# 圆柱路线约束

- 本目录是独立工作流，默认中文沟通；只复用显式依赖 blueprint_core 中的中性基础工具。
- 不修改原三角孔入口、schema或默认参数；不在原包中添加圆柱特例。
- 所有几何、相位选型、网格和工艺参数显式配置于 main/parameter.json。
- 相位CSV/物理元数据各自校验SHA256，保留仿真、插值、实测、未验证来源标签。
- v1仅圆柱、正方晶格、轴上聚焦；强制engineering_preview，不冒充生产或整片光学验证。
- 输出限本目录 main/.out；不覆盖case，不产生冗余调试副本。
- 修改后跑本目录测试和原blueprints回归；查看实际生成的PNG；不启动昂贵仿真。
- 未经用户明确要求不提交/推送；清理本任务创建的测试缓存，保留已有结果及无关修改。

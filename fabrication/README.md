# fabrication：工艺资料目录

本目录用于存放**工艺流程文件、测试记录和加工参考资料**等制备产出物。

可执行的参数化版图生成代码不放在本目录，统一维护于 [`../blueprints/`](../blueprints/README.md)。当前版图类型为用于 EBL/刻蚀的**有限六角光子晶体三角空气孔 DXF 工程版图**，并非已完成剂量、极性和生产 DRC 标定的投片版。

历史说明：原存放的 L03（Buzaverov 2024，Si₃N₄ 集成光子学工艺综述）已于 2026-08-30 移入 `literature/`（文件名 `L03_Buzaverov_2024_Silicon_Nitride_Integrated_Photonics.pdf`），在文献清单中标注为 **SiN 加工参考**。

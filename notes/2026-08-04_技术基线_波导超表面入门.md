# 技术基线：波导 + 超表面入门知识

> 本文是**基线知识**，用于建立统一认识。主论文到达后，一切以论文为准，本文中与论文冲突之处以论文为准并在本文中标注更新。

## 1. 两个基本概念

**波导（waveguide）**：把光约束在折射率较高的芯层中传播的结构。光在芯层与包层界面发生全内反射，形成离散的导模（如 TE₀、TM₀），每个模式有自己的**有效折射率 n_eff**（介于包层与芯层折射率之间）。典型体系：SiN/SiO₂、Si/SiO₂（SOI）、TiO₂ 等。

**超表面（metasurface）**：由亚波长周期（p < λ）排列的纳米单元组成的平面结构。每个单元（纳米柱、圆盘、椭圆柱、狭缝等）通过几何参数（高度、直径/宽度、旋转角）调控透过/反射光的相位（0–2π）、振幅与偏振。设计思路通常是把目标波前离散成“每个单元负责一个相位”，再反查单元库得到几何尺寸。

## 2. 波导 + 超表面的常见集成方式

1. **漏波辐射（leaky-wave）**：波导表面周期性地放置辐射单元（光栅/超表面单元），导模的倏逝场逐点耦合到单元向外辐射。辐射方向由相位匹配条件决定：

   sinθ = n_eff − m·λ/p

   其中 θ 为出射角，m 为衍射级次，p 为周期。改变周期或 n_eff 即可控制出射角度；单元几何控制每个辐射点的相位，从而整形波前。

2. **顶面大孔径超表面**：波导把光输运到超表面正下方，超表面作为大面积相位板，将垂直/斜入射的出射光整形为任意波前（聚焦、偏转、涡旋等）。

3. **可调体系**：在波导中集成可调材料（如相变材料、液晶、电光晶体），通过外部激励改变 n_eff 或单元响应，实现动态调控。

## 3. 设计流程速览（由简入深）

1. 确定目标：工作波长、功能（偏转/聚焦/偏振转换/波前整形）、性能指标（效率、带宽、角度）。
2. 选材料体系与波导结构 → 模式分析得到 n_eff 与模式分布。
3. 设计超表面单元库：扫描几何参数，记录每个单元的复振幅响应（相位、透过率），选出覆盖 0–2π 且效率高的单元集。
4. 根据目标相位分布布局单元（注意单元间耦合与周期约束）。
5. 全结构仿真验证（近场分布 → 远场角分布、效率、偏振）。
6. 制备可行性检查（线宽、深宽比、材料工艺兼容性）→ 出版图。
7. 制备与测试 → 对比仿真 → 迭代。

## 4. 常见陷阱

- **单元间耦合**：相邻单元间距过近时，单个单元的响应会漂移，需做超单元（supercell）验证。
- **相位离散误差**：有限单元库只能近似目标相位，离散误差会影响波前质量。
- **工艺偏差**：直径/高度对相位敏感，微米级偏差可能造成明显相位误差；设计中应留裕量。
- **背反射与 Fabry-Perot**：波导-超表面界面可能产生多次反射，影响效率与光谱。
- **波导损耗**：材料吸收、侧壁粗糙散射都会降低到达超表面的光强。

# 文献库入口

本目录保存论文 PDF、阅读笔记和分类索引；规范化 BibTeX 位于 `references/references.bib`。文献采用“唯一物理位置 + 多维分类链接”，同一篇论文可以同时属于多个材料、波段、主题和用途视图。

## 三条查找路径

| 需求 | 入口 |
| --- | --- |
| 查全部稳定编号与状态 | [文献清单](文献清单.md) |
| 按材料、波段、主题或用途交叉查找 | [多维分类索引](多维分类索引.md) |
| 查主线论文 L01–L05 | 本目录根部的 PDF 与 `阅读笔记_L*.md` |
| 查 L01 的物理/工艺支撑 | [Q1 设计物理](Q1_L01相关/README_本文件夹说明.md) · [Q1 工艺](Q1_工艺_L01相关/README_本文件夹说明.md) |
| 按顶层材料查 | [材料体系分类](材料体系分类/README.md) |
| 查 Si 1550 nm 专题 | [Si / 1550 波段](材料体系分类/Si/1550波段/README.md) |
| 使用旧“分区全景”入口 | [兼容入口](分区全景索引.md) |

## 存放规则

- PDF：`编号_第一作者_年份_短标题.pdf`；补充材料以 `_补充材料.pdf` 结尾。
- 笔记：`阅读笔记_编号_作者_年份.md`，使用 [阅读笔记模板](阅读笔记模板.md)。同一 DOI 只维护一份规范笔记；跨分类位置使用链接或兼容页。
- L/Q1/F 旧系列保留既有路径；新专题可在材料体系下建立独立目录，并提供 README、`pdfs/` 和 manifest。
- A/B/C/D/T 是专题内历史架位码；跨专题引用时加限定前缀，例如 `Si-1550:A2`。
- `Q1-xx` 是历史编号，期刊级别必须另写，不由编号推断。
- 论文 PDF 许可边界见 [references/README.md](../references/README.md) 与根目录 [NOTICE.md](../NOTICE.md)。

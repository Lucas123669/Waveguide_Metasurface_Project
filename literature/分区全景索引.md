# 分区全景索引（兼容入口）

旧版索引把期刊级别、材料、波段和 A/B/C/D 专题架位混在同一“分区”概念中，容易造成编号含义与论文属性不一致。该口径已于 2026-09-13 停止维护。

请改用以下入口：

- 按材料、波段、主题和用途组合筛选：[文献多维分类索引](多维分类索引.md)
- 查稳定编号、DOI、期刊级别与入库状态：[文献清单](文献清单.md)
- 按材料浏览：[材料体系分类](材料体系分类/README.md)
- 查项目级变化：[CHANGELOG](../CHANGELOG.md)

## 兼容说明

- `Q1-xx` 是历史编号，不保证论文当前或曾经属于期刊 Q1。
- A/B/C/D/T 是各专题内部的历史架位码；跨专题引用时使用 `Si-1550:A2` 一类限定编号。
- 一篇文献可以同时属于多个材料、波段、主题和用途，不复制 PDF，也不创建重复正文笔记。
- 旧版篇数和逐日维护记录可通过 Git 历史追溯，不在本页重复统计。

## 4. 详细阅读收获（逐技术分类）

### 4.1 材料基础（Sec. 2）

- 核心判据：Mie 共振需 2R ≈ λ/n（n 为折射率），高折射率材料才能缩小器件尺寸；介质材料以复折射率 ñ=n+ik 表征，n 决定约束强度、k 决定吸收。
- 材料光谱地图：可见-NIR 以 Si（a-/m-/p-Si）为主（CMOS 兼容、近零损耗）；TiO₂（n≈2.87–2.31）可见-NIR 低损耗、CMOS 兼容；Si₃N₄、GaN、ZnO、Ge、SiO₂、GaAs 各有波段优势；中红外 Te/GaSb/SiC；UV 区 HfO₂/ZrO₂/Nb₂O₅（60–80% 效率）。
- 对项目：我们 1.55 μm 用 PMMA(n≈1.48)/Si₃N₄(n≈2.0) 是"低折射率弱约束"路线，恰好符合 L01 容错设计；本篇说明高折射率体系（Si/TiO₂）虽能缩尺寸，但吸收/工艺限制更多。

### 4.2 标准纳米光刻（Sec. 3.1）

**EBL（3.1.1）**：
- 商业 EBL 通常 30–100 keV，适合亚波长天线；胶层决定最终几何。
- 典型案例与数据：
  - Si 结构色：PMMA 胶 → Cr 硬掩模 lift-off → CHF₃/SF₆ RIE 刻 Si → 铬刻蚀剂去 Cr；粗糙度 <10 nm；三色纳米盘尺寸 170/320、90/200、160/300 nm。
  - TiO₂ 超表面（Capasso 组）：EBL 负结构 + ALD 填 TiO₂ + 反向 RIE（Cl₂/BCl₃）→ 粗糙度 <1 nm、金属透镜效率 86%。**关键启示：ALD 反向填充的粗糙度极限 <1 nm，说明"胶/掩模决定几何"路线可以把侧壁粗糙度压到 1 nm 量级**。
  - TiO₂ lift-off（EB 蒸发）：粗糙度 0.66 nm，但截面呈梯形（邻近效应），故改用 RIE 获 89–90° 垂直侧壁。
  - GaN 消色差金属透镜（自上而下 EBL+刻蚀）：效率 50.6–91.6%。
- 缺点：面积小、贵、慢、设备维护成本高——"实验室创新主力，量产瓶颈"。

**FIB（3.1.2）**：
- Ga 离子束直写，无掩模、可同时观察（双束系统）；可做 3D/多层/悬臂/螺旋结构。
- 问题：Ga 高斯束使孔呈锥形、重沉积效应、深宽比受限、样品损伤、极低吞吐、昂贵。
- 对项目：FIB 仅适合小面积修版/截面分析，不适合 LWM 量产。

**激光制造（3.1.3）**：
- LIL（干涉光刻）：2/3/4/6 束干涉形成周期图案，大面积、低成本、无掩模；但只能做周期结构、大面积均匀性差。单脉冲四束 LIL 可把 a-Si 膜直接熔融成 Mie 纳米颗粒阵列。
- LDW（激光直写）：点对点直写，激光熔化/烧蚀、激光诱导（如石墨烯 C 形天线 15×15 mm² 34 秒）、双光子聚合（sub-100 nm 3D 打印，可打印到光纤端面做金属透镜/全息）。串行、慢，不适合晶圆级。
- 对项目：LIL/LDW 与我们的 EBL 路线互补性低，仅作了解。

### 4.3 先进纳米光刻（Sec. 3.2）

**灰度光刻（3.2.1）**：变剂量/变强度 → 同一表面上高度可变的纳米结构。
- EBL 灰度 + ALD 填 TiO₂：不同剂量形成不同深度孔 → 高度梯度纳米柱（结构色）。
- FIB 灰度铣削：恒定直径变深度 Mie void 色打印。
- 双光子灰度：低折射率纳米柱高度/周期/直径同时变化。
- UV 灰度（二元掩模）：大批量多光谱滤波片阵列。
- **对项目最重要的一条：L01/F-01 的"剂量控孔深"（dose-to-depth）正是灰度光刻原理在 qBIC 上的应用**——若需要纵向（深度）渐变调 Q，灰度 EBL 是现成手段。

**多步光刻（3.2.2）**：EBL+激光、EBL+光刻等多步组合，用于超浸润表面、合成孔径金属透镜（a-Si 柱 + Al 挡光）、金属-介质混合超表面（两步 EBL + 精确对准标记）。

**扫描探针光刻 SPL（3.2.3）**：热/电/机械探针直写；热 SPL（PPA 自放大解聚 + SiO₂ 掩模 + 深 RIE）侧壁 87±2°；电 SPL 逐层刻 VO₂。低吞吐、高成本。

### 4.4 大规模纳米光刻（Sec. 3.3，量产路线核心）

**UV 光刻（3.3.1）**——三个等级：
- i-line 365 nm stepper：2 cm NIR Si 金属透镜（衍射极限聚焦）；波长限制 → 不适合可见光小特征。
- KrF 248 nm：厘米级全玻璃可见光金属透镜（对应我们的 F-09）；Ge 中红外超表面 + Al₂O₃ 膜（4 英寸晶圆）。
- ArF 193 nm immersion：12 英寸 Si 纳米金字塔偏振带通滤波器（MPW 流片线）；12 英寸玻璃晶圆减色滤波（层转移）；12 英寸 a-Si 指纹成像金属透镜 @940 nm；100 mm 全玻璃可见光金属透镜（直接天文成像月球）。
- **结论：DUV 是当前最成熟的超表面量产路线**，且与 CMOS 平台完全兼容（stepper/scanner 机制：step-and-repeat 与同步扫描）。

**NIL（3.3.2）**：
- 热 NIL / UV-NIL / 软 NIL（PDMS 模）；UV-NIL 分辨率更高更快，应用最广。
- TiO₂ 纳米颗粒嵌入树脂（PER）一步 UV-NIL：超表面金属透镜（省掉沉积/刻蚀）；TiO₂ PER 全息图效率纪录 90.6%，可转印到 PC/PP/曲面玻璃等任意基底。
- PVA 水溶性模：湿法溶解脱模，避免脱模剪切应力 → 无缺陷高深宽比复制。
- 多层 NIL + 溶液相外延（SPE）：高深宽比 ZnO 金属透镜。
- 缺点：母版仍需高分辨率设备（EBL）制备；母版成本与缺陷控制是主要挑战。

**自组装（3.3.3）**：
- 纳米球光刻（PS 球 + 两次 RIE）：大面积 Si 柱超表面（柔性 PET 基底、完美反射器）。
- 灰度纳米球光刻：DMD 投影控制剂量 → 非周期相位分布金属透镜（1.7 μm，相对效率 >83%）。
- 玻璃 dewetting（模板化流体失稳）：高折射率玻璃薄膜退火自碎裂成纳米颗粒，特征 ~100 nm、间距小至 10 nm、可做 20×11 cm² 大面积（EPFL logo 演示）。
- AAO 模板 + TiO₂ 超表面。
- 优缺点：极低成本大面积，但几何自由度与均匀性有限。

### 4.5 极端制造（Sec. 4）

**多层（4.1）**：两步 EBL + 精确对准（手动/自动对准标记）；双层手性 Si 超表面（圆二色 CD 纪录 0.7）；α-Si/Ag 双砖独立调控透/反射相位；PDMS 层叠多层（多波长独立相位）；双光子 3D 打印多层消色差金属透镜（1000–1800 nm）。**对准误差对光学响应的影响必须在容差内核算**。

**柔性（4.2）**：TiO₂/Si 柱嵌入 PDMS，Ge 牺牲层转移；弯曲/拉伸可调。与我们的刚性片上器件无关，但"转移工艺"思路可参考。

**倾斜（4.3）**：
- 斜刻蚀系统：楔形衬底 + Al₂O₃ 离子准直器（保证左右侧壁斜角一致）。
- 斜扰动超表面实现**固有手性 BIC**：CD 0.93、Q>2663（可见光），由面内形变角 α + 面外斜角 φ 联合破缺所有镜像对称。
- 倾斜 TiO₂ 光栅：大角度反常折射 80°，相对效率 98.5%/绝对 89.5%（可调角度铝夹具 + 铝网抑制电场弯曲）。
- **对项目：L01 的椭圆孔是"面内破缺"；若未来要做强手性/椭圆率（Jones 矩阵中的 χ），可参考"面内 + 面外联合破缺"的斜刻蚀路线，但工艺复杂度显著上升。**

**高深宽比（4.4）**：
- TiO₂ 传统 ALD 限制：厚度 <600 nm、深宽比 <15；RIE 旧工艺侧壁 <75°。
- 新方案：1.5 μm 高 TiO₂ 柱、89–90° 垂直侧壁（EB 蒸发膜 + EBL + RIE），消色差金属透镜 650–1000 nm、效率 77.1–88.5%。
- NIL 直接压印：深宽比 >8、CD<60 nm。
- 孔型金属透镜：5 μm 自由 Si 膜上深孔深宽比 ≈30:1（Bosch 工艺，孔壁倾斜 <1°）；三层高深宽比 THz 微柱 20:1。
- **对项目：L01 孔深宽比仅 1–1.5（300 nm 深），远在常规窗口内；只有升级厚膜高 Q 器件才需要 Bosch/深反应离子刻蚀。**

### 4.6 Perspective & Outlook（Sec. 5）

- 材料方向：低损耗高折射率新材料；可调材料（GST、VO₂、Sb₂S₃、LiNbO₃、液晶、BaTiO₃、石墨烯、YIG、多铁/非线性量子阱）。
- 工艺方向：EBL/FIB 保实验室创新；量产靠 DUV（最受推崇、CMOS 兼容、12 英寸先例）、NIL（绿色、高保真，需母版）、自组装。**"方法选择取决于图案、分辨率、可扩展性"**。
- 应用方向：AR/VR、传感器+AI、微流控集成、航天/卫星通信、显示（Si 结构色已达 181.8% sRGB）。
- 趋势：从芯片演示 → 晶圆级量产；高折射率全介质超表面将成为近未来光子平台主力。

## 5. 核心收获（一句话级）

1. 制造技术存在**"分辨率-吞吐-成本"三角**：EBL/FIB 换分辨率、DUV/NIL/自组装换吞吐与成本，没有全能的单一技术。
2. **EBL 的粗糙度上限可以做到 <1 nm**（TiO₂ ALD 反向填充），说明"胶决定几何"路线的表面质量天花板很高——对 L01 的 PMMA 单层方案是正面信号。
3. **灰度光刻与 L01 的"剂量控深"同源**：纵向维度可作为额外的设计自由度。
4. **DUV（KrF 248 / ArF 193）是超表面量产的现实答案**，已到 12 英寸晶圆与 100 mm 全玻璃透镜的规模。
5. **高深宽比与倾斜工艺是"进阶技能"**：L01 目前用不上（深宽比 1–1.5、面内破缺），但它们是未来高 Q/手性器件（如固有手性 BIC，CD 0.93、Q>2663）的可行路线。
6. **多步/多层工艺的对准误差必须纳入容差预算**——与 F-05 的"穷尽容差"思想一致。

## 7. 待确认/后续跟踪问题

- TiO₂ ALD 反向填充的 <1 nm 粗糙度是否可迁移到 PMMA 直接显影路线（PMMA 显影的侧壁粗糙度文献数据需另行确认，可参考 L05 Rahman）。
- 若未来走 DUV 量产，需具体流片资源（F-01 的 248 nm KrF 工艺 + 本篇 12 英寸先例）；我们的 0.8 μm 周期/亚 200 nm 特征在 KrF/ArF 下的良率需实测。
- 灰度 EBL 的剂量-深度标定曲线（与我们已有的 PMMA 剂量测试片流程合并）。

## 2. 一句话总结

提出"反对称梯形柱 + 位置失谐阵列"的 SP-BIC 设计，其 x 偏振下磁偶极主导模式的几何敏感度仅为电偶极模式的 1/10–1/20，并用 EBL 制备验证了对典型加工缺陷的强容忍性。

## 3. 核心内容

- **问题**：可见光 SP-BIC 需要数十纳米级尺寸控制，σ≈0.9 nm 的工艺偏差就会让某些设计 Q 大幅下降（如开口环 Q 从 200 降到 91，-54.5%）。
- **设计**：Si 梯形柱对（H=100 nm）反对称排列；x 偏振激发时共振以磁偶极（MD）为主，电场集中于柱间间隙而非柱体内部 → 对几何形变不敏感。
- **验证**：系统扫几何参数；对典型缺陷（尺寸偏差、粗糙、错位等）MD 峰保持稳定；EBL 制备 + SEM 几何表征 + 光学响应确认。

## 4. 与 L01 的关联

- 与 Q1-11 Kühne 结论一致：单元几何决定工艺鲁棒性。L01 用椭圆孔（已被证明最鲁棒），本工作提供另一种思路：**选磁偶极主导的模式**可进一步降低几何敏感度。
- 对我们的意义：若 L01 的 apodization 要求极小的 δ，可借鉴"模式主导成分"分析来挑选对 δ 误差不敏感的工作点。

## 5. 对我们的启示

1. 单元设计阶段加入"几何敏感度分析"：扫每个参数的 ∂(峰位/线宽)/∂参数，选敏感度最低的工作点。
2. 可见光波长下加工误差影响更大（特征更小），若我们做可见光版本需按此标准收紧工艺。
3. 缺陷类型清单（粗糙、错位、尺寸偏差）可复用于我们自己的容差仿真。

## 6. 待确认问题

- MD 主导模式与 L01 的 qBIC Jones 矩阵控制是否兼容（是否牺牲偏振自由度换取鲁棒性）。

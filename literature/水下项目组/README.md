## 2. 如何选择阅读顺序？

- **先理解条纹怎么产生和移相**：UW03；重点是输出检偏器及双偏振复响应。
- **再理解条纹怎样变成三维点云**：UW01；重点是散斑/相位融合与双目匹配。
- **最后研究怎样减少采集帧数**：UW02；重点是编码约束、混合矩阵及标定，而不是只看“四通道”名称。

三篇解决的是不同层次的问题，不能把各自最好的数字组合成一套已经实现的系统。

## 3. 三种“通道”不能混为一谈

UW01 是两种入射偏振下的两个固定全息图案，采集后再融合信息。UW02 是 DLP 上四个相关的移相条纹通过四角偏振与空间混合并行编码。UW03 则在两个本征偏振响应的基础上，利用输出分析轴上的相干叠加形成中间相移。

因此，不能从 UW01 的“两通道”直接推导 UW02 的“四通道”，也不能把 UW03 的“三个读取状态”写成三个独立偏振本征通道。

## 4. 水下迁移前的共同验证关口

以下均为项目建议，不是三篇原文已经完成的实验。

1. **先定义水下使用方式**：器件直接浸水，还是隔着窗口置于空气腔？两者对元胞、偏振与标定的影响不同。
2. **选择波长与功率预算**：实测具体水体的衰减/散射和目标反射，不能仅凭“绿光”或现有 1064 nm 激光器决定量程。
3. **测偏振传递**：包含窗口、水体、目标和相机；记录消光、退偏、通道增益及串扰。
4. **建立真实测量模型**：加性后向散射不一定能被 DoLP 比值消去；非均匀模糊也可能破坏相位和通道互补约束。
5. **做含折射的几何标定**：空气中的双目或投影器标定不能自动覆盖水界面。
6. **逐级对照**：空气 → 清水短光程 → 光程扫描 → 浑浊度扫描 → 运动/高反光目标；统一功率、曝光与误差定义。
7. **先验证算法，再投片**：用现有 DLP/偏振光学验证信息融合/约束模型，降低第一次超表面加工的不确定性。

每一级都报告原始图、条纹调制度、相位残差、有效点数/覆盖率、标准件误差、重复性和完整采集/计算时间。平滑后的点云不代替原始误差。

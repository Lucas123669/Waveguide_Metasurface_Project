# 文献多维分类索引

文献只保存一份 PDF 和一份规范笔记，但可以同时出现在多个分类视图中。分类用于检索，目录只表示文件的物理位置。

## 编号与分类的区别

| 字段 | 作用 | 是否可多选 | 示例 |
| --- | --- | --- | --- |
| 稳定编号 | 追踪一篇文献，不随分类变化 | 否 | `L01`、`Q1-06`、`F-02` |
| 专题限定编号 | 消除 A/B/C/D 在不同专题中的重名 | 否 | `Si-1550:A2`、`SiN-1550:A2` |
| 材料 | 表示文献涉及的材料或平台 | 是 | `Si`、`SiN`、`PMMA`、`TiO2` |
| 波段 | 表示原文实际工作波段 | 是 | `1550nm`、`visible`、`broadband` |
| 主题 | 表示论文解决的问题 | 是 | `guided-wave`、`BIC`、`metalens`、`fabrication` |
| 用途 | 表示项目中如何使用 | 是 | `design`、`simulation`、`process`、`background` |
| 期刊级别 | JCR/中科院等评价信息 | 否 | `JCR Q1`、`中科院二区`、`中文核心` |

`Q1-xx` 是历史编号前缀，不再解释为“这篇论文当前一定属于 Q1”。期刊级别只写在独立字段中。A/B/C/D/T 也是专题内的历史架位码，不承担唯一分类含义。

## 专题限定编号

- `Si-1550:A1` 至 `Si-1550:E1` 对应 `材料体系分类/Si/1550波段/` 中的历史架位码。
- `SiN-1550:A1` 至 `SiN-1550:D4` 对应 `材料体系分类/SiN/1550波段/` 中的历史架位码。
- `TiO2-1550:T1` 至 `TiO2-1550:T6` 对应 `材料体系分类/TiO2/1550波段/`。
- 文献已有 L/Q1/F 稳定编号时，L/Q1/F 为规范编号，专题限定编号仅作为别名。
- 没有 L/Q1/F 编号的专题文献以专题限定编号作为规范引用方式。

## 笔记归一规则

1. 同一 DOI 只维护一份规范笔记。
2. 其他材料或专题目录只保留兼容页，写明别名、标签和规范笔记链接。
3. 精读笔记已覆盖简版时，以精读笔记为规范笔记；简版路径改为兼容页。
4. 参数清单与精读笔记确有不同职责时可以并存，但必须在文件开头写明边界。
5. 新增分类只改索引或标签，不移动原始 PDF。

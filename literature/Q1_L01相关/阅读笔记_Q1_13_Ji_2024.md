# 阅读笔记 Q1-13｜Ji 2024：全参量 Jones 矩阵片上超表面

## 1. 论文信息

- 题目：*On-chip multifunctional metasurfaces with full-parametric multiplexed Jones matrix*
- 作者：Jitao Ji et al.
- 期刊：*Nature Communications* 15, 8271 (2024)
- DOI：https://doi.org/10.1038/s41467-024-52476-2
- 开放状态：Open Access；本地 PDF 为出版社正式版。
- 项目标签：`Si`、`LNOI`、`1550nm`、`guided-wave`、`Jones-matrix`、`polarization`、`fabrication`、`design`

## 2. 一句话总结

作者用四个相邻 a-Si 纳米柱构成超胞，把 detour phase 与 geometric phase 组合起来，在 1550 nm 片上导模激励下独立控制四个 Jones 矩阵分量的振幅和相位，并进一步用传播相位实现双方向复用。

## 3. 结构与原理

- 平台为 x-cut LNOI：600 nm LiNbO₃、2.0 µm buried SiO₂；上覆 100 nm SiO₂ 和 1.2 µm a-Si。
- 示例纳米柱尺寸约为长 300 nm、宽 100 nm；四柱超胞的周期为 `2Py = 1520 nm`、`2Px = 1580 nm`。
- 四个柱的位移/旋转分别编码 `Jxx`、`Jxy`、`Jyx`、`Jyy`；沿导模传播方向的相位累积提供方向复用自由度。
- 这是“完整复振幅矩阵”架构，不只是单偏振相位库；适合用来定义本项目 Jones-matrix 单元库的接口与验收量。

## 4. 仿真与实验

- FDTD 使用 1550 nm 的 TE₀ 导模；传播方向采用 PML，周期方向采用 periodic boundary。
- a-Si、LiNbO₃ 等折射率来自椭偏实测，而不是只采用常数手册值。
- 论文完成了多通道全息/偏振复用实验；正文给出的实验提取效率约为 6.5%。该效率是本文具体器件与测量定义下的结果，不可与 L02 的理论上限直接比较。

## 5. 加工流程

1. 在商用 LNOI 上 PECVD 沉积 100 nm SiO₂ 与 1.2 µm a-Si。
2. 旋涂约 200 nm PMMA A4，使用 Elionix ELS-F125 EBL 曝光。
3. 电子束蒸发 Cr 并 lift-off，形成硬掩模。
4. 用 `C4F8/SF6` 干法刻蚀 a-Si；以 ammonium cerium nitrate 去除 Cr。

## 6. 对本项目的直接启示

- 单元库不应只记录相位；至少应保留四个复数 Jones 分量、辐射效率、串扰和传播方向。
- 需要在超胞级联合优化位置、旋转角和相邻单元耦合，不能把四个柱当成互不影响的独立像素。
- a-Si + PMMA EBL + Cr hard mask + 氟基刻蚀的链条与当前首轮路线相近，可作为流程模块参考。
- 对 1550 nm 波导超表面，传播相位本身可以成为额外复用自由度，适合纳入后续 COMSOL/FDTD 端口定义。

## 7. 证据边界

- 原文衬底是 LNOI，不是本项目的 HPFS 7980；LiNbO₃ 波导模场、折射率和尺寸不能直接移植。
- 1.2 µm a-Si 与当前候选膜厚可能差异很大；所有几何尺寸必须重新缩放并做本征模/色散校准。
- 6.5% 是实验提取效率，不代表四通道矩阵控制的理论极限，也不等于耦合器效率。

## 8. 建议复现任务

1. 在 `case_002` 的单元库中增加 `Jxx/Jxy/Jyx/Jyy` 复数输出。
2. 先以四柱超胞复现相位覆盖与交叉偏振响应，再替换为 HPFS + a-Si:H 平台。
3. 对柱长、柱宽、旋转角、位置偏差各做 ±10 nm/±1° 容差扫描，并记录串扰而非只记录峰值效率。

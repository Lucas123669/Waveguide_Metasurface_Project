## 2. 一句话总结

把超表面划分为"局域 / 非局域非衍射 / 衍射非局域"三类，指出衍射非局域超表面（基于 q-BIC）是最一般类别：响应编码在空间扩展的共振模式中，只在 Fano 共振带宽内出现，且**光谱选择性与空间选择性可独立调谐**，既能做波前整形也能做波前选择器件。

## 3. 核心内容

### 3.1 三类超表面（散射核视角）

- **局域超表面**：散射核空间瞬时 ρ(x,x',ω)=r(x,ω)δ(x−x')，逐点独立控制 → 宽带、宽角；金属透镜/涡旋/全息常用。
- **非局域非衍射超表面**（0 阶光栅）：动量域散射 r(k,ω)，共振响应只对特定频率/动量匹配 → 窄带滤波、折射率传感、图像微分。
- **衍射非局域超表面**：空间-频率域核 ρ(x,x',ω)，最一般类别；结合局域的空间控制与非局域的频率选择性 → 任意带宽内任意二维波前。

### 3.2 非局域度谱系

- 所有超表面都处于"局域↔非局域"连续谱上（深亚波长有效介质 → 等离激元 → 介质柱 → 双各向异性 → Huygens → 高对比光栅 → 低对比光栅）。
- **非局域特征长度 ≈ Q·λ₀/n_eff**：Q 越大，模式携带能量的距离越长。
- 高对比光栅（HCG）是衍射非局域超表面的最佳载体：可通过能带与 Q 工程显式控制局域化程度。

### 3.3 设计维度

- 按 Λ/λ 区分：0 阶光栅 Λ/λ<1；metagrating 1<Λ/λ<N（N≈3）；metasurface Λ/λ>N。
- 按 Q 区分：非微扰（低/中 Q）vs 微扰（高 Q，对称破缺 → Q 无界可控）。
- **谱选择性与空间选择性独立调谐**：微扰控制 Q/带宽，空间微扰分布控制波前 → 波前整形器件（宽带平面波→准单色定制波前）或波前选择器件（只对特定波前+频率共振）。

## 4. 与 L01 的关联

- L01 正是**波导集成版衍射非局域超表面**：导模驱动 + q-BIC 微扰，响应仅在其 Fano 带宽内，同时整形振幅/相位/偏振。
- "共振带宽内响应"对应 L01 的 apodization 设计（Q_min≈25 保证波前覆盖）；"谱/空间选择性独立调谐"对应 L01 用 δ 控 Q/振幅、α 控偏振的独立编码。
- 非局域长度 ≈ Qλ₀/n_eff 可用来检查 L01 的 400 μm 孔径是否足以支撑目标 Q 的共振模式（Q=25 → ~25×1.55/1.52 ≈ 25 μm ≪ 400 μm，成立）。

## 5. 对我们的启示

1. 定位清晰化：我们的 LWM 是"高 Q 衍射非局域超表面"，设计时要用共振模式而非逐单元本征响应来思考。
2. apodization 设计可参考其"空间微扰分布 ↔ 波前"映射框架。
3. 若做波前选择类器件（只对特定入射波前共振），本框架提供概念基础。

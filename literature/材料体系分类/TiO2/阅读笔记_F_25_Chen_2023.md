## 1. 一句话总结

在 TiO₂ 膜中制备"斜梯形纳米孔"方阵超表面（斜刻蚀同时引入面内变形角 α 与面外斜角 φ，破缺全部镜像对称），首次在可见光实验实现**固有（true/intrinsic）手性 qBIC**：CD 高达 0.93、Q 因子 2663（可见光纪录），且反射矩阵交叉极化分量为零，证明 CD 源于真实手性而非"假手性"（斜入射或结构各向异性）。

## 2. 研究动机与问题

- 光子自旋本征手性（intrinsic chirality）是手性光源/探测、手性传感、valleytronics、不对称光催化的基础，但天然材料手性极弱。
- 此前的强圆二色 CD 实验大多依赖"假/外在手性"：斜入射或面内各向异性导致的偏振转换，其 CD 不能度量真实手性，且应用受限。
- 手性超构材料 Q 因子普遍很低（典型 <200，辐射与非辐射损耗大）；已报道的高 Q CD 均在红外，可见光极难。
- 理论（Gorkunov/Overvig/Dixon 等）指出：实现手性 BIC 需破缺**全部**镜像对称（面内 + 面外），而此前实验只分别破缺面内或面外，剩余对称面仍阻止固有手性 BIC 产生。

## 3. 结构设计与关键参数

- 结构：玻璃基底上 TiO₂ 膜内的**斜梯形纳米孔**方阵，表面覆盖一层 index-matched PMMA（Fig. 1a）。
- 关键几何（Fig. 1a 标注）：周期 p = 340 nm，孔宽 w = 210 nm，膜厚/孔深 h = 220 nm。
- 两个几何扰动自由度：
  - α：面内变形角——方孔被"切"成梯形（破缺 C2z 面内对称）；
  - φ：面外斜角——孔沿 x 方向倾斜（破缺面外镜像对称）。
- 实验选定组合：α = 0.12、φ = 0.1（受制于加工能力，尽量小以保证高 Q）。
- 器件尺寸：制了 68 µm 与 200 µm 两组方阵；200 µm 样品给出最高 Q。
- 模式选择：基模 TM1 为最优（TM2/TE2 单靠斜角无法达 CD→1；TE1 需更大 φ 导致 Q 过小）。

## 4. 工作原理 / 物理机制

- 无扰动（α=φ=0）：TM1 因 C2z 对称在 Γ 点为对称保护 BIC（时间反演 → 近场线偏振、辐射相消）。
- 只破面内（α≠0）：BIC → qBIC，近场出现圆偏振，用光手性密度 OCD = −½ω·Im[D·B*] 表征；但 OCD 是 parity-odd 标量，镜像对称迫使两侧符号相反，体积积分相消 → 面外镜像对称保护下远场无手性通量（对面内几何"免疫"）。
- 斜孔（φ≠0）破缺面外镜像对称：ΔOCD = (Δε/ε)·OCD 在所有扰动区同号累积 → 近场 OCD 失衡 → 远场手性通量 ≠ 0 → 圆偏振辐射，即 CD。
- 偶极图像：原构型电偶极 p ∥ k（与磁偶极 m 垂直投影 p⊥·m⊥=0，无手性）；孔向 −x 倾斜后电场矢量随之倾斜而磁场近似保持 x 偏振 → p⊥·m⊥ ≠ 0。
- k 空间偏振拓扑：未扰动 BIC = Γ 点整数荷 V 点；引入 φ 后 V 点分裂为 Γ 两侧一对半荷 C 点（C+ RCP、C− LCP）；再引入 α 使整个偏振图向结构倾斜方向移动；α=0.12、φ=0.1 时 C+ 恰好回到 Γ 点 → Γ 点处实现固有手性 BIC（TE1 同理可构造）。
- 定量规律：Q ~ 1/(α² + Aφ²)；|p|、|m| ~ Q^½；故 CD ~ p⊥·m⊥ ~ φ/(α²+Aφ²)——φ 从 0 增大时 CD 先增后减，存在最优；对 φ 求导得 **CD 最大化条件 α = √A·φ**。TM1 的理论斜率 √A = 1.066，与仿真一致；实验拟合斜率 1.197（略偏）。
- CD 定义为反射谱 CD = (RR − RL)/(RR + RL)，RR(L) 为 RCP(LCP) 入射下的归一化反射。

## 5. 关键结果与性能数字

- **Q = 2663**（200 µm 样品，可见光手性结构纪录）与 **CD = 0.93**（近 unity）同时实现。
- CD 随器件尺寸增大而提高（200 µm > 68 µm）——大尺寸同时抑制面内/面外泄漏，是除减小 α/φ 外另一条提 Q 途径。
- 圆基反射矩阵 R = [RRR, RRL; RLR, RLL] 中交叉偏振项 RRL、RLR 可忽略 → 无偏振转换 → CD 确为 intrinsic chirality（排除假手性），此为本工作与"假手性高 CD"工作的根本区别。
- 角度分辨谱中 C+/C− 点实验出现在入射角 0 与 −0.044 rad（仿真 −0.04 rad），吻合良好。
- C 点入射角随 φ 近似线性变化（仿真与实验一致）。
- 实测 CD 普遍小于仿真（归因于加工容差与表面粗糙度散射）。

## 6. 制备工艺细节

- 斜刻蚀系统（modified slanted-etching system，详见 SI Fig. 5，本文本未含全流程）：样品置于**楔形（wedged）衬底**上控制小斜角；样品上方放置带孔径的 **Al₂O₃ 屏作离子准直器（ion collimator）**——保证左右侧壁斜角几乎一致（SEM 验证）。
- 面内梯形孔由常规图案定义，面外斜角由刻蚀几何引入，两步扰动在同一结构上叠加。
- 表面覆盖 index-matched PMMA 层（作用见 SI Sec. 5）。
- α、φ 定为 0.12/0.1 是"加工能力"下的折中；斜孔方向还带方位角 θ 自由度（SI Sec. 11，本文未用）。
- 器件尺寸 68 / 200 µm，样品按 α 固定、φ 可变的系列扫描 φ 的影响。

## 7. 与本项目（L01/L02）的关系与可借鉴点

- **与 L01（PMMA/Si₃N₄ qBIC 漏波超表面）同属 qBIC 平台**，且同为"高折射率膜 + 低折射率 PMMA"叠层（本文是 TiO₂ 孔内/上方 PMMA index-matching；L01 是 PMMA 参与弱扰动）。PMMA 层的 index-matching 角色可对照 L01 中 PMMA 的介电包覆作用。
- 可直接搬用的**设计工具**：
  1. Q ~ 1/(α²+Aφ²) 的扰动标度律 + "α 与 φ 协同调制把 C 点移回 Γ"的偏振拓扑判据——若 L01 用两个几何自由度调 Q/CD，可套用此框架；
  2. **器件尺寸-泄漏折衷**：加大孔径可显著提 Q（68→200 µm，Q 提升明显）——支持 L01 大孔径方案的 Q 增益预期；
  3. **区分固有/假手性的判据**：测圆基反射矩阵交叉偏振项是否为零——若 L01 未来验证 Jones 矩阵手性/椭圆率，可直接采用。
- 工艺借鉴：斜刻蚀用"楔形衬底 + Al₂O₃ 离子准直器"获得左右对称斜角；但该 3D 斜结构工艺复杂度显著高于 L01 平面结构，仅当项目升级到手性/强椭圆率需求（类似 F-08 §4.5 的判断）才值得引入。
- 对 L02（Si 波导 + Au/SiO₂/Au）直接关联弱；其价值在于方法论与"容差导致响应偏离仿真"的警示。

## 8. 局限性 / 待确认问题

- 手性 CD 由**反射**谱定义/表征（透射数据在 SI）；工作波段在可见光，未见扩展论证细节。
- 精确加工流程（TiO₂ 膜沉积、孔刻蚀参数、PMMA 覆盖工艺）与 PMMA 作用分析在主文本外（SI），本 txt 无法核对——如需复制需另取 SI。
- 实测 CD 低于仿真：斜角控制误差、粗糙度散射的量级未量化。
- α/φ 组合受"加工能力"限制，更小扰动的更高 Q（理论可达）未在本文演示；仅测了两种器件尺寸。
- 概念声称可推广至红外及更长波段（未实验验证）；与 L01 的 Si₃N₄/PMMA 材料体系无直接可比数据，PMMA 在此处是覆盖层而非结构层。

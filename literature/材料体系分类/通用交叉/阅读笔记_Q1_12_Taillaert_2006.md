## 一句话总结

系统给出把单模光纤与纳米光子波导耦合的光栅耦合器设计方法（周期、占空比、刻蚀深度、层叠结构），实验在标准 SOI 晶圆上实现 >30% 耦合效率、1 dB 带宽 40 nm；理论优化（非均匀光栅 + 底部反射镜 + 折射率匹配层）可达 >90%（92%）。

## 研究动机与问题

- 纳米光子波导（100–300 nm 芯层、强模式约束）与单模光纤模式严重失配，耦合是集成光子电路的关键问题。
- 已有方案：倒锥 + 聚合物上包层（损耗可 <1 dB），但只能从芯片**端面**耦合，需要抛光端面。
- 光栅耦合器优点：**表面耦合、可放芯片任意位置、免端面抛光、支持晶圆级测试**；缺点：偏振敏感（本工作只做 TE）。

## 关键设计参数（原文可核对）

- **周期条件**：垂直耦合 Λ = λ/n_eff；实际为避免二阶衍射反射，**失谐 + 倾斜出射**，TE 下光纤倾角 θ ≈ 8–10°（论文取 10° 实验、8° 带匹配层）。
- **基准参数**（SOI，中心波长 1550 nm）：Λ = **630 nm**，刻蚀深度 **70 nm**，填充因子 **0.5**；220 nm Si 顶层，BOX 1 µm（非最优，最优 900 nm / 1.45 µm）。
- **效率阶梯**（表 I，全部为计算值）：
  | 层叠结构 | 效率 |
  | --- | --- |
  | SOI + 空气上包层 | 37% |
  | + 折射率匹配层（n=1.46） | 44% |
  | + 最优 BOX 厚度（1.45 µm） | 53% |
  | + 非均匀光栅（变占空比/刻蚀深度，BOX 925 nm） | 61% |
  | + 底部 Si/SiO₂ 反射镜（2-pair） | 79% |
  | 底部反射镜 + 优化（刻蚀 100 nm、最小槽宽 30 nm、匹配层） | **92%**（耦合损耗 <1 dB @1532–1567 nm，回反射 <−24 dB） |
- 耦合长度 Lc ≈ 3.8 µm（70 nm 浅刻蚀即达强耦合，得益于 SOI 高折射率对比）。
- **对准容差**：倾角 θ 改变 → 中心波长漂移 ≈ **9 nm/°**；xy 平面角误差 2° → 0.5 dB 附加损耗；光纤‑光栅距离 <15 µm 附加损耗可忽略、55 µm → 0.5 dB；横向对准 1 µm → <0.5 dB。
- 偏振选择：TE/TM 有效折射率差大（2.83 vs 1.89）→ 强偏振选择；通信需 polarization diversity（二维/交叉光栅做偏振分束）。

## 仿真方法

- 2D 特征模展开法（eigenmode expansion）+ PML 边界，TE 偏振；光纤模用高斯近似（束径 10.4 µm）做重叠积分；3D 近似 = 2D 结果 × x 方向重叠积分（有效折射率法同类近似，波导宽 12 µm ≫ λ 时有效）。

## 制备工艺（SOI 实验）

- 200 mm SOI（SOITEC，220 nm Si / 1 µm BOX）；**DUV 248 nm 光刻**（NA 0.63，Shipley UV3 + 抗反射层；周期低至 400 nm 有足够工艺窗口）；两步刻蚀：光栅 70 nm + 波导/电路 220 nm。
- 器件：12 µm 宽波导 + 400 µm 绝热 taper → 450 nm 光子线；两端光栅，3 mm 间距；精密三维平移台装夹切割光纤，θ=10°，宽谱可调谐激光 + PM 光纤测 T=η² 得单端效率。

## 对项目的启示

1. **激励端基准**：L01/L02 实验前，先按本轨道 `ref_taillaert_2006` 的 2D 模型跑通耦合效率基线；1550 nm 下 Λ≈630 nm / 刻蚀 70 nm / 占空比 0.5 可作为 SOI 起始参数（Si₃N₄ 平台需按 n_eff 重算周期）。
2. **层叠工程套路**：效率提升路线 = 匹配层 → 最优 BOX → 非均匀光栅 → 底部反射镜；本项目若做漏波/辐射器件，可移植"上下行比（directionality）"的层叠优化思想。
3. **小角度失谐出射**：为避免二阶反射，出射角偏离表面法线 ~8–10°，与漏波超表面辐射角设计可类比。
4. **端面 vs 表面耦合取舍**：超表面波导若做晶圆级测试/多器件阵列，光栅耦合（表面）优于端面耦合；若做单器件高功率，考虑倒锥端面耦合。

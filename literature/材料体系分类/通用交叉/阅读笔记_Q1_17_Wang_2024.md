## 一句话总结

把"单向导模共振（UGR）"这一**拓扑辐射机制**做成标准 340 nm SOI 上的 L 形光栅耦合器：让对称保护 BIC 的整数拓扑荷 q = −1 分裂成一对半荷 q = ±1/2、再在下侧复合为 UGR，从而**无需底部反射镜**即抑制向下辐射；再以色散工程 + 变迹（apodization）同时完成波导模式匹配与光纤模式重叠整形，实验取得 **−0.34 dB** 耦合损耗（92.47%）、1-dB 带宽 **> 30 nm**，并用同一对耦合器验证层叠芯片间的"光过孔"（**−0.94 dB**，80.53%）。

## 研究动机与问题

- 光 I/O 是硅光的关键环节；光栅耦合器因 footprint 小、可晶圆级测试、布置灵活而受青睐，但**能量效率长期不足**，成为大规模光子集成的功耗瓶颈。
- 已有提效手段基本是**参数工程**：L 形、interleaved、多层、overlay、倾斜刻蚀、底部反射镜——能压低无用向下辐射与背散射，但缺乏系统性的设计策略；尤其底部反射镜需要**额外工艺层**。
- 辐射拓扑学提供另一条路：UGR（本文 ref 54 = Yin 2020 *Nature*；ref 57 = Yin 2023 *PRL*）通过把一对半整数拓扑荷在一侧合并、另一侧保持分离，实现**无反射镜的单向辐射**。
- 但前人 UGR 实现多依赖**厚膜或强带间耦合**，与标准 SOI 厚度不兼容；如何把它做成"完整、实用、工艺友好"的耦合器，此前未解决。
- 本文的关键取舍：改用**对称保护 BIC**（对任何平板厚度都稳定驻留于 Γ 点），绕开厚膜限制，并把 UGR 与波导模式、光纤模式一起做整体设计。

## 关键设计参数（原文可核对）

- **平台**：标准 **340 nm 厚 SOI**；上包层 SiO₂，n_c = **1.445**（实测用 Cargille Series A 折射率匹配液模拟 foundry 的 SiO₂ 包层）。
- **单元**：L 形孔 = 两个矩形块 **B1(w1, h1)** + **B2(w2, h2)**，垂直侧壁（刻意避免倾斜刻蚀与多层沉积）。
- **周期**：a = **528 nm**。
- **实测样品几何**：a = 528 nm，w1 = **158 nm**，w2 = **200 nm**，h1 = **100 nm**，h2 = **262 nm**。
- **工作模式**：最低**反对称 TE 带（TE-A）**，ky = 0 时电场 **y 偏振**。
- **拓扑机制**：无 B1 时结构恢复 C2 对称 → Γ 点对称保护 BIC，q = −1，Q = ∞；加入 B1 破缺 C2 → 整数荷分裂为半荷对 q = ±1/2，Γ 附近 Q 从 ∞ 降到 **≈ 134**（刻意压低以支持宽带）。
- **UGR 位置**：kx = **−0.1192**（h1 从 0 增到 100 nm，RCP/LCP 轨迹在 kx 轴相遇）；上下辐射**不对称比 η ≈ 65.8 dB**。
- **器件分段**：tapered waveguide + **apodization region** + uniform region；群速度匹配（波导宽度 20 → 2 µm 时 vg = dω/dk 近似不变），变迹实现动量匹配以压低背向散射。
- **光纤**：Corning SMF-28e+（芯 8.2 µm / 包层 125 µm，**MFD 10.4 µm**）；设计辐射角 **θ = −13.72°**。
- **footprint**：**20 µm × 20 µm**，接 2 µm 宽波导。

## 关键结果

### 数值（Lumerical FDTD / COMSOL）

- 耦合器→光纤 CE 的 −3 / −1 dB 阈值对应谱宽 **57.6 / 28.9 nm**（固定 −13.72° 入射）。
- 角容差：1550 nm 下 −3 / −1 dB 分别为 **6° / 3°**。
- 刻蚀宽度与深度偏差范围内 CE 保持 **> −1 dB**（§S3；逐参数范围见下文"补充材料要点"）。
- 层叠"光过孔"仿真插入损耗 **< −1 dB**。

### 实验（fiber-to-detector link：两个相同耦合器 + 7 mm 波导）

- 链路最小损耗 **−1.24 dB** @ 1550 nm。
- 扣除 coupler-to-fiber / coupler-to-detector 重叠比后，**耦合器→光纤峰值 CE = −0.34 dB（92.47%）**，1-dB 带宽 **> 30 nm**（原文称 record-low loss）。
- **套刻平移容差**（B1/B2 横向错位 −50…+50 nm，步进 10 nm）：峰值 CE 全部 **> −1 dB**；|偏移| ≤ 30 nm 时 CE 优于 **−0.6 dB**。
- **重复性**：36 个同工艺器件（图形位置/宽度 σ ≈ 5 nm）平均 CE = **−0.426 dB**（方差 0.005 dB），平均 1-dB 带宽 **32.83 nm**（方差 0.55 nm）。
- **层叠芯片（光过孔）**：4 个 UGR 耦合器 + 总长 10 mm 波导，链路最小损耗 **−2.68 dB**；扣除光纤/探测器/波导损耗后，耦合器间峰值 CE = **−0.94 dB（80.53%）**，1-dB 带宽 **21.4 nm**。
- **代表图**：Fig. 1 拓扑荷演化与 UGR；Fig. 2 器件设计与 CE 的波长-角度图；Fig. 3 EBL/ICP 样品（光学 + SEM）；Fig. 4 耦合器→光纤 CE 分解、容差图与 36 器件统计；Fig. 5 层叠光过孔仿真与实测。

## 补充材料要点（S1–S7，2026-09-15 入库）

> 原文 PDF：`pdfs/Q1_17_Wang_2024_补充材料.pdf`（29 页）。以下数值取自补材原文，可用于设计与引用；公式编号为补材编号。

### S1 上行辐射的拓扑荷演化（Fig. S1）

- 拓扑荷定义：`q = (1/2π)∮_C dk·∇_k φ(k)`，`φ(k) = arg[c_x(k) + i·c_y(k)]`，C 为动量空间中逆时针环绕目标态的闭合路径。
- **上行辐射的整数荷同样分裂为一对 q = −1/2，但两个半荷单调分离、永不相遇** → 上行通道始终打开；下行则复合回整数荷 q = −1 → 下行通道关闭。这才是"无反射镜单向辐射"的完整论证（正文只给了下行侧在 kx = −0.1192 处复合）。

### S2 变迹区设计公式与两款扩展设计

- 相位匹配（式 S2）与**周期设计公式**（式 S3）：`a = [λ + w₁(n_wg − n_b1) + w₂(n_wg − n_b2)] / (n_wg − n_c·sinθ)`，本文 θ = −13.72°、n_c = 1.445。**做参数移植时应直接用式 S3 反算 a，而不是照抄 528 nm。**
- Fig. S2：下行辐射在宽谱内被压到 **−10 dB 等值线**以下；上行用 −1 / −3 dB 等值线标出。
- **正文器件受"最小特征尺寸 60 nm"约束**（制造精度折中）；Fig. S3 给出放宽该约束的"高精度"设计，仿真峰值 coupler-to-fiber CE = **−0.154 dB**——优于已加工的低精度版，因为空间/角分布更接近高斯。
- Fig. S4：把整段光栅做变迹以支持**变化的 θ**，即可匹配发散光束（如 VCSEL）：1510–1590 nm 内 CE **> −0.18 dB**，1550 nm 峰值 **−0.115 dB**（30° 发散角）——耦合器兼作微透镜。

### S3 几何偏差鲁棒性（Fig. S5，逐参数范围）

以 −1 dB 为门限，**单独**扰动各参数（变迹区同步跟随）后 CE 仍 > −1 dB 的范围：

| 参数 | 保持 CE > −1 dB 的偏差范围 |
| --- | --- |
| w₂ | −60 ~ +55 nm |
| w₁ | −85 ~ +150 nm |
| h₂ | −50 ~ +40 nm |
| h₁ | −55 ~ +90 nm |

- 物理解释：只要保留面内镜像对称，UGR 可在任意二维参数空间中存在并演化，**一个参数的偏差可由另一个参数补偿**，从而继续完美消除下行辐射。
- 与正文的分工：正文测的是**工艺套刻平移**（±50 nm，含 36 器件重复性），这里扫的是**几何参数空间**，两者互补而非重复。

### S4 耦合效率标定链（Fig. S6、S7）

- 损耗分解：`IL = CE_coupler-to-fiber + WL + CE_coupler-to-detector`（式 S4）。
- **波导损耗实测 0.11 dB/mm**：参考件用**常规光栅耦合器**、波导长 3 / 7 / 11 mm（340 nm 全刻蚀），差分法在 1510–1590 nm 取平均（四次测量 0.105 / 0.119 / 0.101 / 0.121 dB/mm）。
- 重叠比 `OR = P_fiber / P_upward` 由场重叠积分给出（式 S9–S11），最终 **`CE_coupler-to-fiber = 0.5·(IL + 10log(OR) − WL)`**（式 S13）——正文 −0.34 dB 即由此式分解而来。
- **边界**：参考件刻意用常规耦合器而非 UGR 耦合器（作者明示是为回避 UGR 设计的复杂度/不确定性），且假定波导均匀。引用 0.11 dB/mm 时必须带上这两个前提。

### S5 层叠耦合效率的测法（式 S14–S18）

- 先测下层耦合器的 fiber-to-detector 链路损耗 IL1，再叠上上层样品测 IL2 → **`CE_coupler-to-coupler = IL2 − IL1 − WL`**（式 S18）。
- 前提：上下耦合器 CE 近似相等；上层用耦合器**阵列**以缩短位移台扫描时间。−0.94 dB 属该分解值。

## 仿真方法

- **COMSOL** "Radio Frequency" 模块，**频域**；能带结构与 Q 用**特征值求解器**。
- 上下不对称比：结构**上方与下方两个 surface probe**。
- 边界：x/y 方向**周期（Floquet）边界**；结构上下 **PML**。
- 波导色散：**Lumerical mode solver**。
- **Lumerical FDTD**：波导左侧 mode source 激励，四周 PML；x-z 二维监视器取电场剖面；空间分布取结构上方 2 µm 处，角分布由监视器**远场投影**得到；CE 由波导左侧监视器收集（高斯入射，MFD 10.4 µm）。

## 制备工艺（SOI 实验）

- 340 nm SOI；**ZEP520A** 电子束胶；**EBL**（Elionix ELS-F125G8，1 nA，500 µm 写场）。
- **ICP**（Oxford）刻蚀，气体 **C₄F₈ / SF₆ / Ar**；**DMAC** 去胶。
- **三轮套刻**：① 定义 B2；② 用第一轮做下的**十字对准标记**套刻 B1（构成 L 形）；③ 再套刻一次把波导/taper **刻穿硅层**。各形状/深度的 ICP 时间分别控制。
- 测试：Santec TSL-550 可调谐激光 **1510–1590 nm**；Thorlabs FDG10X10 光电探测器（10 × 10 mm 大接收面）；层叠测量用 Thorlabs PT3-Z8 三维电动位移台扫描上层芯片；芯片浸于折射率匹配液（Cargille Series A）模拟 SiO₂ 包层。

## 对项目的启示

1. **"上行/下行比"可以靠对称性拿，不必靠反射镜**：本文把 directionality 从层叠工程（`Si-1550:A6` / Q1-12 的底部反射镜 + 匹配层路线）转到**拓扑荷**路线。做 L01/L02 这类"导模→自由空间"器件时，若目标只是单侧辐射，应先问"结构是否存在 UGR/C2 破缺路径"，再考虑增加反射镜层。
2. **对称保护 BIC 是标准厚度友好的起点**：off-Γ BIC 或 void point 路线需要厚膜支撑强带间耦合，与 340 nm（更不用说本项目更薄）SOI 不兼容；对称保护 BIC 在**任何厚度**都驻留 Γ 点，是可移植的构造起点——可与 Q1-05/Q1-06 的 qBIC 选择定则并列使用。
3. **Q ≈ 134 是"故意降低"的**：为换取宽带，本文主动把 Γ 附近 Q 从 ∞ 压到 ~134。这与本项目 L01 追求**高 Q（qBIC）**的目标**方向相反**：同一个 BIC 工具箱，既可做高 Q 窄带，也可做低 Q 宽带单向辐射——选题前先定目标，再选参数区。
4. **变迹同时管两件事**：本文用变迹同时做①动量匹配（压低背散射）②空间/角分布整形（提高与光纤的模式重叠）。这与 `Si-1550:A2` / L01 的"振幅梯度"是同一件事的不同语言——只控相位/方向不解决效率，必须同时做**孔径加权**。
5. **套刻平移容差有实测数字可用**：±30 nm 内 CE 优于 −0.6 dB、±50 nm 内仍 > −1 dB；36 器件 σ ≈ 5 nm 下平均 CE −0.426 dB。可作为本项目**套刻/overlay 误差预算**的对照基准（与 Q1-11 Kühne 的 σ 统计展宽互补：一个针对高 Q 共振，一个针对宽带耦合器）。
6. **效率口径提醒**：本文 −0.34 dB（92.47%）是**耦合器↔光纤（激励端）**的 CE；与 `Si-1550:A2` 的 16%（波导馈电辐射端出耦合）、L02 的 9%/80%（每超胞提取率 / 纯介质理论上限）**不是同一件事**，不可直接比大小（沿用 Q1-12 笔记与工作流 §4 口径表）。
7. **体系差异**：本文是 Si/SiO₂ 高对比平台 + **三轮套刻**；本项目 L01 是 PMMA/Si₃N₄ 弱约束，周期、耦合长度与 Q 敏感度都需按 n_eff 重算（同 Q1-12 结论）。

## 术语易错提示

- **UGR ≠ BIC**：UGR 是"只向单侧辐射"的共振态（上下不对称）；BIC 是"完全不辐射"的束缚态。本文是"BIC 的整数荷分裂成半荷、再在下侧复合 ⇒ 下侧无辐射"——UGR 由 BIC 的拓扑荷衍生，但两者**辐射性质相反**。
- **asymmetry ratio（上下不对称比）** 是 up/down 辐射强度比（本文 η ≈ 65.8 dB），与"耦合效率""方向性 D"不是同一量，别混用。
- **"record-low loss −0.34 dB"** 指**耦合器→光纤（激励端）**的插入损耗，既非器件总损耗，也非端到端链路损耗（后者 −1.24 dB）。
- **overlay lithography** 这里是"**多次套刻**"（本文 3 轮），不是"overlay 层"结构；中文写"套刻 / 叠对光刻"。
- **TE-A 带**是"最低反对称 TE 带"的简写，不是 TE 与 TM 的混合模。

## 1. 一句话总结

在商用 silicon-on-sapphire (SOS) 上做单晶 Si nanodisk 阵列（h=100 nm，周期 110–320 nm）实现反射式结构色：因 Si 本征吸收导致的"宽反射峰 + 背景反射"使色域仅 78% sRGB，引入折射率匹配层（n≈1.48，DMSO 或 PMMA 封装）后 FWHM 收窄约 40%、衬底背景反射压至近零，实测色域达 ~181.8% sRGB / 135.6% Adobe RGB / 97.2% Rec.2020，且 2×2 个 nanodisk 即可形成衍射极限分辨率的像素。

## 2. 研究动机与问题

- 颜料/染料色暗淡、色域小、分辨率差（~25 µm 色点、<1000 dpi）；plasmonic 结构色分辨率可达衍射极限但亮度低、色域小（~45% sRGB）；全介质（如 TiO₂）色鲜艳、亮场可见，但依赖集体共振使分辨率受限（~10⁴ dpi），实验色域纪录仅 68% Rec.2020，且此前混合多层材料体系工艺不兼容、上层在刻下层时变形。
- 没有任何单一种技术同时满足：可制造性、反射率、窄 FWHM、空间分辨率、大色域（UHDTV/Rec.2020 标准）。
- Si 极稳定、CMOS 兼容、可量产、高折射率使单元简单（利于低成本制造），但 Si 可见光有本征吸收，直接做只有宽带反射 + 白背景、小色域（78% sRGB）——本文要"扬长避短"给出 all-in-one 方案。

## 3. 结构设计与关键参数（材料、几何、波长、工艺步骤）

- **材料/衬底**：商用 SOS（蓝宝石上外延单晶 Si，sapphire n≈1.76，可见光透明）；单晶 Si 比 poly-Si、a-Si 可见吸收低得多。
- **单元几何**：Si nanodisk，半径 R + 方晶格周期 l，厚度固定 h=100 nm（薄层缓解本征吸收）；调 (直径/周期) 覆盖全可见，实验组合含 180/320、160/300、150/230、140/220、130/250、90/220、90/180、80/140、60/110（nm），周期/直径减小 → 反射峰连续蓝移。
- **折射率匹配层**：n≈1.48，介于空气(1)与蓝宝石(1.76)之间；以 DMSO 液体（n=1.48，灌注微流道）验证，以 PMMA 旋涂封装做固化成形。
- **波长/谱**：工作 400–700 nm；例：180/320 在空气中 ED@581 nm、MD@609 nm，峰值反射 ~84%（橙色）；短波端反射率下降（~29% @402 nm）。
- 制造：EBL（PMMA A2, MicroChem 写反图）→ Cr 掩模 lift-off → RIE 刻 Si → Cr etchant 去 Cr。

## 4. 工作原理/物理机制（如适用）

- 每个 Si nanodisk 支持电偶极 ED 与磁偶极 MD Mie 共振，选择性反射特定波长；减薄到 100 nm 把本征材料吸收影响降到可接受。
- 色域小的根源有二：①衬底界面产生宽带反射"白色背景"；②反射峰太宽（ED/MD 未重合）。匹配层解决方式：
  - 降低 sapphire/匹配层折射率对比 → 抑制衬底反射背景；
  - ED 场更贴近单元边界、对环境折射率比 MD 更敏感 → 匹配层把 ED 推向 MD、二者干涉（类 Kerker 条件）→ FWHM 收窄 + 峰外反射被相消压制。
- 色与入射角近似无关（SI Note 19）；材料吸收只轻微增加（SI Note 20）；色度按 CIE1931 标准（黑体照明）评估。

## 5. 关键结果与性能数字

- **色域**：空气中实测 78% sRGB → DMSO 中 ~181.8% sRGB、135.6% Adobe RGB、97.2% Rec.2020（实验 108 个样品）；模拟（63 样品、空气）仅 92% sRGB，加匹配层后模拟 ~186% sRGB / 138.7% Adobe RGB / 99.5% Rec.2020。创当时结构色色域纪录（此前最高 68% Rec.2020）。
- **谱形**：DMSO 中主峰 FWHM ~34–40 nm（比空气中窄 ~40%），与 TiO₂ metasurface（~34 nm 量级）相当；衬底背景反射抑制到 ~0；600 nm 处反射 ~76%（亮场下鲜艳）。计算谱中空气环境峰值反射最大 84%（@~600 nm）、402 nm 处降至 29%（实验空气谱 Fig. 3b 亦给出相近的高反射读数）。
- **动态切换**：同一片样品在空气/DMSO 间切换颜色（China pink→Fandango 等 8 组颜色迁移），演示"微流道可调色"；PMMA 封装后的"孔雀"图与 DMSO 态几乎一致（PMMA 可作永久匹配层）。
- **分辨率**：每像素仅 2×2 个 nanodisk，像素中心距黄/绿/蓝/紫 = 320/250/200/190 nm，即 ×100 NA=0.9 亮场显微镜的衍射极限；像素从 5×5 缩到 2×2 颜色不退化（纯色 "Phoenix"、多色 "Rainbow" 演示）；单晶 Si 的色域比 poly-Si 大 110%、比 a-Si 大 238%（Fig. 3d 数据）。
- **演示**：220×260 µm² "Peacock + orchid" 全彩图（每像素 9×9→2×2 disk），DMSO 灌注立即变色且背景近乎全黑。
- **对比口径**：等离子体结构色 ~45% sRGB、分辨率虽高但强度低；此前多材料混合超表面模拟 171% sRGB 而实验仅 ~124% sRGB/68% Rec.2020（上下层工艺不兼容）。

## 6. 制备工艺细节（材料体系/光刻/刻蚀/表征）

- 商用 SOS 晶圆；EBL 在 PMMA A2 (MicroChem) 写**反图** → 蒸 Cr → lift-off 得到 Cr 硬掩模 → RIE（Oxford PlasmaLab 80）刻 Si → 铬刻蚀剂去除 Cr（"Methods"；具体 Si 刻蚀气体配方在 SI Note 10，正文未给）。
- 结构质量（SI）：倾斜 SEM 显示侧壁近 90°、粗糙度 <10 nm——粗糙度/垂直度足以让实测谱与设计吻合。
- 表征：ZEISS Axio Scope AI 亮场显微镜成像；×50 NA=0.55 物镜 + 光谱仪测反射谱；分辨率测试用 ×100 NA=0.9；色度坐标用 MATLAB 计算（CIE1931，黑体照明）；仿真用 Lumerical FDTD 与 COMSOL（周期边界 + PML），Si/sapphire 折射率取材料库（sapphire n 固定 1.76）。

## 7. 与本项目（L01/L02）的关系与可借鉴点

- **PMMA 反图 + Cr lift-off + RIE + 去 Cr 的 Si 图形化链**与 L01（PMMA 体系）直接同源：掩模链思路（PMMA 只做图案化胶、Cr 做硬掩模、湿法去 Cr）可复用到 L01 的 Si₃N₄ 或 L02 的 Si 结构加工；PMMA A2/EBL 剂量-显影参数可作起始工艺卡。
- **"包覆/匹配层改变共振"的重要提醒**：把 n≈1.48 的介质（DMSO/PMMA）加在超表面上方会系统性移动共振峰、收窄线宽并抑制背景——对 L01 的 qBIC 漏波超表面（PMMA 本身既是包层也是结构材料）意味着：器件"封装态"（覆盖 PMMA）与"裸态"的谱/Q 可能显著不同，设计与仿真必须按最终覆盖状态进行，这与"用 PMMA 做匹配/保护层且不影响色彩"的正面结论互相印证。
- **材料纯度/晶相决定损耗**：单晶 Si 色域显著大于 poly/a-Si——支撑 L02 的 Si 波导/谐振器优先用单晶（SOI/外延）材料以保低损耗高 Q；薄膜厚度与吸收的权衡（本文 h=100 nm 缓解吸收）也可类比对 L01 的 Si₃N₄ 膜厚与 Q 的关系。
- **环境折射率灵敏度**：ED 比 MD 更贴近边界、对环境更敏感——该物理对 L01 的"孔/柱共振"同样成立：超表面顶面吸附/氧化层/残留胶都会移动共振，工艺末态的一致性（去胶干净、无残留）必须受控。
- **衍射极限像素的版图启示**：每像素 2×2 单元即可保住颜色 → 小写场/高密度版图（大面积 LWM 版图数据量与写场拼接）可借鉴这种"最少单元数"设计策略。
- 大色域 + 动态切换 + PMMA 封装的应用链（光学防伪/显示）对项目属于背景应用价值。

## 8. 局限性 / 待确认问题

- 反射式工作模式，只适合显示/打印/防伪类应用；正文反射谱由 ×50 NA=0.55 小数值孔径物镜测得，与大面积均匀性/入射角扩展的关联需另查。
- 短波端（蓝/紫）因 Si 吸收上升反射率明显低（402 nm 仅 ~29%），蓝紫色仍偏暗。
- 空气中模拟色域（92%，63 样品）与实验色域（78%，108 样品）存在口径差，正文未统一解释；引用其空气值时应注明出处（模拟 vs 实验、样品数）。
- DMSO 是液体方案，实用性靠 PMMA 封装背书，但正文仅给一张封装对比图；PMMA 的折射率色散、旋涂厚度均匀性对共振的定量影响需项目自行验证。
- SOS 衬底为特殊商用平台（外延 Si 成本高于 SOI），Si 刻蚀气体配方在 SI 中，正文未公开具体参数——若借鉴其 RIE 流程需自行获取/标定。

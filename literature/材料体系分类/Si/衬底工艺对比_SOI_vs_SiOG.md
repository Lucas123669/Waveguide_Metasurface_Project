## 一、两种衬底是什么

| | SOI（Silicon-On-Insulator） | SiOG（Single-crystal Silicon On Glass） |
| --- | --- | --- |
| **层结构** | 底硅衬底 / 埋氧层 BOX（SiO₂，通常 1–2 µm）/ 顶层单晶硅（通常 220 nm 或 340 nm） | 玻璃衬底（整块，~500 µm–1 mm）/ 顶层单晶硅膜（可薄至 50–220 nm） |
| **顶层硅** | 单晶硅（SIMOX 或 Smart-Cut 制备） | 单晶硅（层转移：氢离子注入剥离或阳极键合+腐蚀） |
| **下包层** | BOX 氧化层（薄，1–2 µm） | 整块玻璃（极厚，且透明、绝缘） |
| **底衬底** | 单晶硅（半导体，不透明，有寄生电导） | 玻璃（绝缘体，透明） |
| **供应链** | CMOS 产线主流，200/300 mm 晶圆成熟 | 非 CMOS 主流，面向 Gen 4.5 面板级（730×920 mm） |

> **先排除一个常见混淆（2026-09-11 补）：本项目第一主线「a-Si:H on HPFS 7980」不是 SiOG。**
>
> 两者都含"玻璃 + 硅"，但处在**不同层级**、且**硅的结晶形态不同**：
>
> | | a-Si:H on HPFS 7980（本项目第一主线） | SiOG（本节讨论的外购衬底） |
> | --- | --- | --- |
> | 层级 | **本项目工艺**（自己沉积功能层） | **外购衬底产品**（厂商做好后交付） |
> | 顶层硅 | **非晶** a-Si:H（PECVD 低温直接沉积，无序、含氢、损耗偏高） | **单晶**硅膜（层转移后减薄，低损耗、可长距离导波） |
> | 玻璃角色 | **项目的器件基片**（HPFS 7980，直径 ≤250 mm、`t≥300 µm`） | **衬底内的厚下包层/载板**（0.5–1 mm，消除衬底泄漏、支持超薄硅膜） |
> | 硅从哪来 | PECVD 沉积，无键合、无层转移 | 键合 + 层转移（Smart-Cut 类 / 阳极键合+腐蚀） |
> | 界面能否预置 | 沉积界面，**不能**预置底部光栅/反射镜 | 键合界面，**转移前可预置**底部结构 |
> | 适用光程 | 超表面纳米柱等**短光程**结构（几百 nm–几 µm），非晶硅损耗可接受 | 需要**长距离低损耗导波**、超薄硅膜或有源器件的场景 |
>
> 换句话说：**要不要单晶硅，取决于"光在硅里走多远"。** 只做波前调控的纳米柱用非晶硅即可；要做波导传输、调制器等，才需要 SOI/SiOG 这类单晶平台。
>
> 另注：本页出现两种"玻璃"，含义不同——第一行的玻璃是**熔融石英**（本项目基片，Corning HPFS 7980 一类合成熔融石英），SiOG 的玻璃是**显示面板类玻璃**（厚下包层）。"熔融石英 ≠ 泛指的 SiO₂"的完整对照见 [熔融石英与 SiO₂ 术语差别](../../../docs/reports/fabrication/2026-09-11_熔融石英与SiO2术语差别.md)。

## 二、SiOG 相比 SOI 的核心优势

### 1. 下包层极厚 → 完全无衬底光泄漏（光学核心优势）

- SOI 的 BOX 仅 1–2 µm，在以下场景可能出现衬底泄漏：
  - TM 模、高阶模
  - 超薄硅膜（<100 nm）
  - 较长波长（中红外）
  - 大角度辐射结构（模式向衬底方向耦合）
- SiOG 的玻璃衬底厚度达 ~500 µm–1 mm，作为下包层完全消除衬底泄漏。
- **对项目的意义**：若设计超薄硅膜超表面（<100 nm）或大角度辐射结构，SiOG 可避免 SOI 中可能存在的衬底泄漏损耗。

### 2. 支持超薄纳米硅膜导波

- 浙大 Yang 2005 明确演示：SiOG 可支持 75 nm、130 nm、185 nm 厚的硅纳米膜导波，模式仍被有效约束在硅芯中。
- SOI 中硅膜过薄时，模式会因下包层（BOX）不足而向底硅泄漏，无法有效导波。
- **对项目的意义**：若需要超薄硅膜实现特定共振或场增强，SiOG 是更合适的平台。

### 3. 硅-玻璃界面可预制备微结构/电极

- SOI 的硅-BOX 界面是键合后的内部界面，无法后处理。
- SiOG 在层转移前，可在硅膜底面或玻璃表面预制备：
  - 底部光栅/反射镜
  - 埋层电极
  - 微结构/图形
- **对项目的意义**：若超表面需要底部反射镜、埋层电极或界面光栅，SiOG 的层转移工艺允许在键合前预处理界面，这是 SOI 难以实现的。

### 4. 玻璃衬底电学绝缘 → 无寄生效应

- SOI 底硅是半导体，存在寄生电导/电容，对高速调制器、射频器件不利。
- SiOG 玻璃是优良绝缘体，无寄生电学效应。
- **对项目的意义**：若集成高速调制器或有源器件，SiOG 的电学隔离更优。

### 5. 玻璃衬底透明 → 便于背面光学表征

- SOI 底硅在 1550 nm 不透明（硅有吸收），无法从背面进行光学测量。
- SiOG 玻璃透明，可从背面测量辐射方向图、耦合效率，或进行背面耦合。
- **对项目的意义**：超表面辐射方向图的背面测量更方便。

### 6. 面板级制造 → 潜在成本优势

- Corning 白皮书定位：SiOG 面向 Gen 4.5 面板级（730×920 mm）制造，比 SOI 晶圆（200/300 mm）尺寸大。
- 在 1500–2500 ppi 显示背板场景，SiOG 提供"面板级加工成本优势 + 无晶界高迁移率/高均匀性"的组合。
- **对项目的意义**：若未来需要大面积超表面制造，面板级 SiOG 工艺可能有成本优势。

## 三、SiOG 的局限（客观对比，避免只看优势）

| 局限 | 说明 | 对项目的影响 |
| --- | --- | --- |
| **硅膜表面质量不如商用 SOI** | SiOG 硅膜经 RIE 减薄，表面粗糙度高于商用 SOI 的 prime-grade 表面。Corning 白皮书显示 SiOG TFT 迁移率偏低（172 vs 223 cm²/V·s）且有陷阱态。 | 表面粗糙度散射损耗可能更高；对高 Q 共振结构（BIC/qBIC）不利 |
| **供应链不成熟** | SiOG 不是 CMOS 产线主流，可获得性、工艺兼容性远不如 SOI。Yang 2005 明确说"需要特殊键合+腐蚀工艺，并非 CMOS 产线主流方案"。 | 流片成本高、周期长、工艺窗口窄 |
| **散热较差** | 玻璃热导率（~1 W/m·K）远低于硅（~150 W/m·K） | 对高功率有源器件不利；对无源超表面影响不大 |
| **标准 220 nm SOI @1550 nm 已足够** | 常规 220 nm SOI 波导在 1550 nm，2 µm BOX 通常已足够，衬底泄漏不是主要问题 | SiOG 的"无衬底泄漏"优势在常规场景不凸显，主要在超薄硅膜、长波长、特殊模式才体现价值 |
| **键合/剥离工艺引入额外缺陷** | 氢离子注入剥离可能在硅膜中残留缺陷；阳极键合+KOH 腐蚀可能引入表面损伤 | 需额外的脱氢/退火工艺恢复材料质量 |

## 四、对 1550 nm 超表面项目的选型建议

| 场景 | 推荐衬底 | 理由 |
| --- | --- | --- |
| 标准 220 nm SOI 波导 + 超表面，常规工艺 | **SOI** | CMOS 兼容、供应链成熟、表面质量高、1550 nm 下 BOX 已足够 |
| 超薄硅膜（<100 nm）超表面 | **SiOG** | 无衬底泄漏、支持超薄硅膜导波 |
| 需要底部反射镜/埋层电极/界面光栅 | **SiOG** | 界面可预制备结构 |
| 高 Q BIC/qBIC 共振结构 | **SOI**（优先） | 表面质量高、散射损耗低；SiOG 表面粗糙度可能降低 Q |
| 大面积/面板级制造 | **SiOG**（潜在） | Gen 4.5 面板级工艺，单位面积成本可能更低 |
| 中红外（>2.5 µm）波导 | **SiOG** 或 SOS | SOI 底硅在中红外有吸收，SiOG 玻璃透明 |

## 五、SiOG 是怎么"加工"出来的（两条层转移路线）

> **先分清两件事（2026-09-11 补）**：SiOG 的"加工"指的是**衬底本身的制造**——把**单晶硅膜**转移到玻璃上，属于**厂商工艺**；我们拿到 SiOG 之后要做的图形化（EBL + 硬掩模 + ICP-RIE/氟基刻蚀）与其他硅基平台**完全一样**。本节只讲前者。
>
> 一句话定性：两条路线都是**"先键合、后减薄"的层转移**，**不是**在玻璃上"长"硅——这正是它与本项目第一主线「a-Si:H on HPFS 7980（PECVD 直接沉积非晶硅）」的本质区别。

### 5.1 路线 A：氢离子注入剥离 + 亲水键合（Corning SiOG 主线；与 SOI 的 Smart-Cut 同机理）

| # | 步骤 | 参数 / 要点 |
| --- | --- | --- |
| 1 | 硅片热氧化 | 形成表面氧化物保护/界面层，避免注入损伤留在最终硅膜表面 |
| 2 | **H₂⁺ 离子注入** | **70 keV、2.75×10¹⁶ cm⁻²**；在硅片内部形成**富氢缺陷层**，**注入深度直接决定最终硅膜厚度** |
| 3 | **亲水键合** | 注入面与玻璃贴合（亲水处理 → 范德华接触 → 退火形成共价键） |
| 4 | **热剥离（layer splitting）** | **450–500 °C 退火**，富氢层开裂，硅膜整片转移到玻璃上 |
| 5 | **RIE 减薄** | 减到目标厚度（**220 → 100 → 50 nm**）+ 抛光 |
| 6 | 脱氢 / 退火 | 去除注入残留缺陷与陷阱态，恢复材料质量 |

- 全流程 **<600 °C**（FPD / 面板产线兼容）；可做到 **Gen 4.5（730×920 mm）**面板级；代价是**需要离子注入设备**与专用键合线。

### 5.2 路线 B：阳极键合 + KOH 腐蚀减薄（浙大 Yang 2005）

| # | 步骤 | 参数 / 要点 |
| --- | --- | --- |
| 1 | **阳极键合（anodic bonding）** | SOI 晶圆与玻璃在 **~300 °C、750 V**（同类工艺亦有 400–500 °C、~1 kV）下静电键合：玻璃中 Na⁺ 迁移形成耗尽层与强电场，把硅-玻璃界面拉合成共价键 |
| 2 | **KOH 选择性腐蚀** | 去除 SOI 的底硅，**BOX 层作腐蚀停止层** |
| 3 | **BOE 去 BOX** | 去除埋氧层，露出顶层硅膜 |

- 演示结果：**75 / 130 / 185 nm** 硅纳米膜导波。
- 代价：硅膜厚度由**外购 SOI 的顶层厚度**决定（不够灵活）；KOH 腐蚀引入**表面损伤与粗糙度（RMS ≈3 nm）**；非 CMOS 主流工艺。

### 5.3 两条路线的共同点与三条直接推论

- **共同点**：都是"先键合、后减薄"的层转移；都要额外处理**注入残留缺陷或腐蚀损伤**。
- **推论 1｜界面可预置**：键合发生在图形化**之前**，因此可以在玻璃或硅表面**先做**底部光栅/反射镜/埋层电极再键合；SOI 的 BOX 界面是厂商封在内部的，**不可后处理**。
- **推论 2｜表面质量不如商用 SOI**：SiOG 的硅膜是"**剥离 + RIE 减薄**"得到的，不是原生抛光表面，且有注入/腐蚀残留缺陷。证据：Corning 白皮书 TFT 迁移率 **172 vs SOI 223 cm²/V·s** 且存在陷阱态；中文文献 RMS **≈3 nm**。→ 对高 Q 的 BIC/qBIC 结构不利。
- **推论 3｜本项目不会自己造 SiOG**：项目实际做法是"**若需要就外购衬底**"，我们自己只做拿到衬底之后的图形化；第一主线 a-Si:H on HPFS 7980 属于**自沉积**，SOI 与 SiOG 都属**外购平台**。

> 术语提醒：SiOG 的离子注入剥离与 **SOI 的 Smart-Cut** 是同一种机理（氢注入 + 键合 + 热剥离），差别只在**键合对象**——SOI 键合到硅衬底上（中间形成 BOX），SiOG 键合到**玻璃**上。别把两者混为一谈，也**不要**把 SiOG 与 SOS（silicon-on-sapphire，蓝宝石）混淆。

## 七、一句话总结

**SiOG = SOI 的单晶硅芯 + 极厚透明绝缘下包层 + 可预处理界面**，代价是表面质量和供应链成熟度。对 1550 nm 超表面项目：常规场景 SOI 更务实；超薄硅膜、底部结构、中红外等场景 SiOG 有明确价值。

# A11｜Wang 2019｜Advanced Optical Materials 7(4)

## 论文信息

- **题目**：Compact Silicon Waveguide Mode Converter Employing Dielectric Metasurface Structure
- **期刊 / 年份**：*Advanced Optical Materials* **7**(4), 1801191 (2019)（在线发表于 2018-12-14；DOI 显示 1801191 为该刊 2019 卷期，部分库著录为 2018）
- **DOI**：[10.1002/adom.201801191](https://doi.org/10.1002/adom.201801191)
- **单位**：上海交通大学区域光纤通信网与新型光通信系统国家重点实验室（通讯：张永 / 苏翼凯）
- **本地原文**：[A11 PDF](pdfs/A11_Wang_2019_Silicon_Mode_Converter_Dielectric_Metasurface.pdf)
- **定位**：A 组（波导集成 / 片上辐射）。SOI 波导内嵌全介质超表面结构实现模式转换，与 C1 综述 §4.2 模式调控、C3（片内 Jones 矩阵超表面）同属"波导内超表面操控导模"路线。

## 一句话总结

在 SOI 硅波导芯层内刻出**倾斜亚波长周期微扰**（平行四边形全介质超表面结构），利用周期性介电微扰的波导模式耦合理论，实验实现 **TE₀→TE₁**（耦合长度 5.75 µm）与 **TE₀→TE₂**（6.736 µm）模式转换：转换损耗 <1 dB（TE₁）/ <0.5 dB（TE₂），串扰 <−10 dB，工作带宽约 20 nm（1542–1563 nm / 1545–1565 nm）。

## 核心机理与设计

- **模式耦合原理**：波导中周期性介电微扰 Δε(x,y,z) 使 TE₀ 与 TEⱼ 模式耦合，耦合系数 κ₀ⱼ 由两模式场分布与微扰的重叠积分决定；满足相位匹配（布拉格条件）时能量周期性交换，耦合长度由 κ 决定。
- **结构**：倾斜（平行四边形）亚波长微扰单元，周期 Λ = 400 nm、周期数 n = 5、波导宽度 w = 1100 nm；TE₀→TE₂ 用两段微扰（间距 δ = 5.535 / 3.229 µm）。**倾斜**是为了引入纵向（z 向）梯度相位，等效于"graded perturbation"，可灵活调控模式耦合强度与相位匹配。
- **工艺**：单次蚀刻（深度 70 nm），特征尺寸 <50 nm（θ = 11.3° 时），CMOS 兼容；测试端口用光栅耦合器（损耗 7.7 dB/port）+ 非对称方向耦合器做模分（解）复用器回读。

## 关键结果（原文可核对）

- TE₀→TE₁：耦合长度 5.75 µm，转换损耗 <1 dB，串扰 <−10 dB（1542–1563 nm）。
- TE₀→TE₂：耦合长度 6.736 µm，转换损耗 <0.5 dB，串扰 <−10 dB（1545–1565 nm）。
- 制造容差仿真：角度、周期、蚀刻深度、宽度扰动下的损耗与串扰（图 5）。
- 对比此前方案：LiNbO₃/Si₃N₄ 上硅纳米天线仿真 ~10 µm、其他方案 23 µm——本文把实验耦合长度压到 <7 µm。

## 对项目的启示

1. **波导内超表面 = "浅蚀刻周期微扰"**：与 C3（LNOI+α-Si 柱全参量 Jones）不同，本文是 SOI 直接蚀刻（70 nm 浅蚀）实现模式转换——工艺更简单，是"片内超表面"的低成本实现路径。
2. **倾斜微扰提供 z 向相位梯度**：与 C1 精读笔记中 φ(x)=β(x)+Δφ(x) 的检查思路一致——倾斜结构是给周期微扰加连续相位渐变的通用手段。
3. **与项目接口**：若项目需要"片上模式整形/高阶模激励"（如 FMF 耦合、A9 简并模式的模式调控），A11 提供可直接复用的设计参数与实验模板。

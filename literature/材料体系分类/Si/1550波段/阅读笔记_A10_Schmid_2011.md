# A10｜Schmid 2011｜Optics Letters 36(11)

## 论文信息

- **题目**：Temperature-independent silicon subwavelength grating waveguides
- **期刊 / 年份**：*Optics Letters* **36**(11), 2110–2112 (2011)
- **DOI**：[10.1364/OL.36.002110](https://doi.org/10.1364/OL.36.002110)（Doc. ID 145382）
- **单位**：加拿大国家研究院 NRC（J. H. Schmid 等）+ Carleton University；SWG 领域奠基团队（Cheben/Halir/Schmid 系）。
- **本地原文**：[A10 PDF](pdfs/A10_Schmid_2011_Temperature_Independent_SWG_Waveguides.pdf)
- **定位**：A 组（波导集成）。SWG（亚波长光栅/超材料波导）**无热化**奠基实验，1550 nm 波段 Si 波导温度稳定性的经典范例。

## 一句话总结

利用亚波长光栅（SWG）的**空间等效折射率平均**效应，把 Si 波导芯切成 Si + SU-8 聚合物（负热光系数）周期交替的复合芯，在 1550 nm 测得最低热光（TO）系数 **1.8×10⁻⁶ K⁻¹**——比常规 Si 光子线波导低两个数量级，接近完全无热化。

## 研究动机与问题

- Si 热光系数高（dn_Si/dT = 1.8×10⁻⁴ K⁻¹）→ 干涉仪、谐振器、波分器件对温度敏感（典型 ~70 pm/°C 波长漂移），需要精密控温。
- 既有无热化路线：负 TO 聚合物**上包层**补偿（靠模式与包层重叠）或 **slot 波导**（场集中到低折射率聚合物窄缝）。
- 本文新原理：**SWG 空间平均**——把 Si 芯周期性切缝、缝内填负 TO 聚合物，让"等效芯折射率"由 Si/聚合物占空比加权，从而直接工程化整个芯层的 TO 系数。

## 结构设计（关键参数）

- 工作波长：λ = **1550 nm**（测量覆盖约 1525–1575 nm，50 nm 谱窗）。
- 波导：SWG 复合芯 = 交替 Si 块 + SU-8 缝；宽度 470 nm，光栅周期 250 nm（< λ/2，等效介质条件）；实测占空比（duty cycle）46% / 56% / 64% / 66%，对照 100%（即普通光子线）。
- 衬底：商用 **SOI**，0.26 µm 顶层 Si / 2 µm 埋氧（BOX）。
- 材料折射率：n_Si = 3.476，n_SU-8 ≈ 1.58（@1.55 µm），n_SiO2 = 1.444；TO 系数：dn_Si/dT = +1.8×10⁻⁴ K⁻¹，dn_SU8/dT = **−1.1×10⁻⁴ K⁻¹**。
- 器件：非平衡 **MZI**（马赫-曾德尔干涉仪），上臂插入 ΔL = 3 mm 的 SWG 段；wire 波导经绝热耦合器（参考文献 [9] 的 coupler 结构）过渡到 SWG，验证两类波导同片兼容。

## 工作原理与物理机制

- **SWG 等效介质**：周期 < 有效工作波长的一半 → 光的精细结构不可分辨 → 衍射被抑制，基模为束缚 Bloch 模（原理上无损），光学行为等效于"芯折射率被空间平均"的通道波导。
- **TO 补偿**：复合芯的有效热光系数 ≈ Si/聚合物按占空比与场重叠加权的平均。降低占空比（更多聚合物）→ 有效 TO 系数下降 → 过零（无热化）→ 反号（负 TO）。
- **测量原理**：MZI 透射谱 I = cos²(k0/2 · n_eff · ΔL)，由透射谷随温度位移 dλ/dT 反推 TO 系数：dn_eff/dT = (n_g/λ)·(dλ/dT)，群折射率 n_g = λ²/(Δλ·ΔL)。

## 关键结果（原文可核对）

- **1550 nm 最低实测 TO 系数 1.8×10⁻⁶ K⁻¹（duty 64%）**，比光子线波导（1.8×10⁻⁴ K⁻¹）低 **2 个数量级**。
- TE 偏振：duty 100%（光子线）+70 pm/°C；duty 46% 变号（负漂移）；~65% duty 接近无热化（线性拟合给出 1576 nm 处完全无热化）。
- TM 偏振：所有实测 duty 下 TO 系数仍为负（未到无热化），但符号反转说明无热化存在于 duty 66%–100% 之间；数值预测无热化 duty **85%（TM）** vs **61%（TE）**——TM 模垂直方向更离域、与 SU-8 上包层重叠更大，需更高 Si 占比补偿。
- 数值（MIT Photonic Bands，Bloch 模求解器）：对同一结构升温 20 K 重算色散，dn_eff/dT 与实验吻合良好，并预测占空比足够低时可**完全抵消** Si 温度依赖。

## 制备工艺（原文可核对）

- EBL 定义图形 → **ICP RIE**（SF6 / C4F8 混合气体）刻蚀 Si 层；2 µm 厚 SU-8 旋涂 + 标准烘烤成包层/缝填充。
- 测试：芯片贴温控铜热沉，透射谱随温度扫描；线波导与 SWG 用绝热耦合器过渡。

## 对项目的启示

1. **Si 波导温漂的工程解**：本项目若做 MZI/滤波/波分类器件（含超表面波导），SWG+负 TO 聚合物是无源无热化首选路线；1550 nm 波段下 SU-8（n≈1.58，TO=−1.1×10⁻⁴ K⁻¹）参数可直接入设计。
2. **SWG 等效介质是本项目通用工具**：A9 用 SWG 做色散简并、A10 用 SWG 做无热化——同一亚波长周期结构可按需切换"等效介质 / 色散工程"两种角色，元胞库设计时应同时记录两种视图。
3. **工艺兼容提醒**：SU-8 填充对 CMOS 后端（BEOL）兼容性有限（聚合物），若项目要求全 CMOS 工艺，可考察其他负 TO 材料或改用结构补偿（如双层、狭缝）方案——这与 L03 里 PECVD SiN 低温工艺的"可集成性"评估是同一套取舍逻辑。
4. **表征方法可复用**：非平衡 MZI + 温控台测 dλ/dT → dn_eff/dT，是无热化验证的标准做法，项目实验阶段可直接照搬。
5. **口径提醒**：本文"无热化"指**有效折射率**温度无关（dn_eff/dT = 0），不包含热膨胀（Si 热膨胀系数很小，通常可忽略），引用数据时口径要写清楚。

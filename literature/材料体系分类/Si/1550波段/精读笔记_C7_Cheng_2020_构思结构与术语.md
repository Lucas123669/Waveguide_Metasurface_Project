## 一、作者的构思：为什么写、以什么视角写

### 1.1 问题背景（论文要解决的痛点）

硅光子学（silicon photonics）要在低成本量产的同时提供高性能，核心难题之一是**接口**：

- 片上波导截面只有 **几百纳米**（典型 400–500 nm）；
- 单模光纤（SMF）模场直径 MFD ≈ **10 µm @1550 nm**；
- 二者模场严重失配 → 光纤↔芯片耦合是硅光的"老大难"。

耦合方案两条路线：

| 方案 | 机理 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **端面耦合（edge / butt coupling）** | 光纤对准芯片端面，经**倒锥（inverse taper）**绝热扩模 | CE 高、带宽大、PDL 低 | 需高质量抛光端面（增成本）、占地大、只能放芯片边缘、对准容差低、**无法晶圆级测试** |
| **光栅耦合器（grating coupler, GC）** | 光纤置于芯片上方，靠表面光栅衍射实现面外↔面内波矢转换 | 位置任意、紧凑、制造简单、**可晶圆级测试** | CE 较低、对波长和偏振敏感（本文两大主线） |

> 作者立场很明确：**GC 是"灵活性 + 可测性"的首选**，本文的任务就是系统综述"怎么补上 GC 在 CE、波长、偏振上的短板"。

### 1.2 写作视角：以"性能短板"为主线的系统综述

与一般"按时间罗列进展"的综述不同，本文的组织逻辑是**问题驱动**：

1. 先建"物理语言"（§2：布拉格条件、损耗通道、波矢图、SWG 等效介质）；
2. 再用这套语言逐项解决三个核心短板（§3 CE → §4 偏振/波长）；
3. 再打开新维度（§5：空分复用、逆向设计、新材料平台）；
4. 最后落地工程（§6：测试、封装、应用）。

每个性能维度都遵循同一种"**机理分析 → 解决方案分类 → 对比表**"结构——读者能学到的不是孤立器件，而是一套**可迁移的设计决策框架**。

## 三、内容递进（每节核心逻辑）

### §2 基础：先给"物理语言"

**2.1 布拉格条件（Bragg condition / 相位匹配）**

$$k_0 \sin\theta + mG = \beta_m$$

- $k_0 = 2\pi/\lambda$ 入射光波矢，$\theta$ 光纤倾角，$G = 2\pi/\Lambda$ 光栅矢量，$m$ 衍射级次，$\beta_m$ 波导传播常数。
- **波矢图**（k-vector diagram）把上式画成矢量三角形，是判断"哪个衍射级次被允许"的第一性工具。
- **为什么光纤要倾斜（θ ≈ 8–10°）**：完全垂直入射（θ=0）时，m=+1 与 m=−1 对称 → 光**双向耦合**（一部分进波导、一部分往反方向走），且二阶衍射产生强烈背反射 → CE 大幅下降。倾斜打破对称，牺牲"垂直封装便利"换取效率。

**损耗通道分解**（本文最重要的分析框架）：

- 输入耦合：$P_w = P_{in} - P_{sub} - P_r - P_{w2}$
  - $P_{sub}$：向下泄漏进衬底（**衬底泄漏**，可通过 BOX 厚度/底部反射器回收）
  - $P_r$：向入射相反方向反射（**背反射**）
  - $P_{w2}$：耦合进与目标相反方向的功率（垂直入射时最严重）
- 输出耦合：$P_{out} = \eta (P_w - P_t - P_r)$，其中 $\eta$ 是**模式重叠积分**（光栅向上辐射场与光纤高斯模的重叠）。

> 由此 CE 提升只有两条路：**① 提高方向性**（directionality = 向上辐射功率占比，减少 P_sub/P_r）**；② 提高模式重叠**（modal overlap，让辐射场分布更像高斯）。§3 整章都是这两条主线的展开。

**2.2 亚波长光栅（SWG）与等效介质理论**

- SWG = 周期 $\Lambda \ll \lambda$ 的光栅，衍射被抑制，整体表现为**均匀介质**。
- 等效折射率用 **Rytov 表达式**：
  - TE：$n_{TE}^2 = f n_1^2 + (1-f) n_0^2$（$f$ = 填充因子/占空比）
  - TM：$n_{TM}^{-2} = f n_1^{-2} + (1-f) n_0^{-2}$
- 价值：**等效折射率工程**——只需改变占空比/周期，就能连续调节 neff，避免精细控制蚀刻深度。SWG 由此实现：单次全蚀刻的耦合器（SWGC）、渐变耦合器、宽带耦合器、无热化波导（本项目 A10）、MMI 等。

**2.3 过渡锥形与聚焦 GC**

- 光栅宽度 ≈ MFD（~10 µm）→ 必须**绝热过渡（adiabatic taper）**到 400–500 nm 单模波导，条件：$\theta_{taper} < \lambda / (2 W n_{eff})$；直线 taper 通常 300–500 µm 长。
- **聚焦 GC**：把光栅线弯成椭圆（$m\lambda = n_{eff}\sqrt{x^2+y^2} - x n_0 \sin\theta$），省掉长 taper，占地缩到几十 µm。代价：多边形逼近增加散射损耗，需平衡扇形角 α_s。

### §3 效率提升：两条主线的展开

**3.1 附加制造工艺 → 方向性**

- **多晶硅 overlay**：蚀刻前先沉积 poly-Si 加厚齿部 → 上下辐射的散射中心相位差可调 → 向上相长、向下相消（~−1.6 dB 实测）。
- **底部反射器**：把向下泄漏"回收"再向上——金属镜（Au/Al，flip-chip + BCB 键合，亚 dB 级）或 DBR（层数受限）或 **Si 光栅反射器**（SiN-on-SOI 多层平台，最优雅，−1.3 dB / 80 nm）。
- 作者明确说：**迄今所有实测亚 dB GC 都用了底部反射器** → 方向性天花板在工艺而不在原理。

**3.2 光栅结构创新 → 模式重叠（apodization）**

- 均匀光栅辐射场沿 x 指数衰减（$G(x)=G(0)e^{-\alpha_0(x-x_0)^2}$），与高斯光纤模不匹配 → 损耗大。
- **变迹（apodization）**：沿 x 变化耦合强度 α(x)，使辐射包络逼近高斯。实现手段：变**占空比** Δf、变**周期**、两者结合；SWG 则变填充因子（等效折射率渐变）；也有蚀刻深度渐变（利用 ICP-RIE 的 lag 效应）。
- 代表：Benedikovic 2015 单步蚀刻 SWG 渐变 −2.16 dB / 64 nm（本项目上一轮检索已列）。
- **z 向复杂度**：双蚀刻深度（方向性 >95%，但需亚 10 nm 级对准）、倾斜光栅（需 FIB，不可量产）、双层光栅。

### §4 偏振与波长多样性

**4.1 偏振分集**

- SOI 双折射强 → GC 偏振选择性强，而 SMF 输出偏振漂移 → 接收端必须"偏振不敏感"。
- **PSGC（偏振分束光栅耦合器）**：
  - 1D PSGC：TE/TM 用 m=+1/−1 耦合进相反方向波导；
  - 2D PSGC：两个正交 1D GC 组合，任意偏振分解为两个正交线性分量分别进两个波导 TE0，**总功率对偏振不敏感**（入射面转 45° + 保持倾斜）。
- 单向偏振不敏感：用 SWG 等效介质消除双折射（TE/TM neff 拉近），或用厚 SOI 降低双折射，或 T 型/非均匀光栅逆向设计。

**4.2 波长分集**

- 1-dB 带宽推导：$\Delta\lambda_{1dB} = C \cdot NA \cdot \frac{\lambda_0 n_0 \cos\theta_0}{n_{eff} - n_0 \sin\theta_0}$
- 宽带手段三招：**降 neff**（换 SiN、SWG 工程）、**让光纤接受更大角色散**（高 NA 光纤、Si 棱镜补偿，126 nm 带宽演示）、**最小化 dneff/dλ**。
- 双波长带（PON 场景 1310/1490/1550 nm）：用 2D PSGC 两正交方向不同周期、1D PSGC m=±1 反向、或 TE/TM 双模带耦合。

### §5 新兴趋势

- **空分复用（SDM）**：多芯光纤（MCF）→ 多个 GC 阵列按芯距排布；少模光纤（FMF）→ 高阶 LP 模耦合——多个独立 GC 各控相位、TE1 波导模式直接出 LP11、非均匀光栅内建 π 相位差。
- **逆向设计（objective-first）**：目标驱动优化（突破直觉器件极限、省研究人力）；缺点——高分辨率图案依赖 EBL、3D-FDTD 算力大、GC 必须接口 10 µm MFD 与"紧凑化"矛盾。
- **新平台**：多层 SiN（低损耗、可沉积、z 向复杂度天然可行、易配底部反射器）；等离激元 GC（金属周期槽激发表面等离激元 SPP，超紧凑、适合传感）。

### §6 工程实际

- **晶圆级测试**：GC 使 dies 在晶圆上即可光学质检，省封装成本；光纤探针有偏振控制、探针损伤、位置要求三大问题；用 Mueller 矩阵法 4 个固定偏振态快速测 PDL。
- **封装**：垂直 pigtail（g-Pack 标准、8° 倾斜角）vs **角度抛光光纤横向耦合**（机械强度好、占地小，v-groove 三点接触）。
- **应用**：PIC 光纤 I/O（省功率预算、多通道）；片上光源↔波导耦合（InP DFB 经双 GC 接 SiN）；多层 PIC 层间耦合；生物传感（消逝波灵敏、正交传播提高信噪比）；LiDAR（OPA 相位阵列的 GC 发射单元 + 近场 apodization 优化远场波束）。

## 四、专业术语表（按出现顺序，面向本项目读者）

| 术语 | 英文 | 一句话解答 |
| --- | --- | --- |
| 端面耦合 | edge / butt coupling | 光纤从芯片端面水平对准波导，靠倒锥绝热扩模匹配模场；效率高但需抛光端面、不能晶圆级测试 |
| 倒锥 | inverse taper | 波导宽度向端面逐渐收窄，光约束减弱、模斑放大到接近光纤模 |
| 模场直径 | mode field diameter (MFD) | 光纤中基模强度分布的横向尺寸，SMF @1550 ≈ 10 µm |
| 光栅耦合器 | grating coupler (GC) | 芯片表面周期光栅，把面外入射光衍射进面内波导（或反之） |
| 布拉格条件 | Bragg / phase-matching condition | k0 sinθ + mG = β：决定哪个衍射级次能耦合，是 GC 的第一性判据 |
| 波矢图 | wave-vector diagram | 把布拉格条件画成矢量三角形，直观判断耦合方向与级次 |
| 传播常数 | propagation constant β | 波导模式沿传播方向的波矢分量，β = neff·k0 |
| 光栅矢量 | grating vector G | 2π/Λ，指向周期变化方向 |
| 衍射级次 | diffraction order m | 整数，对应不同衍射方向；GC 常用 m=±1 |
| 方向性 | directionality | 向上（朝光纤）辐射功率占总辐射功率的份额，P_up/P_w；CE 的核心因子 |
| 模式重叠 | modal overlap | 光栅辐射场与光纤高斯模的重叠积分，CE 的第二个核心因子 |
| 衬底泄漏 | substrate leakage | 向下穿过 BOX 漏进衬底的功率（P_sub），可被底部反射器回收 |
| 背反射 | back reflection | 向入射相反方向反射的功率（P_r），与二阶衍射/光栅对称性相关 |
| 双向耦合 | bi-directional coupling | 垂直入射时 m=±1 对称，光同时往两个方向走（P_w2），降低单路效率 |
| 光纤倾角 | fiber tilt angle | 光纤相对法线倾斜约 8–10°，打破对称性以提升 CE |
| 数值孔径 | numerical aperture (NA) | 光纤/光学系统接受角的正弦，NA 越大带宽越大（Eq. 12） |
| 偏振相关损耗 | polarization-dependent loss (PDL) | 不同偏振态下损耗的差异，接收端要求 PDL 小 |
| 亚波长光栅 | subwavelength grating (SWG) | 周期远小于波长的光栅，无衍射、整体像均匀介质（等效折射率） |
| 等效介质理论 | effective medium theory | 用 Rytov 公式把 SWG 近似为均匀介质，TE/TM 各一套公式 |
| 填充因子 / 占空比 | fill factor / duty cycle f | 光栅材料占一个周期的比例，决定等效折射率与耦合强度 |
| 变迹 / 渐变 | apodization | 沿传播方向调制耦合强度，使辐射包络匹配高斯模、提升模式重叠 |
| 耦合强度 | coupling strength α | 单位长度衍射功率的比例；均匀光栅 α 恒定 → 指数衰减辐射 |
| 绝热过渡 | adiabatic transition | 模式尺寸/形状渐变而不辐射、不转换高阶模的过渡，能量守恒 |
| 聚焦光栅 | focusing GC | 光栅线弯成椭圆，把 10 µm 模斑直接聚焦进窄波导，省长 taper |
| 多晶硅覆盖层 | poly-silicon overlay | 蚀刻前沉积的 poly-Si，加厚齿部、调上下辐射相位差提升方向性 |
| 底部反射器 | bottom reflector | 金属镜 / DBR / Si 光栅，把向下泄漏反射回收；目前亚 dB 级 GC 的标配 |
| 双蚀刻 | dual-etch | 顶层硅两种蚀刻深度，z 向不对称提升方向性；需纳米级套刻对准 |
| 倾斜光栅 | slanted grating | 齿侧壁倾斜的 GC，方向性好但需 FIB 制造，不可量产 |
| 双层光栅 | dual-layer grating | 上下两层光栅叠加，z 向复杂度、可提升 CE/偏振不敏感 |
| 偏振分束光栅耦合器 | polarization splitting GC (PSGC) | 把 TE/TM 分到不同波导（1D）或两个正交 TE0（2D），实现偏振不敏感 |
| 双折射 | birefringence | 材料/波导对 TE、TM 折射率不同；SOI 强双折射 → GC 偏振敏感 |
| 1-dB 带宽 | 1-dB bandwidth | CE 相对峰值下降 1 dB 的波长范围；GC 通常 <50 nm |
| 双波长带 | dual-wavelength-band | 两个分离波段（如 1310/1550）同时耦合，供 PON 收发 |
| 少模光纤 | few-mode fiber (FMF) | 支持少数几个横模（LP01/LP11…），用于空分复用 |
| 多芯光纤 | multi-core fiber (MCF) | 一根光纤内多根纤芯，用多个对准的 GC 阵列接口 |
| 空分复用 | space-division multiplexing (SDM) | 用空间信道（模式/纤芯）扩容 |
| 模分复用 | mode-division multiplexing (MDM) | 用不同横模携带独立信道 |
| LP 模 | linearly polarized mode | 弱导光纤中近线性偏振的近似模式（LP01/LP11a/LP11b/LP21） |
| 逆向设计 | inverse design / objective-first | 以目标性能为优化函数反推结构，突破直觉设计极限 |
| 表面等离激元 | surface plasmon polariton (SPP) | 金属-介质界面传播的表面电磁波，强约束、超紧凑、适合传感 |
| 晶圆级测试 | wafer-level testing | 芯片在晶圆上未切割时即完成光学测试，GC 的关键优势 |
| 主动对准 | active alignment | 边发射边微调光纤位置找最大耦合功率的对准方式 |
| g-Pack | g-Pack packaging | ePIXpack 的标准化 GC 垂直耦合封装（玻璃块磨 8° 角装于 v-groove） |
| 角度抛光光纤 | angle-polished fiber | 光纤端面磨成斜角实现横向（侧向）耦合，机械强度好 |
| 无源光网络 | passive optical network (PON) | 点到多点光纤接入网，上行 1310 nm / 下行 1490/1550 nm |
| 光相控阵 | optical phased array (OPA) | 多通道相位控制实现波束偏转，GC 作发射/接收单元 |
| 激光雷达 | LiDAR | 车载/机器人测距方案，需要低损耗大角度波束偏转 |

## 五、对项目的启示（可执行）

1. **布拉格条件是第一性检查工具**：本项目任何"波导→自由空间辐射"设计（漏波、超表面出射）都应先用 $k_0\sin\theta + mG = \beta$ 与波矢图核对相位匹配方向与级次，再谈效率（对应 C1 精读中建议的 φ(x)=β(x)+Δφ(x) 检查）。
2. **效率分析用"损耗通道分解"**：把 CE 拆成方向性 × 模式重叠 × 背反射 × 衬底泄漏，逐项找瓶颈——本项目 SOI 平台要注意 BOX 下方衬底泄漏（可借鉴底部反射器思路，或评估 SOS 平台如 A9）。
3. **apodization 是辐射包络整形通用手段**：不只是 GC 用——本项目若要把波导超表面的辐射远场/近场整形（如 OPA 发射单元、L02 导波驱动超表面），变占空比/周期/耦合强度这一套直接可迁移。
4. **SWG 等效介质与 A10/L03 呼应**：Rytov 公式（TE/TM 分开）是 SWG 波导、无热化、模式色散工程（A9 简并）的共同数学基础，可并入项目"SWG 元胞库"理论文档。
5. **宽带三招可复用**：降 neff（SiN/SWG）、高 NA/棱镜补偿角色散、min dneff/dλ——项目若做宽带辐射器件，先按这三类评估。
6. **综述引用闭环**：本文 [55] Taillaert 2004（本项目 Q1-12 同作者）、[34] Benedikovic 2015（上一轮检索的 −2.16 dB 单蚀 SWG）、[19-28] 垂直耦合、[46] Sacher SiN-on-SOI 双层——可作为后续选读/入库的候选清单。

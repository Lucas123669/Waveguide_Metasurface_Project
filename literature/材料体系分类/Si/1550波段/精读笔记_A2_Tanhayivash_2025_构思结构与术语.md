## 一、作者的构思：为什么写、站在什么立场写

### 1.1 一句话的问题意识

> **给 PIC 做一个"紧凑、任意角度、效率尽量高"的耦合器——而且要用纯硅做，还要顺手解决前人没管的"振幅下降"问题。**

### 1.2 问题是怎么被一步步逼出来的（Introduction 四步推导）

| 步骤 | 作者的逻辑 | 通俗解释 |
| --- | --- | --- |
| ① 需求 | PIC 集成度快速上升，需要把成像/发射系统也搬到片上 | 片上光路要有"出口" |
| ② 耦合器的三条硬指标 | **尽量紧凑** + **能耦合到任意角度** + **效率接近 1**（否则整个 PIC 的插损被拖住） | 三项同时满足才算可用 |
| ③ 现有方案不够 | **端面耦合**与**表面光栅**"不具备 PIC 所需的通用性"，尤其**自由空间光必须接近法向入射**这一点在特定场景成为限制；效率与紧凑性只能二选一 | 光栅耦合器的老问题（与我们 Q1-12 笔记里的判断一致） |
| ④ 两侧的空白 | 自由空间超表面控制力强，但**绝大多数必须由平面波驱动**、离不开自由空间，难与片上器件集成；已有的"导模驱动超表面"工作（偏振控制、空间耦合、模式路由、模式转换、频率转换）**多半不与硅光子兼容**——因为用了**金属**（吸收损耗），而且**背散射大** | 即：能做的不用硅、用硅的又没管背散射与振幅 |

### 1.3 本文的两个主张（novelty 就这两条）

1. **全硅（Si-bar）超胞**：元原子完全由硅条构成 → **与标准硅光子工艺兼容、没有等离激元吸收**。
2. **同时控制相位与振幅（phase *and* amplitude gradient）**：作者明确指出，前人（其引用 27，即我们库里的 **L02 / A8 Guo 2020**）**没有讨论"振幅下降"问题、也没有给出补偿办法**。本文用**分段变振幅**补偿波导内衰减，换来两个可量化的结果：
   - **出耦合效率 8% → 16%（翻倍）**；
   - 焦面 **FWHM 从 >2.8 µm → 893 nm**（作者称"几乎达到衍射极限"）；
   - 并且**背散射几乎被消除**。

### 1.4 论证策略（这篇最值得学的三点）

1. **"先做理想设计、再看哪里坏、再修"的叙事**：§"1D metalens"先用**等振幅 2π 三单元**做一版，Fig. 7 看出"**末段出光弱**"→ 归因**波导衰减**→ 才引出 §"Amplitude gradient"。**不是一上来就给最优解**，而是让读者跟着"发现缺陷"的过程走。
2. **一套公式贯穿两种功能**：Eq. 1–5 同时支撑"偏转"与"聚焦"——`Φ(x)=βx+φ_s(x)` 是全篇骨架，聚焦只是把 Φ 换成透镜相位后**求差**。
3. **把"连续变迹"离散成"分段"**：amplitude gradient 用**三个 category（各自一套 bar 尺寸）**近似，工程上可用"EBL + 沉积 + CMP"重复实现；并且**主动指出继续增加段数收益递减**（接近衍射极限后提升可忽略、复杂度上升）——这是**诚实且实用**的结论。

### 1.5 作者主动声明的边界（引用时必须照抄）

- **纯数值**：FDTD（Ansys Lumerical），**没有实验**；数据集"on reasonable request"（未公开）。
- **未考虑非线性**（原文明确："we have not considered nonlinear effects such as Si third order nonlinearity"），因此 16% 与输入功率无关。
- **效率定义**：**出耦合光功率 / 输入波导功率**（"ratio between outcoupled light power to the input light power to the waveguide"）。
- **口径警告（作者自己提的）**：**"不要拿它和光栅/棱镜耦合器直接比"**——后者成熟几十年。

## 三、内容的递进（每节核心逻辑与关键数字）

### 3.1 设计理论（Design theory）

$$\phi(x)=\beta x+\phi_s(x)\qquad k_x=\frac{\partial \phi}{\partial x}=\beta+\frac{\partial \phi_s(x)}{\partial x}\qquad \theta=\sin^{-1}\!\left(\frac{\beta+\partial\phi_s/\partial x}{k_0}\right)$$

- 超胞提供线性相位梯度 `∂φ_s/∂x = −2π/Λ`（**3 个硅条**，相邻相位差 **2π/3**）→

$$\theta=\sin^{-1}\!\left(\frac{1}{k_0}\left(\beta-\frac{2\pi}{\Lambda}\right)\right)$$

- **平台**：**220 nm 厚硅平板波导（slab）+ SiO₂ 衬底**；激励模式 **TE₀₀**，求解器给出的**模态指数 `n_mode = 1.92`**；
- **元原子**：硅条（silicon-bar），**同时支持两个共振**（本文指出 bar 支持两个谐振模式）；Fig. 2 的 `Ey / Hx` 分布显示 **ED 与 MD 特征同时存在**——作者称"两次共振的重叠对 2π 相位覆盖与高散射效率至关重要"（与 L02 的 MDM 双共振逻辑同源，但这里**没有金属**）；
- **参数扫描**：Fig. 3 给出振幅与相位随 `Lx`（沿传播方向尺寸）与 `Lz`（高度）的彩色图，取三个横向尺寸 `Ly = 750 / 1000 / 1200 nm`；作者结论：**相位主要受高度与长度影响**；
- **选点准则**：从图中挑 **三组"振幅大致相同、相位间隔 2π/3、合起来覆盖完整 2π"** 的几何（Fig. 3 中白圈①），Fig. 4 用辐射场验证了 `2π/3` 间隔。

### 3.2 偏转可行性（Fig. 5）

- `Λ₁ = 1250 nm → 光束偏右`；`Λ₂ = 1000 nm → 近乎垂直`；`Λ₃ = 850 nm → 偏左`；
- 逻辑闭环：**Λ 越小 → `2π/Λ` 越大 → 括号里的余量越小 → 出射角越接近法向甚至反向**（与 Eq. 4 的形式一致）。

> **本笔记的核算与一处待核对（重要）**：把 `n_mode = 1.92` 代入 Eq. 4，λ = 1550 nm 时
> `Λ=1250 → θ = sin⁻¹(1.92 − 1.24) = +42.7°`、`Λ=1000 → +21.7°`、`Λ=850 → +5.5°`（**三者都偏同一侧**）。
> 但原文描述为"右偏 / 近垂直 / **左偏**"。若要让 Λ=850 nm 真的左偏（θ<0），需要 `β/k₀ < λ/Λ = 1.824`，即**有效折射率约 1.6** 而非 1.92。
> → 可能原因：**1.92 是"裸平板"的模式指数，未含 Si 条加载的影响**；或原文对 Fig. 5 的方向描述是示意性的。**引用角度数值前必须回查原文图与模式设置。**

### 3.3 聚焦设计：先做"等振幅版"，暴露问题（Fig. 6–7）

- 透镜相位 `φ(x) = −k₀√(f²+x²)`，扣掉传播相位后硅条需要提供：

$$\phi_s(x)=-k_0\sqrt{f^2+x^2}-\beta x$$

- **排布**：共 **17 个超胞，分三段**——`5 × Λ₁ = 1100 nm` + `4 × Λ₂ = 1000 nm` + `8 × Λ₃ = 850 nm`（**用分段的 Λ 逼近双曲透镜相位的局部梯度**，这是"相位梯度离散化"）；
- 目标 **f = 7500 nm @ 1550 nm**；
- **结果**：Fig. 7 显示"可接受的聚焦"，但**末段（最后一段）出光明显偏弱** → 作者归因：**光沿波导传播被衰减，后段拿到的光本来就少**。

### 3.4 振幅梯度：本文的核心贡献（§"Amplitude gradient"）

- 思路：既然后段入射振幅小，就让**后段的硅条散射得更强**——从 Fig. 3 再选 **第二套（黑圈②）与第三套（红圈③）**尺寸：**各自仍覆盖完整 2π，但出射振幅更高**；
- **Table 1** 给出三套共 **9 个硅条**的尺寸（单位 nm，全部位于 220 nm 硅波导上方）：

| | 第 1 类（5 超胞） | 第 2 类（4 超胞） | 第 3 类（8 超胞） |
| --- | --- | --- | --- |
| `Lx1 / Ly1 / Lz1` | 80 / 750 / 730 | 80 / 1000 / 900 | 65 / 1200 / 900 |
| `Lx2 / Ly2 / Lz2` | 180 / 750 / 570 | 180 / 1000 / 580 | 180 / 1200 / 760 |
| `Lx3 / Ly3 / Lz3` | 175 / 1200 / 930 | 175 / 1200 / 930 | 190 / 1200 / 1000 |

- **Fig. 8**：把"波导内振幅随传播的衰减"与"三段出射振幅"画在同一张图上，作者称**波导损耗被完全补偿**；
- **结果（Fig. 9–10）**：聚焦清晰；焦面 FWHM **893 nm**（初版 **>2.8 µm**）；
- **效率 16%**（出耦合/输入，纯仿真、与功率无关，未含非线性），并归因于两点：**纯硅结构** + **振幅梯度**；
- **Fig. 11**：段数越多焦斑越好，但**接近衍射极限后收益递减**、且复杂度上升 → **建议适可而止**。

### 3.5 波长敏感性："beam squinting"（Fig. 12）

- 讨论 **1450 / 1550 / 1600 nm**；
- 机理解释（原文式）：波长变长时 `k₀` 与 `β` **同时变小** → 硅条**设计相位小于所需相位** → **焦点向输入端口移动**；短波长则相反；
- 作者的推广结论：**"想要的主束指向可以通过工程硅条参数（即选 Λ）获得，而不必依赖改变工作波长"**，因此该方法可用于**降低超表面的 beam squint**。

### 3.6 制备流程（作者在正文末尾给出，虽无实验）

1. 从**硅层足够厚的 SOI** 出发 → 常规光刻 + 刻蚀做**波导**；
2. 对**每一套尺寸**的硅条：涂胶 → **EBL 图形化** → **PECVD/LPCVD 沉积硅** → 必要时 **CMP 平坦化**；
3. **对九组不同尺寸/高度的硅条重复上述整套流程**（→ 这是本文最重的工艺代价，也正是它选择"分段"而非连续变迹的原因）。

## 六、对项目的启示（可执行）

1. **"振幅梯度"必须写进我们的设计流程**：本项目做辐射器件时，`Φ(x)=βx+φ_s(x)` 只解决**相位/方向**；要效率就必须同时给**孔径加权**。这与 L01 补充材料里"1 mm 理想渐变设计可达 99% 表面发射"、以及 Q1-12 的 GC 变迹是**同一件事的三种说法**。
2. **"分段"是最现实的制造折中**：连续变迹在元胞库与版图上都难落地；A2 用**3 段 × 3 套尺寸**就把 FWHM 从 2.8 µm 打到 893 nm，说明**少量分段即可拿到大部分收益**（Fig. 11 也给出"收益递减"的量化趋势）。
3. **纯硅 vs 金属：重述我们已有结论**：A2 把效率从 8% → 16% 的两个归因之一是"**去掉金属**"；这与 L02 里 Au/SiO₂/Au 的 9% 上限、纯介质方案 80% 的理论值**互相印证**——**金属是效率的直接上限**。
4. **不要与光栅耦合器比效率**（作者自己提醒）：16% 是**波导馈电辐射端**的出耦合效率；Q1-12 的 92% 是**光纤–波导耦合器**的层叠优化值，两者**分母与任务都不同**（详见对照文档）。
5. **报告"指向"时要给三件套**：`dθ/dλ`（squint）、孔径长度、出耦合效率——只看焦点 FWHM 不足以评价 LiDAR/通信发射端（A2 恰好三件都给了，可作为我们的报告模板）。
6. **Si-bar 可直接作为全介质单元库的第一版起点**，但要补：3D 全波（含侧壁角/线宽偏差）、真实 Si 色散与损耗、以及与本项目平台（**玻璃上 a-Si:H** 而非 SOI 220 nm 晶硅）的折射率/约束差异。
7. **模式指数要"加载后"重算**：本文暴露的问题（§3.2）提醒我们——**裸波导的 `n_eff` 与"加了元原子之后"的有效折射率不同**，`Λ` 的选取必须以加载后的 `β` 为准（我们的 COMSOL 流程应把这条写成检查项）。

## 七、局限与待确认

- **全篇为数值结果**：无实验、无工艺公差分析、数据集不公开；**任何效率/焦斑数字都不能当作已实现指标**。
- **效率口径要写全**：16% 是"出耦合/输入"，**未声明是否扣除反射与背散射**（虽然正文称背散射"几乎消除"）。
- **焦斑与衍射极限的核对（本笔记粗算，待回查）**：若取孔径 ≈17 超胞 × 约 0.85–1.1 µm ≈ 15–17 µm（半宽 ≈8 µm）、f = 7.5 µm，则 `NA ≈ sin(tan⁻¹(8/7.5)) ≈ 0.73`，**高斯近似衍射极限 FWHM ≈ 0.51λ/NA ≈ 1.08 µm**；而本文报 **893 nm**，已略小于该极限。按 T1 笔记的判据（见 [T1 精读 §四](../../TiO2/1550波段/精读笔记_T1_Bayati_2019_构思结构与术语.md)），**"焦斑小于衍射极限"通常意味着能量被搬到旁瓣**，或使用了不同的极限/收集口径。→ **引用 893 nm 时必须同时说明口径**。
- **§3.2 的角度方向与 `n_mode = 1.92` 不自洽**（右偏/近垂直/左偏 vs 公式给出三个同侧角）→ 需回查原文的 β 取值与加载效应。
- **"beam squint" 用词**：原文把"**焦点随波长移动**"也归入 squinting 讨论；严格说 **beam squint 多指主束指向随波长漂移**，而**焦点沿轴向移动**属色差/焦移。引用时建议分开表述，避免概念混淆。
- **平台差异**：A2 的硅条长在 **220 nm 晶硅 slab（SOI 体系）**上；我们第一主线是**玻璃上 PECVD a-Si:H**，`n_eff`、损耗机制与热膨胀环境都不同，**参数不能直接照搬**。
- **制备代价被低估**：Table 1 的 9 组尺寸意味着**多轮"沉积 + CMP + EBL"**，套刻与平坦化误差会直接破坏"振幅梯度"的设计意图——这是 A2 未量化但我们必须评估的风险。

## 八、术语易错提示（三条）

1. **amplitude gradient ≠ 相位梯度**：前者是**孔径加权（变迹）**，决定"哪里出光多"；后者决定"往哪个方向出"。**两者必须同时设计**，只看相位梯度会把效率锁死。
2. **16% 不是"耦合效率"**：它是**波导馈电辐射端**的出耦合效率（分母是输入波导功率）。与 Q1-12 的 **92%（光纤–波导耦合器理论值）**、L02 的 **9%（每超胞提取率推出的上限）** 都**不可直接比大小**。
3. **893 nm 焦斑要带口径**：这是**仿真焦面 FWHM**；是否归一化、是否含旁瓣、衍射极限怎么定义，都会改变结论（对照 T1 的 FWHM 与极限口径讨论）。

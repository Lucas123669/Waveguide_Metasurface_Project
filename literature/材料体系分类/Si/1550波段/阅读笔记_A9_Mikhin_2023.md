# A9｜Mikhin 2023｜Nano Letters 23(6)

## 论文信息

- **题目**：Coherent control of topological states in an integrated waveguide lattice
- **期刊 / 年份**：*Nano Letters* **23**(6), 2094–2099 (2023)（正文=预印本 arXiv:2210.01648v1，17 页，含 Methods）
- **DOI**：[10.1021/acs.nanolett.2c04182](https://doi.org/10.1021/acs.nanolett.2c04182)　[arXiv:2210.01648](https://arxiv.org/abs/2210.01648)
- **单位**：ITMO University（圣彼得堡）+ CUNY 先进科学研究中心（纽约）+ 马丁-路德大学（Halle）；通讯 M. A. Gorlach
- **本地原文**：[A9 PDF](pdfs/A9_Mikhin_2023_Coherent_Control_Topological_States.pdf)
- **定位**：★A 组（波导集成 / 片上辐射）。严格说它不是"超表面辐射"器件，而是**硅亚波长结构波导阵列 + 拓扑光子学**实验；但因使用 SWG（亚波长光栅/超材料波导）同族结构、工作在 1550 nm 通信波段，作为拓扑光子平台进入本专题。

## 一句话总结

不依赖晶格对称性，而是通过**单个硅纳米波导内两个模式（HE11 与准 TE01）的偶然简并**，在 SOS（蓝宝石上硅）亚波长结构波导阵列中实验实现拓扑边缘态；利用边缘态"两个波导模式叠加"的混合本质，用左右两个单模总线波导的相对相位实现边缘态/体态的**实时相干切换**，并用三倍频（THG）成像定量表征场分布。

## 研究动机与问题

- 传统拓扑光子结构（zigzag 链、breathing honeycomb/kagome 等）的拓扑性来自**晶格对称性**，需要特殊几何；晶格难以动态修改 → 拓扑态及其局域长度难以实时控制。
- 替代路线：利用单个元原子**偶然简并（accidental degeneracy）**的模式——简并模式的近场干涉调控相邻元原子耦合，模式失谐控制拓扑相变（理论见 Savelev & Gorlach, PRB 2020）。此前纳米尺度实验一直缺失。
- 本文首次把该策略做成**集成光学实验**：让每个波导同时支持两个简并模式（不同近场对称性），由此产生 Floquet 拓扑相与拓扑边缘态。

## 结构设计（关键参数）

- 工作波长：λ ≈ **1.55 µm（电信波段）**；拓扑 gap 中心 1555 nm，边缘态实验窗口约 1530–1600 nm（~50 nm），1560 nm 处局域最明显。
- 平台：**SOS（silicon-on-sapphire）**，600 nm 器件层 Si（衬底蓝宝石，近红外透明、与 Si 高折射率差）。
- 波导：从均质 Si 脊波导周期性切出缝隙 → 亚波长周期结构波导（SWG 家族），缝隙宽度调制模式色散。
- 几何参数（图 2a）：h = 600 nm（Si 厚度），wx = 605 nm（波导宽度），wz = 205 nm（缝隙宽度），dx = 790 nm（x 向周期），dz = 300 nm（z 向缝隙周期）；阵列 7 根波导 + 边缘延伸波导。
- 两个被简并的模式：**hybrid HE11**（磁场以 x 分量为准）+ **准 TE01**（磁场以 z 分量为准）；二者 Ez 场强差异大 → 改变缝隙宽度时色散位移不同 → 通过优化在 1.55 µm 使色散分支相交（图 2b 绿线）。
- 耦合/激励：边缘波导两侧各接一条**单模总线波导（SMWG）**，宽度设计为其基模色散穿过两个模式的交点；每个 SMWG 经线性 taper + 全刻蚀光栅耦合器从远场（衬底侧）入射（图 4b）。
- 相干控制配置：左右耦合器同时以 π/2 相位差激发，E_tot = E_r cos(φ/2) + i·E_l sin(φ/2) → 等效于两个波导模式带 φ 相位差叠加（E1·e^(iφ/2) + E2·e^(−iφ/2)）。

## 工作原理与物理机制

- **偶然简并 → 拓扑相**：两个不同对称性（相对 Oyz 面反射的奇偶性不同）的简并模式，其线性组合场强关于波导轴强烈不对称 → 直接改变与相邻波导的倏逝耦合强度 → 形成波导阵列的 bulk/edge 态；色散 kz(kx) 出现 gap，Zak phase 非零（Floquet 拓扑相；严格模型见正文 SI 与紧束缚模型）。模式失谐超过临界值（取决于耦合强度）→ gap 闭合、退化为平凡相。
- **混合本质（hybrid nature）**：边缘态 ≈ E1 + E2（同相）——场在阵列边缘外侧形成热斑、向晶格体内方向几乎为零，与体内解耦；体态 ≈ E1 − E2（反相）——场在边缘波导处被强烈抑制、向晶格体内耦合（图 2c、图 1b）。
- **相干控制**：混合本质使边缘态可以被**选择性激发**——从右耦合器入射 → 同相叠加 → 边缘态；从左耦合器入射 → 反相叠加 → 体态；两端口间连续调相位 → 边缘态 ↔ 体态连续过渡（图 3 数值）。
- **波长调谐局域**：gap 宽度随波长变化（1555 nm 附近最大），扫波长可把拓扑模式从边缘紧局域切换到全域离域。

## 关键结果（原文可核对）

- 数值：7 波导有限阵列存在边缘态色散（图 2b 红曲线）；图 3 显示同相激发场集中于边缘、反相激发几乎完全离域。
- 实验（THG 成像，图 4c–h）：耦合器 1 入射 → THG 信号强局域在阵列边缘（边缘态，1530–1600 nm 出现，**1560 nm 最显著**）；耦合器 2 入射 → 相位差反转 → 波衍射进体内（体态）。
- 失谐增大 → THG 信号下降（方向耦合器带宽限制）；更大失谐 → 拓扑 gap 闭合，两端口都只激发出体态（平凡相，见 SI）。
- 表征方法：THG（三倍频）信号 ∝ 基频场三次方 → 对强局域场有极佳空间分辨；配合 OPA（250 fs Yb 泵浦，1 MHz）宽谱调谐 + 短通滤波 + CCD 成像。

## 制备工艺（原文 Methods）

- 衬底：SOS（Universitywafers 采购），600 nm 器件层；丙酮超声 + IPA 清洗 → O2 plasma 5 min → 热板 180 °C 10 min 除气。
- 光刻：230 nm **HSQ** 掩模旋涂（5000 rpm 60 s，85 °C 烘 2 min）；**EBL**（JEOL 100 keV，1 nA）；绝缘衬底防充电 → 表面先涂 10 nm 导电聚合物（Allresist Electra 92），曝光后去离子水去除，195 °C 后烘 2 min；TMAH 25% 显影 70 s + DI/异丙醇清洗。
- 刻蚀：**ICP RIE**（Oxford PlasmaPro 100 Cobra），HBr 20 sccm / Ar 10 sccm，2 min 30 s（ICP 1500 W / RF 40 W / 8 mTorr）；缓冲 HF 去除掩模残余。
- 器件：线性 taper + 全刻蚀光栅耦合器（衬底侧激励）；CMOS 兼容工艺总路线。

## 对项目的启示

1. **SOS 平台进入视野**：本项目 Si 材料家族（a-/p-/m-Si、SOI/SOS）中，A9 是 SOS 的 1550 nm 实验范例——蓝宝石衬底近红外透明且折射率低，辐射器件可衬底侧出光；对比 SOI（BOX 1–2 µm）的衬底泄漏问题，SOS 是值得评估的替代平台。
2. **SWG 的双重用途**：同一族亚波长周期波导既能做"等效介质"（A10 无热化），也能做"模式色散工程 + 简并"（A9 拓扑）；对本项目 SWG 元胞库设计是重要旁证。
3. **相干控制思路可迁移**：用两个输入端口的相对相位切换输出状态（边缘/体）——与 L02（Guo 2020 波导驱动超表面）"从端口/相位控制辐射"的接口相通，可作为"片上多端口相位调控辐射"的参考范式。
4. **THG 表征手段**：近红外波导内场分布可用非线性（THG）成像可视化，对超表面波导近场验证有借鉴价值（需评估材料非线性与本项目 Si 波导功率预算）。
5. **谨慎边界**：A9 不是辐射型（漏波/出射）器件，其"拓扑保护"与本项目"辐射控制"目标不同轨；借鉴其 SWG 色散工程与相干控制机制即可，勿把拓扑鲁棒性直接等同于辐射效率。

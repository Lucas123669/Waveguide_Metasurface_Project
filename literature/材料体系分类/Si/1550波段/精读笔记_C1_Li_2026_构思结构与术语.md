## 2. 作者构思（综述的"立论骨架"）

**① 问题意识**：硅光子学（SiPh）和超表面各有短板——
- SiPh 优势：CMOS 兼容、高折射率差强约束、大规模集成、有源调制/开关成熟；短板：间接带隙→弱发光、弱电光效应→差光-物质相互作用与非线性、缺乏亚波长尺度的动态调控机制。
- 超表面优势：亚波长控制振幅/相位/偏振/光谱；短板：被动静态（几何一经确定即固定）、无有源可调、缺乏系统级集成接口与能量效率。
- 结论：两者**互补性天然成立**，集成是"必要"而非"可选"（原文 necessity）。

**② 分类洞察**（全文最核心的独创贡献）：以往综述只谈器件，本文从**物理构型 + 耦合机制 + 制造时序**三个维度提出统一分类：
- off-chip（超表面与芯片空间分离、自由空间/光纤耦合，作用域=远场）→ 再按对准策略细分；
- on-chip → 三型：**hybrid-type**（独立制造后键合/粘贴组装）、**on-type**（芯片表面/波导之上直接制造，近场倏逝耦合）、**in-type**（嵌入波导层/器件内部，空间重叠最大）。
- 关键判断：**结构不是随意可互换的**——波导类型决定最合适的集成类型（见 §2.4 兼容性矩阵）。

**③ 两大贯穿性框架**：
- 相位机制分类（共振/PB/传播/复合）→ 作为超表面设计的"功能基元"；
- 应用按**光场变换方向**分类（自由空间→芯片耦合 / 片上导模操控 / 导模→自由空间辐射）→ 对应全信息链。

**④ 叙述策略**：原理（§2）→ 工艺（§3）→ 应用（§4）→ 展望（§5），用"模式变换与传播控制"统一各章节，便于读者按图索骥。

## 5. 各章关键内容与可核对数字

### §2.1 四类波导（硅光子学核心概念）
| 波导 | 约束机理 | 关键公式/判据 | 特征与代价 |
| --- | --- | --- | --- |
| **TIR 全内反射**（最主流） | 折射率差 + 全内反射（Snell、临界角 θc=arcsin(n2/n1)） | 倏逝衰减 E(z)∝e^(−κz)，κ=κ0√(n1²sin²θ−n2²)，式(1) | 低损耗、CMOS 兼容；场弱向外延伸（数百 nm）→ 适用于耦合器/微环/传感 |
| **PhC 光子晶体** | 周期折射率调制 + 光子带隙 + 缺陷态导模 | 布拉格条件 2d·sinθ=mλ；Maxwell 本征方程 ∇×(1/u)∇×E=(ω/c)²εE，式(2) | 色散工程强、慢光、场增强>100×；设计不当有辐射损耗、带宽窄 |
| **表面波 SPP/SPhP** | 界面电磁耦合（金属-介质 / 极性晶体-介质） | βSPP=k0√(εmεd/(εm+εd))，Drude 模型，式(3)；βSPhP 用洛伦兹振子 ε⊥(ω)，式(4)(5) | 深亚波长压缩（>λ0/100）、强局域；欧姆损耗、传播长度短 |
| **SWG 亚波长光栅** | 等效介质均匀化（周期 Λ<λ/(2neff)，Maxwell-Garnett） | 相位匹配 β=k0neff·sinθ+m·(2π/Λ)，式(6)；泄漏条件 β<k0·nclad | 可调 neff 梯度、泄露波辐射；介于常规与共振之间 |

### §2.2 四类相位机制 + 补充
- **广义斯涅尔定律**（Capasso 2006 范式）：nt·sinθt − ni·sinθi = (1/k0)·dφ/dx，式(7)——功能由"局域相位梯度"决定，与形貌解耦；dφ/dx→0 时回归经典斯涅尔。
- **共振相位**：靠共振频率附近陡峭相位响应（0→π 甚至 2π），Q 因子越高相位越陡；带宽窄、效率低（早期），Huygens/Kerker 条件匹配阻抗后改善。
- **传播相位**（truncated waveguide 截断波导法）：φ=(2π/λ)·neff·d，靠柱尺寸（直径/宽高）调 neff；高折射率材料、高深宽比；Arbabi 六角晶格硅纳米柱金属透镜为代表；对线偏振可独立调 x/y 相位。
- **PB/几何相位**：各向异性柱旋转 θ，圆偏振转换通道获得 ±2θ。Jones 矩阵推导（式 8–10）：J(θ)=R(−θ)diag(tu,tv)R(θ)，JLR(θ)=½(tu+tv)+½(tu−tv)·exp(2iσθ)；φPB=±2θ，或 Poincaré 球包围立体角 φPB=−½Ω(C)。波长不敏感、制造简化（同一几何只转角度）；只对圆偏振输入工作。
- **复合相位**：PB（旋转）+ 传播（尺寸）联合 → 双圆偏振独立 2π 控制（Capasso 组 PRL 2017）；支持 Jones 全参量。
- **补充机制**（文中提及但未展开）：quasi-BIC 相位、exceptional point 拓扑相位、detour phase——均被归类为"已用于片上集成但非主流分类"。

### §2.3–2.4 集成机制与兼容性
- off-chip 对准三策略：**主动对准**（六轴台+光电监测，亚微米到百纳米级，慢/贵）、**被动对准**（预制对准标记+红外显微，微米级，可量产）、**片上光学反馈监测**（对称小探测器监测散射功率→闭环校正，精度近主动、可补偿热漂移/振动）。
- **兼容性矩阵**（§2.4 核心结论）：
  - TIR 波导 → 首选 **in-type**（直接刻 SWG 做有效折射率工程，宽带/低损/2π/弱偏振依赖）；on-type 可行但需补偿弱倏逝场；hybrid/off-chip 不优。
  - PhC 波导 → 首选 **in-type**（缺陷/带边工程内嵌相位控制）；on/hybrid/off-chip 不适用（场束缚在内部周期结构中）。
  - 表面波 → 首选 **on-type**（纳米天线直接放界面，共振/PB 机制最匹配）；in-type 不兼容。
  - SWG → **in-type 天然超表面**；on-type 冗余；hybrid/off-chip 可在百 µm 尺度"空间解耦"。

### §3 工艺（三型 + 工具链）
- **工具链全景**：DUV 193nm ArF（量产主力，相移掩模/浸没→亚 100 nm）、EUV 13.5nm（单次曝光）、EBL（原型/复杂拓扑，串行慢）、RIE/ICP-RIE（CF4/SF6/O2 各向异性刻蚀，侧壁粗糙度控制）、纳米压印 NIL（周期结构量产）、3D 异质集成（SiO2-Si 介质键合 / Cu-Cu 热压，InP 激光器/LN 调制器）、FIB（单步减材，Ga+ 铣削）、激光直写/干涉光刻。
- **hybrid-type 工艺**：芯片（PECVD 功能层→DUV 图形→RIE/ICP-RIE→SiO2/PMMA 上包层→CMP 平坦化）+ 超表面芯片（熔石英/蓝宝石衬底上多晶硅/高折射率介质→EBL→ICP-RIE）→ 两种键合：**等离子辅助键合**（O2 活化→200–400°C 退火成共价键）与 **BCB 粘合**（苯并环丁烯旋涂→部分固化→层压→终固化）。例子：SU-8 缓冲层 OPA 芯片上做双层超表面（Wang/Lee 组）、PDMS 缓冲+键合（Afridi）。
- **on-type 工艺**：与 hybrid 前段相同，CMP 时将上包层减薄到数百 nm 增强垂直耦合 → 沉积（PECVD/异质集成/微转印）→ EBL/NIL 图形 → RIE 转移 → 去胶。例子：Rao（Si3N4+Si 双层 PECVD 单片）、Fang（LNOI 上 300nm a-Si PECVD + C4F8/SF6 刻蚀，**与 C3 同工艺链**）、Wang（SOI 上直接刻超表面+光栅耦合器）。
- **in-type 工艺**：直接在功能层（Si/SiN/LN 薄膜）刻亚波长结构（槽/孔/晶格），RIE/ICP 转移，去胶，可再镀保护层；CMOS 后道兼容，集成密度/机械稳定性最高，但设计灵活性与相位范围受限。
- **选型权衡**：in（密度/稳定最高，灵活度最低）→ on（多一层材料，相位范围扩）→ hybrid（最灵活、可独立优化，但键合界面对准/损耗）→ off（最自由，紧凑度差）。

- 有源相位梯度：ITO-MIM 180°/2.5 V/30%、10 MHz 级光束切换；双栅 303°/6.5 V/89%；
- 慢光 PhC：Kondo 光栅辐射 600 µm 长、23° 控制、发散 0.23°、~0.8°/nm；Tamanuki 固定波长热光 40°×8.8°、12800 点；OPA：16 光栅 14.1° 起步 → 非均匀阵列 80°；64×64 纳米天线单片阵（576×576 µm）；Lee 双向光栅+超表面双合透镜 3 倍扫描、0.461°/nm；port-selective OPA 80°×7°；Wang LNOI Galilean 双透镜 1.54× FOV；
- 光谱仪：She 波导耦合滤波器阵列（1.15×24.5 µm/通道，C 带 50 pm 分辨率）；Zhang 五层折叠数字 metalens 100×100 µm、0.14 nm/35 nm；Xiong 可重构超表面 CMOS 快照超光谱（在体脑血流成像）。

**4.7 金属超表面与 SPP**
- Lin 偏振不变量定向 SPP 耦合器（孔径列阵）；Chen 中红外 SEIRA：Si 波导+等离激元纳米棒 2 µm²、60 倍增强、ER>20 dB、检测单层分子膜；Wang spoof SPP（THz）PB+共振双机制：60% 绝对效率、聚焦 30%/偏转 35%；Xu spoof SPP 发射器；银单晶双曲超表面负折射/无衍射；Xu slit-pair SP 全息：相位+振幅同控、5 倍对比度、<20% 串扰。

### §5 展望
- **非硅平台互补**：InP（增益/激光）、薄膜铌酸锂 TFLN（电光/非线性）——不替代 Si 而是补自由度；
- 2D 材料（石墨烯等）动态调控；BIC/exceptional point 非厄米物理入片；
- 四大方向：①动态可重构（相变/电光/MEMS+SiPh）②量子超表面 ③AI/拓扑/全局优化设计 ④新材料（III-V、铁电、相变）组合；
- 现存挑战：材料与工艺兼容（热膨胀失配、键合界面缺陷、纳米图形复现性）、散射损耗、有源调谐集成、局域热管理。

## 6. 术语表（重点名词解答）

| 术语 | 解答 |
| --- | --- |
| **TIR waveguide（全内反射波导）** | 靠芯/包层折射率差（n1>n2）与入射角>临界角把光约束在芯层。硅光子学最主流结构（条形波导、脊波导），场在边界以指数衰减延伸数百 nm（倏逝场），可做耦合、传感。 |
| **PhC waveguide（光子晶体波导）** | 周期折射率结构形成光子带隙（特定频率禁带），人为引入缺陷（线缺陷=波导通道）。色散可工程化（慢光：群速度剧降→光-物质作用增强），但带边色散陡→带宽窄、对无序敏感。 |
| **SPP（表面等离激元极化激元）** | 金属-介质界面上自由电子与电磁场耦合振荡的界面模，垂直方向指数衰减、沿界面传播；可压缩至亚波长（λ0/100 量级），但金属欧姆损耗大、传播长度短。 |
| **SPhP（表面声子极化激元）** | 极性晶体（SiC、hBN、AlN）中红外光子与光学声子耦合的界面模，损耗低于 SPP，用于分子指纹光谱、辐射冷却。 |
| **SWG（亚波长光栅）** | 周期 Λ 小于 λ/(2neff) 的光栅：衍射被抑制，等效为均匀介质（等效介质理论），neff 由占空比精确调控。式(6) 相位匹配下可做泄漏辐射（与项目 A10 无热化波导、Taillaert 光栅耦合器同源）。 |
| **广义斯涅尔定律** | Capasso 2006 提出：界面相位突变（梯度 dφ/dx）重写折射/反射定律，功能由局域相位梯度而非累积光程决定，是超表面的理论基础。 |
| **共振相位** | 用共振（局域 Mie/等离激元、或集体晶格共振）附近陡峭相位实现 0–2π；Q 高则相位范围大但带宽窄；Huygens/Kerker 阻抗匹配后透射效率提升。 |
| **传播相位** | "截断波导法"：相位=(2π/λ)neff·d，由柱尺寸调 neff。直观、宽带、对线偏振可分别调 x/y 相位；需高折射率+高深宽比。 |
| **PB phase（几何相位）** | 各向异性单元旋转 θ，圆偏振转换通道得 ±2θ 相位；与波长无关，只用旋转角编码。注意：只对圆偏振输入有效；φPB=−½Ω（Poincaré 球立体角）。 |
| **复合相位** | 旋转（PB）+尺寸（传播）联合：两个圆偏振可独立获得 2π 相位（Jones 全参量的基础，C3 即用此类思路+detour）。 |
| **detour phase** | 单元相对格点面内位移产生的相位（≈2π·δ/P），C3/L01 中用作额外自由度；本文归入"补充机制"。 |
| **in-type / on-type / hybrid-type** | 集成三型：嵌入波导层内 / 制造于芯片表面（倏逝耦合）/ 独立制造后键合。决定场重叠、耦合强度、工艺时序与对齐难度。 |
| **CMP（化学机械抛光）** | 把上包层减薄至数百 nm，增强波导与表面超表面之间的垂直/倏逝耦合（on-type 关键步骤）。 |
| **等离子辅助键合 / BCB 粘合** | hybrid 集成两种键合：O2 等离子活化+退火成共价键（强、热稳定、适合热敏感材料）；BCB 旋涂粘合（容忍热膨胀失配）。 |
| **EBL / DUV / EUV / FIB / NIL** | 电子束光刻（原型、慢）/ 深紫外光刻（量产主力）/ 极紫外光刻（更小特征单次曝光）/ 聚焦离子束（单步减材铣削）/ 纳米压印（周期结构低成本量产）。 |
| **HCTA（高对比度透射阵）** | High-Contrast Transmit-array：高折射率对比度介质结构阵列（本文用作 1D 片上 Fourier 变换/模式变换元件）。 |
| **PBS / PR / PBSR** | 偏振分束器 / 偏振旋光器 / 分束+旋光一体器件；PDM（偏振复用）系统的核心元件。 |
| **MMI / 定向耦合器 DC / Bloch 模** | 多模干涉（自成像原理分束/耦合）/ 相邻波导倏逝耦合 / SWG 周期结构中的布洛赫传播模（可调 neff 与偏振选择性）。 |
| **模式转换器 / MWB / 波导交叉** | 高阶模式生成与转换（MDM 模分复用）/ 多模波导弯（减小弯曲区模式失配与串扰）/ 片上波导网络交叉节点。 |
| **4f 系统 / 空间傅里叶变换** | 两透镜+中间频谱面构成的光学信息处理架构；片上用 metalens 实现傅里叶变换，中间层编程做卷积/微分/积分。 |
| **OPA（光学相控阵）** | 波导阵列+相位梯度控制光束指向，非机械扫描；本文梳理了 1D→2D、均匀→非均匀阵列（抑制多级衍射）、64×64 单片等演进。 |
| **慢光波导** | 色散工程使群速度大幅下降（PhC/光栅结构），提高相位调制效率与波长灵敏度（LiDAR 波长扫描 0.8°/nm）。 |
| **spoof SPP** | 金属亚波长波纹结构在低频（微波/THz）模仿真实 SPP 的界面模，把等离激元概念拓展到无金属色散限制的频段。 |
| **计算光谱仪** | 用多个响应不同的滤波器/超表面通道 + 重建算法反演光谱（如 50 pm 分辨的波导耦合滤波器阵列、折叠 metalens 网络）。 |
| **in-sensor computing** | 把光学计算（如卷积）集成进图像传感器像素层，光敏阶段直接完成特征提取（超表面光谱滤波 CMOS）。 |

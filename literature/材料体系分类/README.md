# 材料体系视图

本目录按材料提供文献浏览入口。它是**可多选视图**，不是互斥归档：同一篇论文可以同时属于 Si、SiN、PMMA、TiO₂ 或通用交叉视图。

## 使用规则

- PDF 只保留一个物理位置；其他视图使用相对链接引用。
- 同一 DOI 只维护一份规范笔记；旧笔记路径保留为兼容页。
- 材料、波段、主题、用途和期刊级别是彼此独立的字段。
- A/B/C/D/T 是专题内部历史架位码；跨目录引用必须带专题前缀，例如 `Si-1550:A8`。
- 全部规则和交叉归属示例见 [文献多维分类索引](../多维分类索引.md)。

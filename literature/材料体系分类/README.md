# 材料体系分类（超表面波导任务）

> 建立日期：2026-09-01
> 分类维度：**顶层超表面材料体系**（Si / SiN / PMMA / TiO₂），即超表面图案层所用的材料。PDF 保持原位（`literature/` 下 L/Q1/F 原结构），本目录只提供分类索引，不复制大文件。

## 分类规则

- 每篇文献有一个**主体系**（最能指导该体系的设计/工艺）与若干**相关体系**（文中涉及）。
- 主体系详见对应子文件夹 README；相关体系仅在各子文件夹"相关文献"中列出编号。
- 物理/方法/综述类（BIC 物理、选择定则、逆设计、泄漏波、制造综述等）归入"通用交叉"。
